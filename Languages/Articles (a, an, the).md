## A/AN (Indefinite articles)
Use a before consonant sounds: a server, a database, a user
Use an before vowel sounds: an error, an API, an hour

### When to use a/an
- First mention of something: I found a bug
- One of many: He's a DevOps engineer
- Describing jobs/rules: She's an architect
- With singular countable nouns: A server needs maintenance

## THE (Definite Article)

### When to use the
- Specific item (both speaker and listener know which one): The server crashed (we know which server)
- Second mention: I found a bug. The bug is critical
- Unique things: the sun, the internet, the cloud
- Superlatives: the best solution, the fastest deployment
- With specific groups: the team, the engineers, the logs

## NO ARTICLE

### When to use no article
- Plural nouns: Servers need updates
- Uncountable nouns: Information is valuable, water, software
- Names of technologies: Docker, Kubernetes, Python, Linux
- Meals: breakfast, lunch, dinner
- Abstract concepts: security, automation, reliability

## Examples
- I need a new keyboard
- The keyboard on my desk is broken
- Keyboards are expensive
- I use Docker for containerization
- The Docker container failed
- She's an engineer at the company
- Engineers work with code
