Formation:
	Regular verbs: base verb + -ed
		work -> worked
		 play -> played
		 deploy -> deployed
	Spelling Rules for -ed:
		Most verbs: add -ed
		Verbs ending in -e: dd -d only
		Verbs ending in consostant + y: change y to i, add -ed
		One-syllable verbs: double last consostant
	Irregular verbs:
		go -> went, buy -> bought, swim -> swam
		make -> made, have -> had, do -> did
		run -> ran, come -> came, know -> knew
		think -> thought, take -> took
	Negative & Questions:
		Negative: subject + didn't + base verb
		Questions: Did + subject + base verb?
Usage: 
	Past simple describes completed actions in the past, often with time expressions like yesterday, last week, in 2020, two days ago
Examples:
- I deployed the application yesterday
- She didn't understand the error message
- Did you backup the database last night?
- The server crashed three times last week
- We migrated to Kubernetes in 2023
