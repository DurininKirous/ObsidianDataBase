Есть два способа добавления ноды в API сервер:
	1.  kubelet на ноде сам регистрируется, обращаясь к Control Plane
	2. ручное добавление 
После создания и добавления ноды, Control Plane проверяет ноду на валидность конфигурации. Например, наличие регистрации ноды с указанным в манифесте metadata.name. Если нода здорова, то есть все процессы работают, тогда ей разрешается запускать Поды. Иначе игнорируется до того момента, когда она станет здоровой. Чтобы остановить проверки, надо или вручную, или через controller удалить ноду.
