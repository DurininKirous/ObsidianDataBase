kubelet будет сам регистрировать ноду, если при запуске указан флаг *--register-node*, это поведение задано по умолчанию.
При запуске авторегистрации используются следующие флаги:
	1. *--kubeconfig* - путь к учётным данным для регистрации в API сервере
	2. *--cloud-provider* - как взаимодействовать с облачным провайдером, чтобы нода могла прочесть метаданные о себе
	3. *--register-node* - автоматически регистрироваться в API сервере
	4. *--register-with-taints* - регистрировать ноду с указанным списком секретов
		Если *--register-node* отключено, то данный флаг работать не будет
	5. *--node-ip* - разделённый список адресов для ноды в кластере. можно указать по одному адресу для каждого типа адресов. если не предоставлять данный флаг, нода будет использовать адрес по умолчанию (ipv4,ipv6)
	6. *--node-labels* - список меток для регистрации к ноде в кластере
	7. *--node-status-update-frequency* - определяет как часто kubelet будет отправлять состояние ноды API серверу
