#sr-due 
- Anycast: один IP анонсируется из ммногих PoP по BGP -> клиент попадает к ближайшему по маршрутизации. Это стандарт для публичных DNS и CDN
- Latency/Geo Routing: авторитетный DNS возвращает адрес ближайшего региона или по наименьшей задержке
- DNS health-checks: исключает мёртвые IP/регионы из ответов 
- Комбинация: GeoDNS + L7-LB внутри региона -> глобалка + локалка
