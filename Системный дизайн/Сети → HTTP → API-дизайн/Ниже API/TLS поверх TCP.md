#sr-due 
- TLS 1.3: 1 RTT на устанвоку (против 2 RTT на старых схемах)
- Сертификаты x.509: цепочка доверия (Root -> Intermediate -> Server). HSTS/H2/H3 обычно требуют валидный TLS
- PFS (Perfect Forward Secrecy): эфемерные ECDHE-ключи -> компрометация приватного ключа сервера не раскрывает прошлый трафик
- ALPN: согласование протокола прикладного уровня внутри TLS-handshake -> h2 (HTTP/2), h3 (HTTP/3)
- Оверхед: +1 RTT (или 0) и криптография на CPU; оправдывается безопасностью и часто ускоряет доступ благодая HTTP/2/3
