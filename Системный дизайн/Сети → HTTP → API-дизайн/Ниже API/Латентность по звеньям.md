#sr-due 
первый запрос обычно складывается из:
1. **DNS lookup** (если кэша нет/TTL мал).
2. **TCP 3WHS** или **QUIC 1-RTT/0-RTT**.
3. **TLS handshake** (встроен в QUIC; в TCP ещё +1 RTT).
4. **HTTP запрос/ответ** (плюс возможные редиректы, кеш-miss у CDN/прокси).

👉 на длинных трассах 2–3 RTT до полезных данных — норма; это почему CDN/edge/QUIC так сильно помогают.
