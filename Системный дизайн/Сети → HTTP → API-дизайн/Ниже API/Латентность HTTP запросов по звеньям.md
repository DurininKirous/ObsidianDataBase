### 💡 The What
	*Что это?*
Первый HTTP запрос всегда проходит цепочку определённых действий для установления соединения с целевым хостом. Каждая такая точка в цепочки добавляет 1 RTT (Round Trip Time) 

### ⚙️ The Why & How
*Инженерная суть. Механика. Зачем это нужно?*
Первый запрос обычно складывается из:
- [[[ObsidianDataBase/DevOps/Неделя 1/Сети/DNS/DNS|DNS]] Lookup (Если кэша нет/TTL мал)
- [[TCP]] 3WHS или QUIC 1-RTT/0-RTT ([[Работа TCP (рукопожатие)]], [[Закрытие TCP соединения]])
- TLS Handshake (Встроен в QUIC; в TCP ещё +1 RTT; [[TLS поверх TCP]]; [[HTTPS рукопожатие]])
- [[HTTP]] запрос/ответ (плюс возможные редиректы, кеш-miss у CDN/прокси)

---
### ⚔️ VS / Trade-offs
*С чем сравнить? Плюсы/Минусы.*
- **Trade-off**: 
	- Больше проверок/доп соединений -> больше RTT -> больше времени установления соединения
	- Меньше проверок/доп соединений -> меньше RTT -> более быстрое установление соединения
