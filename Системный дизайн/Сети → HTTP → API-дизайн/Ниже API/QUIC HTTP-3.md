### 💡 The What
*Что это?*
Это протокол прикладного уровня, по сути HTTP-3, построен на UDP, TLS

### ⚙️ The Why & How
*Инженерная суть. Механика. Зачем это нужно?*
- QUIC = транспорт поверх [[UDP]] + встроенный [[TLS]] 1.3 + мультиплексировние потоков
- Нет HOL-blocking на уровне соединения: потеря пакета тормозит только один поток, остальные идут дальше
- 0-RTT/1-RTT start, connection migration (сохраняет сессию при смене IP - критично для мобильных) 
- Лучше под потери и джиттер, особенно Wi-Fi/мобайл
- Диагностика сложнее (всё шифруется), часть сетей режет UDP -> нужен fallback на H2
Когда брать HTTP/3: публичный web, мобайл, realtime-фичи, CDN/edge - низкая латентность и устойчивость к потерям

---
### ⚔️ VS / Trade-offs
*С чем сравнить? Плюсы/Минусы.*
- **VS [[TCP]]**: TLS имеет проблему с HOL, не имеет встроенного шифрования
- VS [[HTTP]] ниже 3 уровня: нет встроенного шифрования, построен на TLS 
- **Trade-off**: 
	- Труднее мониторить, больший риск перегрузки трафика, большее потребление ресурсов
