#sr-due 
- **RTT (Round-Trip Time)** — полный круг туда-обратно. Ключевой «тактовый генератор» сетевых протоколов (см. выше).
- **BDP = Bandwidth × RTT** — сколько данных должно быть «в полёте», чтобы загрузить канал. Большой RTT ⇒ нужно большое окно для высокой пропускной.
- **Nagle**: копит малые посылки, чтобы слать крупнее (снижает PPS, повышает latency для мелких RPC).
- **Delayed ACK**: отправляет ACK не мгновенно, а с задержкой (десятки мс) → экономит трафик, но добавляет хвосты latency.
- Практика: **RPC/веб-API** часто включают `TCP_NODELAY` (отключают Nagle) и настраивают таймауты/ретраи с учётом RTT.
