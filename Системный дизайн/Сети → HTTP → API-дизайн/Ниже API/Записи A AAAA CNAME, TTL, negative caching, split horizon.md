#sr-due 
- A/AAAA: имя ->  IPv4/IPv6
- CNAME: алиас. Браузер резолвит цепочку до A/AAAA
- TTL: кремя кэширования ответа резолверами/клиентами
	- Низкий TTL (30-300s) = бытрые переключения/канареечные релизы, но выше нагрузка на авторитетный DNS
	- Высокий TTL (3600-86400s) = стабильность и дешёвый резолв, но медленные аварийные переключения
- Negative caching: даже NXDOMAIN кэшируется (По SOA) -> учитывай при "подъёме" домена после ошибки
- Split-horizon: разные ответы для внутренних/внешних (например, api.int -> приватные адреса, api.pub -> публичные)
