#sr-due 
- Производительность
	- Latency - время отклика
	- Throughput - количество запросов в единицу времени
	- Tail Latency - задержка на 95-м/99-м перцентиле (важна больше среднего)
- Надёжность и доступность
	- Availability - доля времени, когда система отвечает 
	- Reliability - вероятность корректного выполнения операции
	- Durability - вероятность непотери данных
	- MTTR/MTBF - среднее время восстановления / между отказами
- Масштабируемость
	- Vertical - мощнее сервер
	- Horizontal - больше серверов
	- Elasticity - автоматическая адаптация под нагрузку
- Согласованность
	- Strong consistency - все клиенты видят одно и то же
	- Eventual consistency - данные сходятся через время
	- Cap theorem: Из Consistency, Availability, Partition tolerance можно выбрать только два
	- BASE: Basically Available, Soft State, Eventually consistent
