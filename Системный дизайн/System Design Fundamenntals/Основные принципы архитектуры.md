#sr-due 

| Принцип                | Идея                                        | Пояснение                           |
| ---------------------- | ------------------------------------------- | ----------------------------------- |
| Stateless Service      | Не хранить состояние в приложении           | Упрощает масштабирование и recovery |
| Separation of Concerns | Делить по зонам ответственности             | Auth, API, Storage, Queue           |
| Loose Coupling         | Минимизировать зависимости между сервисами  | Через API / message broker          |
| Fail-fast              | Ошибайся быстро и явно                      | Circuit breaker, health-checks      |
| Graceful Degradation   | При перегрузке отключай нефункциональное    | Пример: показывать частичные данные |
| Backpressure Control   | Не принимай больше, чем можешь обрабатывать | Rate limit, очереди                 |
| Caching Hierarchy      | Несколько уровней кэша для latency < 100 мс | CDN -> Redis -> local               |
