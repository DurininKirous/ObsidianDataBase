#sr-due 
Горизонтальное масштабирование:
- Load Balancer: распределяет запросы
- Service Discovery: динамически находит инстансы
- Auto-scaling: метрики -> добавление/удаление узлов
Репликация и отказоустойчивость:
- Master-slave / leader-follower: чтение с реплик, запись в лидера
- Multi-leader / quorum-based: распределённые записи
- Failover: автоматическое переключение при сбое
- Data backup + PITR: точка восстановления
- Geo-replication: зоны отказа и latency-aware маршрутизация
