#sr-due 
Простейший алгоритм балансировки:
Request 1 -> Server 1
Request 2 -> Server 2
Request 3 -> Server 3
Request 4 -> Server 1 (по кругу)

Плюсы: Простота, равномерное распределение
Минусы: Не учитывает нагрузку на сервер (один может быть перегружен)

Когда использовать: Все серверы одинаковы, запросы примерно одинаковой сложности
