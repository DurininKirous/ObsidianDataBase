#sr-due 
LB переодически проверяет серверы:
GET /health -> 200 OK

Если сервер не отвечает или возвращает 5xx:
- LB помечает сервер как unhealthy
- Перестаёт отправлять туда трафик
- Продолжает проверять (каждые 10-30 секунд)
- Когда сервер восстановился -> возвращает в rotation

Типы healthchecks:
1. TCP check - просто проверка, что порт открыт
2. HTTP check - GET /health должен вернуть 200
3. Deep health check - проверка подключения к БД, Redis, etc
Trade-off: Глубока проверка = точне, но дороже (нагрузка на сервер, дольше время выполнения)
