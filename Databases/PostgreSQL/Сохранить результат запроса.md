Сохранить через командную строку:
```
psql -c "SELECT username,city FROM users;" -U rebrain_admin -d rebrain_courses_db -h localhost -p 5432  -o /tmp/out_fileaname.query_result
```
Сохранить уже работая в psql:
``` 
	\o /tmp/file_name
	SELECT * FROM tables;
```
Для выполнения команды командной оболочки из psql можно написать команды с помощью \!:
```
\! mkdir -p /tmp/your_new_directory_name
\! ls /tmp/
\! cat /tmp/out_filename.query.smth
```
