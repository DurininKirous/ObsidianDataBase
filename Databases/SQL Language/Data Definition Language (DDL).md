Язык определения данных (DDL) - это часть языка SQL, которая используется для создания, изменения и уничтожения основных элементов реляционных баз данных. В число этих элементов могу входить таблицы, представления, схемы, каталоги, кластеры, и, возможно, не только они.
Основные команды для PostgreSQL:
	1. CREATE - создаёт объект СУБД или базы данных, например базу данных.
		1. CREATE DATABASE db_name;
	2. ALTER - изменяет параметры объекта СУБД или базы данных, например выбранной роли.
		2. ALTER ROLE role_name WITH PASSWORD "password";
	3. DROP - удаляет объект СУБД или базы данных, например таблицу для текущей базы данных.
		1. DROP TABLE table_name;
