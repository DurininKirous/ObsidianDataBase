Язык Управления Транзакциями (TCL) - это часть языка SQL, используемая для обработки и контроля транзакций.
Основные команды DCL для PostgreSQL:
	1. BEGIN - начать блок транзакции. BEGIN начинает блок транзакции, то есть обозначает, что все операторы после команды BEGIN и до явной команды COMMIT или ROLLBACK буду выполняться в одной транзакции. По умолчанию PostgreSQL выполняет транзакции в режиме "autocommit", то есть каждый оператор выполняется в своей отдельной транзакции, которая неявно фиксируется в конце оператора (если транзакция выполнена успешно; в противном случае происходит откат)
	2. COMMIT - зафиксировать текущую транзакцию. Все изменения, произведённые транзакцией, гарантированно сохраняются в случае сбоя и становятся видимыми для других пользователей, у которых есть доступ на просмотр этих данных.
	3. ROLLBACK - прервать текущую транзакцию. Откатывает текущую транзакцию и приводит к аннулированию всех изменений, произведённых транзакцией.
