Язык управления данными (DCL) - это часть языка SQL, предназначенная для администрирования операций, присваивающих или отменяющих право (привелегию) использовать базу данных, таблицы или другие объекты базы данных, а также выполнять те или иные команды SQL.
Основные DCL команды для PostgreSQL:
	1. GRANT - выдать права доступа. Есть два варианта использования, первый это назначение права для доступа к объектам базы данных, второй это назначение одних ролей другим ролям.
		1. GRANT ALL PRIVILEGES ON DATABASE 'db_name' to 'db_role';
		2. GRANT 'admins' to 'joe';\
	2. REVOKE - отозвать права доступа.
		1. REVOKE ALL PRIVILEGES ON DATABASE 'db_name' TO db_user;
