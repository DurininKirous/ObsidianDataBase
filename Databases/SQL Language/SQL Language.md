Structured Query Language - декларативный язык программирования, применяемый для создания, изменения и удаления данных в реляционных базах данных, которыми управляет соответствующая СУБД. 
SQL содержит в себе 4 подраздела языка:
	1. Язык определения данных (Data Definition Language, DDL)
	2. Язык манипулирования данными (Data Manipulation Language, DML)
	3. Язык управления данными (Data Control Language, DCL)
	4. Язык управления транзакциями (Transaction Control Language, TCL)
