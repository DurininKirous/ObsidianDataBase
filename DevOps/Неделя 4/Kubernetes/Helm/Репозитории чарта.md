#sr-due 
**Classic (HTTP):**
- `helm repo add name https://…`
- `helm search repo name/chart`
- Хорош для публичных каталогов, но требует `index.yaml`.

**OCI (контейнерный реестр):**
- `helm push/pull oci://ghcr.io/<org>/charts`
- Нативные теги/версии, единая политика доступа, удобно в CI/CD.
- Рекомендую для внутренних репозиториев.
