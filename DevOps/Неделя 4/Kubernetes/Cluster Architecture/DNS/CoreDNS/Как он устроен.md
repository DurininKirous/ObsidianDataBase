#sr-due 
CoreDNS — модульный сервер, конфигурируется через **Corefile** (ConfigMap в Kubernetes).  
Пример Corefile:
.:53 {
    errors
    health
    kubernetes cluster.local in-addr.arpa ip6.arpa {
        pods insecure
        fallthrough in-addr.arpa ip6.arpa
        ttl 30
    }
    prometheus :9153
    forward . /etc/resolv.conf
    cache 30
    loop
    reload
    loadbalance
}
Разбор:
- `. :53` → слушать на всех интерфейсах, порт 53 (стандартный DNS).
- `kubernetes` → плагин, резолвит сервисы/Pod’ы внутри кластера.
- `forward . /etc/resolv.conf` → всё, что не внутри кластера (google.com и т.п.), переслать наружу (во внешний DNS, например 8.8.8.8).
- `cache` → кэшировать результаты.
- `prometheus` → отдавать метрики.
