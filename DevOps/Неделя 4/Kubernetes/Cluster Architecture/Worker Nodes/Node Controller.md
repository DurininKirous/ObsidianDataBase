Нод контроллер это компонент Control Plane, который контроллирует различные аспекты нод.
Нод контроллер имеет несколько ролей в жизни нод. Во-первых, это присвоение блока CIDR ip-адресов ноде внутри кластера, кода она регистрируется в API сервере.
Во-вторых, она проверяет внутренний список доступных нод и сравнивает его со списком доступных машин провайдера. Если нода недоступна, нод контроллер проверяет у провайдера, работает ли ещё данная машина. Если нет, нода удаляется из списка доступных нод у нод контроллера.
В третьих, нод контроллер следит за состоянием нод. Он отвечает за:
	1. Если нода становится недоступна, нод контроллер обновляет Ready условие в *.status* ноды. В таком случае Ready меняется на Unknown.
	2. Если нода остаётся недоступной на протяжении долгого времени, то инициируется API сервером сценарий выселения всех подов с данной ноды. По умолчанию нод контроллер ждёт 5 минут после присвоения ноде статуса Unknown и потом начинает вышеуказанный сценарий.
По умолчанию, нод контроллер проверяет состояние нод каждые 5 секунд, но это значение можно поменять с помощью флага *--node-monitor-period* в компоненте [[kube-controller-manager]]
