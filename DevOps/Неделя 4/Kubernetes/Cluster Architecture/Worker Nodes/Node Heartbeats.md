Сердцебиения, или состояния, отправленные нодой к API серверу, помогают определить доступность ноды в кластере, и применять действия при её отказе, недоступности.
Есть два вида сердцебиения:
	1. Обновление  *.status* ноды
	2. Обновление и создание Lease объектов в пространстве kube-node-lease. Это короткоживущие объекты, храняющие информацию о владельце ноды, последнем изменении и доступности.
