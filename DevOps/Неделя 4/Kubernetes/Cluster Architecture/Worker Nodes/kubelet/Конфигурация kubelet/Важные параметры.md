- `--cgroup-driver` (systemd vs cgroupfs) → должен совпадать с контейнерным runtime.
- `--kube-reserved` / `--system-reserved` → ресурсы, вырезаемые под kubelet/систему.
- `--eviction-hard` / `--eviction-soft` → пороги эвикции.
- `--fail-swap-on` → запретить запуск с включённым swap (по умолчанию true).
- `--container-runtime-endpoint` → сокет containerd/cri-o.
- `--pod-manifest-path` → путь для Static Pods.
