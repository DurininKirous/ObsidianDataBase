#sr-due 
### Когда запускается
- kubelet переодически смотрит usage `imagefs`
- Порог задаётся флагами:
	- `--image-gc-high-threshold` (по умолчанию 85%)
	- `--image-gc-low-threshold` (по умолчанию 80%)
Алгоритм:
1. Если usage > high => запускается GC
2. Удаляются неиспользуемые образы
3. Чисти, пока usage > low

### Какие образы удаляются
- Старые, неиспользуемые
- Учитывается "last used" (поддерживается CRI-runtime)
- Поддерживаемые runtime возвращают kubelet список `ImageStatus` -> kubelet решает, что убрать
