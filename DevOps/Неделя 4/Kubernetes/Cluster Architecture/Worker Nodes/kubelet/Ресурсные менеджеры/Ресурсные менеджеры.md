# Зачем нужны ресурсные менеджеры

По умолчанию kubelet использует cgroups:
- `requests` → гарантирует долю CPU/памяти,
- `limits` → верхняя граница.

Но этого мало для **high-perf** ворклоадов (ML, телеком, финтех), где важны NUMA, pinning и hugepages.  
 Ресурсные менеджеры позволяют kubelet работать «тонко»: закреплять CPU, учитывать топологию памяти/PCI, выделять большие страницы.
