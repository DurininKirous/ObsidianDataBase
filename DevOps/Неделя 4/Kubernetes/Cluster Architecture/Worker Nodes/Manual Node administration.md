Ноды можно создавать и модифицировать вручную с помощью *kubectl*, для этого надо выставить флаг *kubelet* *--register-node=false*.
Модифицировать ноды можно независимо от состояния флага *--register-node*, например задать дополнительные метки к существующей ноде или отключить шедулинг подов на ней.
Можно использовать метки вместе с селекторами для управления шедулинга, чтобы поды разворачивались только на определённом подмножестве доступных нод.
Для отключения размещения подов на ноде можно использовать следующее:
*kubectl cordon $NODENAME*
Стоит отметить, что [[DaemonSet]] допускает размещение подов даже на таких подах. DaemonSets обычно представляют собой внутринодовые локальные сервисы, которые должны работать на ноге даже если она перегружена рабочей нагрузкой.
