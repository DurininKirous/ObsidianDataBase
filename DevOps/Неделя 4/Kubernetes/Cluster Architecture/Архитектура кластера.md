Кластер состоит обычно из Control Plane и Worker Nodes.
Внутри них каждого работают уже свои сервисы.
Control Plane:
	1. kube-api-server
	2. kube-scheduler
	3. kube-control-manager
	4. etcd
	5. cloud-control-manager
	Все компоненты Control Plane общаются друг с другом через Api сервер
Worker Node:
	1. kubelet
	2. kube-proxy
