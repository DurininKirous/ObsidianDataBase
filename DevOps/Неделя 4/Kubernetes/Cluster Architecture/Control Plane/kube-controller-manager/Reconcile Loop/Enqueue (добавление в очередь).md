#sr-due 
- Когда informer получает событие, оно ставит объект в очередь (WorkQueue)
- В очередь ставится ключ объекта (обычно: "namespace/name")
- Если несколько событий подряд - дубликаты схлопываются
✅ Это позволяет разгрузить обработку и избежать гонок
