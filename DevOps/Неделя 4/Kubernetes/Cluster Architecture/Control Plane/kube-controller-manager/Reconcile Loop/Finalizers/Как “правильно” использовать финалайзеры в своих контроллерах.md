1. При создании управляемого ресурса контроллер добавляет свой финалайзер, например:
	- metadata.finalizers: ["example.com/my-controller"]
2. В reconcile:
	- Если deletionTimestamp == nil -> обычная логика
	- Если объект Terminating -> запускаем cleanup внешних артефактов
	- Убедились, что всё удалено/приведено в инвариант -> удаляем свой финалайзер
3. После того как финалайзеры сняты, объект удалит API-сервер.

> Важные свойства: **идемпотентность** и **повторяемость** cleanup (может зваться много раз).
