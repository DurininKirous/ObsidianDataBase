#sr-due 

1. Клиент шлёт DELETE объекта
2. API-сервер не удаляет объект, а ставит ему metadata.deletionTimestamp. Объект переходит в состояние Terminating
3. Пока список metadata.finalizers не пуст, объект остаётся в etcd и виден в списках
4. Контроллеры, добавившие свои финалайзеры, замечают deletionTimestamp, выполняют cleanup, и потом удаляют свою строку из metadata.finalizers.
5. Когда список пуст -> API-сервер физически удаляет объект
