#sr-due 
- **Застрял в Terminating**:
    - Контроллер умер / нет доступа / баг в cleanup → финалайзер не снимается.
    - Что делать: починить контроллер **или** вручную удалить финалайзер (крайняя мера: `kubectl patch … --type=json -p '[{"op":"remove","path":"/metadata/finalizers/0"}]'`), понимая риск **утечки** внешних ресурсов.
- **Порядок финалайзеров**: их может быть несколько; снимаются не “автоматически”, каждый владелец отвечает за свой.
- **RBAC**: снимающий финалайзер должен иметь право `update` на ресурс (иногда отдельно на подресурс `finalizers`).
- **Гонки**: всегда считайте, что объект мог “измениться” пока вы чистите; проверяйте актуальное состояние из кеша/апи и делайте патчи.
