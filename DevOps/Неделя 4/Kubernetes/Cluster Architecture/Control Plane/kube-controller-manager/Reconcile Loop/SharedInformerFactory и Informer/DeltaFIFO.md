#sr-due 
Это **очередь изменений (delta = разница)**. Она:
- хранит ключи объектов (namespace/name)
- для каждого объекта - цепочку изменений: add, update, delete
- не даёт одному объекту оказаться в очереди 1000 раз - дедуплицирует ключи 
Это **не та очередь, которую ты используешь в контроллере** — это очередь **внутри informer'а**, она служит для хранения raw-событий от API.
