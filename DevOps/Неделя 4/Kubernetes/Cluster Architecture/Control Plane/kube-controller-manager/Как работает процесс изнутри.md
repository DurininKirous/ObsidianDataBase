#sr-due 

- При старте запускается `Run()` → запускает **все контроллеры**, которые разрешены через `--controllers=`
- Каждый контроллер — **отдельная горутина**, со своим именем, логикой и очередью
- Все они используют **SharedInformerFactory**:
    - подписка на изменения (watch → events)
    - кеширование объектов
- Контроллер реагирует на изменения: enqueue → sync → reconcile → act
