#sr-due 
Все ключи в etcd имеют путь вида:

/registry/ (resource) / (namespace) / (name)
Примеры:
/registry/pods/default/nginx
/registry/nodes/node1
/registry/configmaps/default/app-config
/registry/customresourcedefinitions/mycrd.mygroup.io

🔸Это дерево путей (prefix keyspace)
🔸Вся сериализация идёт в **protobuf**, не JSON
