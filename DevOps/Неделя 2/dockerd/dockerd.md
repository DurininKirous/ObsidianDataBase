#sr-due 
dockerd - демон Docker Engine, который:
- обрабатывает команды от docker cli или http клиентов
- управляет образами, контейнерами, сетями, volume'ами
- делегирует запуск контейнеров containerd
- предоставляет полноценный REST API (Docker Engine API)
- работает как "мозг" Docker'а, собирающий всё воедино
dockerd - это высокоуровневый слой, делающий работу с контейнерами удобной и полной
