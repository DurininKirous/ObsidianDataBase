#sr-due 
Когда запускаешь контейнер, Docker:
1. Создаёт **veth-пару** (виртуальные интерфейсы)
2. Один конец добавляет в контейнер как `eth0`
3. Второй подключает к **bridge-интерфейсу** на хосте (например, `docker0`)
4. Выдаёт контейнеру IP из пула этой сети
5. Настраивает **NAT через iptables** для связи с внешним миром
6. Включает **встроенный DNS-сервер**, чтобы контейнеры общались по имени
