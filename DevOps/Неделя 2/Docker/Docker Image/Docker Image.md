#sr-due 
Docker image - это read-only шаблон контейнероной root файловой системы + метаинформация, превращающийся в исполняемый контейнер через snapshot, overlayFS и runc.
Это не просто архив, а слоистая модель, которую можно:
- кэшировать
- пересобирать
- копировать по сети
- воспроизводить с точностью до бита
