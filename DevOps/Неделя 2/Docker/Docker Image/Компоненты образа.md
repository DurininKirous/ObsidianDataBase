#sr-due 
#### Layers (.tar)
Read-only diff'ы (изменения к FS)
- каждый слой описывает: что добавилось, изменилось или удалилось
- Dockerfile -> каждый RUN, COPY, ADD -> новый слой
#### Image Config
Json с:
- Env, Entrypoint, Cmd
- WorkingDir, User, ExposedPorts
- rootfs.diff_ids - список sha256 от слоёв
Содержит мета-информацию, но не исполняется напрямую

#### Manifest (manifest.json)
- Указывает порядок слоёв
- Ссылается на config.json
- Поддерживает медиа-типы (OCI, Docker, Schema v2)
