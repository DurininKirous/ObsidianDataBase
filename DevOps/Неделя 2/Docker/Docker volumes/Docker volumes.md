#sr-due 
Docker volume - это абстракция над хранилищем, хранящимся вне контейнера:
- обладает собственной жизнью
- находится вне образа и контейнерного слоёв
- используется для данных, которые должны пережить перезапуск контейнера
- можно шарить между несколькими контейнерами

Хранятся в: 
/var/lib/docker/volumes/
└── <volume_name>/
    └── _data/  ← сюда идёт всё содержимое
