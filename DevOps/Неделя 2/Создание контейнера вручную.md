# Ручной контейнер без Docker
Цель — вручную создать Linux-контейнер: изолированный процесс с собственным rootfs, PID space, сетью и ограничениями по ресурсам. Используются только стандартные утилиты: `unshare`, `mount`, `pivot_root`, `cgroups`, `chroot`.

---

## 🧱 Этап 1: Подготовка root файловой системы

```bash
mkdir /tmp/alpine
cd /tmp/alpine
docker export $(docker create alpine) | tar -xvf -
```
Теперь `/tmp/alpine` — это минимальный rootfs.

## Этап 2: unshare — создание namespace'ов
`sudo unshare --mount --uts --ipc --net --pid --fork --user --map-root-user bash`
Мы в новой песочнице:
- новый PID namespace
- пустая сеть, hostname и UTS
- UID=0 внутри, но не root на хосте

## Этап 3: pivot_root или chroot

> **pivot_root** — безопасный способ смены root

mkdir /tmp/alpine/old_root
mount --bind /tmp/alpine /tmp/alpine
cd /tmp/alpine
pivot_root . old_root
umount -l /old_root
exec /bin/sh

##  Этап 4: Монтирование нужных системных файловых систем
mount -t proc proc /proc
mount -t tmpfs tmpfs /tmp
mount -t sysfs sys /sys
## Этап 5: Ограничения через cgroups (v2)
mount -t cgroup2 none /sys/fs/cgroup
mkdir /sys/fs/cgroup/mycontainer
echo $$ > /sys/fs/cgroup/mycontainer/cgroup.procs
echo "memory" > /sys/fs/cgroup/cgroup.subtree_control
echo 100000000 > /sys/fs/cgroup/mycontainer/memory.max
