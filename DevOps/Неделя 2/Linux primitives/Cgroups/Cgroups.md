#sr-due 
Cgroups - подсистема ядра Linux, которая позволяет:
1. Организовывать процессы в группы (cgroups = control groups)
2. Ограничивать использование системных ресурсов  (CPU, память, диск, сеть) для этих групп
3. Учитывать статистику использования ресурсов этими группами
4. Приоритизировать группы процессов относительно других
5. Приостановить и возобновлять процессы группой
Вместо того, чтобы ограничивать процессы по отдельности, Linux позволяет группировать их в cgroups, на которые навешиваются правила управления ресурсами.  
Это критично для контейнеров: ведь контейнер = просто процесс в Linux с изоляцией через namespaces + ограничениями через cgroups.
