| executor       | Где выполняется job                      | Применение                      |

| docker         | Временный контейнер                      | Изолированная среда, кэшируемая |

| ssh            | Подключается к удалённому серверу по SSH | Простой деплой, но ручной       |
| custom         | Через скрипты                            | Полный контроль                 |
