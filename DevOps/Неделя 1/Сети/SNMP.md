# 📡 SNMP (Simple Network Management Protocol)

## 🔥 Зачем нужен
- Мониторинг сетевых устройств, серверов, UPS.
- Поддерживается почти всем железом.

## 🚀 Архитектура
| Компонент | Описание                           |
|-----------|-----------------------------------|
| Manager   | NMS (например Zabbix, Grafana SNMP) |
| Agent     | snmpd на устройстве               |
| MIB       | база описания OID                 |
| OID       | дерево значений (например sysName) |

## 📦 Протокол
- UDP порт **161** для запросов
- UDP порт **162** для traps
- Версии: **v1, v2c, v3**

## 🛠 Примеры
bash
snmpget -v2c -c public 192.168.1.1 1.3.6.1.2.1.1.5.0
snmpwalk -v2c -c public 192.168.1.1
