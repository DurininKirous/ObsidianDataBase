#sr-due 
Установление TCP соединия происходит в 3 этапа (трёхстороннее рукопожатие):

| Этап | Типы флагов | Что происходит                                                                                                                                                                      |
| ---- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1    | SYN         | Клиент генерирует случайный sequence number (seq=1000) и отправляет SYN с этим Seq N, это объявляет старт нумерации                                                                 |
| 2    | SYN-ACK     | Сервер отправляет подтверждение SYN клиента (ACK), говоря что готов принимать байты начиная SYN+1. Также отправляет свой SYN=y, говоря что будет отправлять  байты с y номера байта |
| 3    | ACK         | Клиент подтверждает SYN сервера, говоря что готов принимать байты начиная с y+1 номера                                                                                              |
