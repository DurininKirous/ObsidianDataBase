#sr-due 
Основные используемые состояния сокетов из документа RFC 793

| Состояние    | Что значит                                                 |
| ------------ | ---------------------------------------------------------- |
| LISTEN       | Сокет слушает, ждёт входящих соединений                    |
| SYN-SENT     | Клиент отправил SYN, ждёт SYN-ACK                          |
| SYN-RECEIVED | Сервер получил SYN, отправил SYN-ACK, ждёт ACK             |
| ESTABLISHED  | Соединение установлено, можно передавать данные            |
| FIN-WAIT-1   | Отправил FIN, ждёт ACK                                     |
| FIN-WAIT-2   | Получил ACK на свой FIN, ждёт FIN от другой стороны        |
| CLOSE-WAIT   | Получил FIN от другой стороны, готовит своё закрытие       |
| LAST-ACK     | Получил FIN в ответ на FIN, ждёт последний ACK             |
| TIME-WAIT    | Подтвердил свой FIN, ждёт ~2MSL, чтобы избежать дубликатов |
| CLOSING      | Оба почти одновременно отправили FIN, ждут ACK             |
| CLOSED       | Соединение полностью закрыто                               |
|              |                                                            |
