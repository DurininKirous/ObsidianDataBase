#sr-due 
Протокол канального уровня, работает с mac адрессами, типо аналог ip адресов на указанном уровне osi.
Используется чтобы найти MAC-адрес по IP-адресу в локальной сети.
Хост, который отправляет IP пакет, смотрит свой ARP кеш, чтобы сопоставить конечную точку с его MAC адресов. Если MAC-адрес не найден, то шлётся по broadcast ARP request, находится нужный хост, он отправляет ARP Reply, заполняется MAC-адрес, отправляется пакет дальше
