#sr-due 
Таблица всех основных кодов HTTP ответов

## 1xx - Информационные

| Код | Тип                 | Значение                                                  | Где используется       |
| --- | ------------------- | --------------------------------------------------------- | ---------------------- |
| 100 | Continue            | Клиент может продолжать отправку запроса                  | Загружать большие POST |
| 101 | Switching Protocols | Сервер переключает протокол                               | Upgrade: WbSocket      |
| 102 | Processing          | WebDAV: сервер принял и обрабатывает, но ответа ещё нет   | Редко                  |
| 103 | Early Hints         | Подсказывает браузеру preload ресурсы до основного ответа | CDN, HTTP/2            |

---

## 2xx - Успешно

| Код | Тип        | Значение                         |
| --- | ---------- | -------------------------------- |
| 200 | Ок         | Успех, всё норм, ответ с данными |
| 201 | Created    | Ресурс создан (POST /api)        |
| 204 | No Content | Успех, но тело пустое (DELETE)   |

---

## 3xx - редиректы

| Код | Тип               | Значение                                         |
| --- | ----------------- | ------------------------------------------------ |
| 301 | Moved Permanently | Постоянный редирект                              |
| 302 | Found             | Временный редирект                               |
| 304 | Not Modified      | Кеш актуален, можно использовать локальную копию |

---

## 4xx - ошибка клиента

| Код | Тип                  | Значение                               |
| --- | -------------------- | -------------------------------------- |
| 400 | Bad Request          | Неверный запрос                        |
| 401 | Unauthorized         | Нужна авторизация                      |
| 403 | Forbidden            | Запрещено, даже если авторизован       |
| 409 | Conflict             | Конфликт при PUT/POST                  |
| 422 | Unprocessable Entity | Валидация не прошла (Часто в REST API) |

---

## 5xx - ошибка сервера

| Код | Тип                   | Значение                              |
| --- | --------------------- | ------------------------------------- |
| 500 | Internal Server Error | Ошибка на сервере                     |
| 502 | Bad Gateway           | Upstream не отвечает или отдал ошибку |
| 503 | Service Unavailable   | Сервер перегружен или в мейнтейненсе  |

2xx → успех
3xx → редиректы
4xx → ошибка клиента
5xx → ошибка сервера
