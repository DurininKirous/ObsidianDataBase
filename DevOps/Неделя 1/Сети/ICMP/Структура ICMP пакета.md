#sr-due 
ICMP Header:

| Поле           | Длина                                                    | Описание                                                                  |
| -------------- | -------------------------------------------------------- | ------------------------------------------------------------------------- |
| Type           | 8 бит                                                    | Тип сообщения ICMP (Echo Request = 8, Echo Reply = 0, Time Exceeded = 11) |
| Code           | 8 бит                                                    | Уточнение типа                                                            |
| Checksum       | 16 бит                                                   | Для проверки целостности ICMP                                             |
| Остальные поля | Зависит от поля: для Echo: Identifier, Sequence Number   |                                                                           |
| Data           | Данные (Например ping несёт по умолчанию 56 байт текста) |                                                                           |
