#sr-due 
RAID 5 сочетает в себе:
- Striping как в RAID 0
- Parity (XOR контрольные блоки), которые позволяют восстановить данные при отказе одного диска
![[Pasted image 20250713140301.png]]
### Как это выглядит
Представим есть три диска и данные делятся на блоки A, B, C, D, E, F:
Disk1: A    D    P3
Disk2: B    E    P1
Disk3: C    F    P2

- Где **P1, P2, P3** — блоки **парити**, вычисленные через XOR от соответствующих блоков на других дисках.
Например:
- `P1 = A ⊕ B ⊕ C`
- `P2 = D ⊕ E ⊕ F`
- Так парити **распределяется по всем дискам**, чтобы нагрузка на запись не ложилась только на один диск.
Алгоритм размещения определяется алгоритмом в RAID-контроллере, обычно циклически смещаются сверху вниз. 

### Производительность

| Операция | Как происходит                                                                                                                |
| -------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Чтение   | Очень быстро, параллельное чтение со всех диск                                                                                |
| Запись   | Медленнее, потому что нужно читать старые данные и старое парити, пересчитать новый XOR, записать новые данные + новое парити |

### Полезная ёмкость
Полезная ёмкость для RAID 5 = (N-1)*размер одного диска

### Отказоустойчивость
- RAID 5 выдерживает отказ 1 диска
- Если в degraded режиме умирает ещё один диск - массив полностью потерян

### Реализация в Linux
```
#создать RAID 5 из 3 дисков
mdadm --create /dev/md0 --level=5 --raid-devices=3 /dev/sdb /dev/sdc /dev/sdd

#смотреть процесс синхронизации
cat /proc/mdstat

#детали
mdadm --detail /dev/md0
```
