#sr-due 
Утилита для анализа активности сокетов
ss -tulwn - показать tcp и udp сокеты в состоянии listen в raw формате, порты числами
ss -p - показывает какой процесс использует сокет
ss -tulwn sport = :8080 - показать кто слушает 8080 порт
ss -s - показать статистику по сокетам
ss -tan state (state) - показать сокеты в указанном состоянии
