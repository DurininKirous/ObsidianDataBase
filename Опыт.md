## Проект: Observability-Ready FastAPI Service
**Описание:**  
Проект, разработанный в рамках обучения, демонстрирует архитектуру наблюдаемого FastAPI-сервиса с PostgreSQL и Prometheus.

**Ключевые возможности:**
- CRUD API для сущности service_checks
- PostgreSQL с асинхронными сессиями (asyncpg, SQLAlchemy)
- Endpoint /metrics с prometheus-fastapi-instrumentator
- Тестирование с помощью pytest и TestClient
- Docker Compose-окружение (FastAPI + PostgreSQL + Prometheus)
Проект изучался и развивался как часть практики по backend и DevOps.
