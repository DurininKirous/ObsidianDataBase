#sr-due 
Data Link - канальный (Ethernet, MAC, коммутаторы)
- Для чего: надёжная передача по одной физической среде между соседями
- Что делает:
	- Кадрирование: добавляет заголовок/хвост кадра
	- Адресация MAC-адресами в пределах сегмента
	- Работа коммутаторов: пересылка по MAC-таблица
- Единица данных: кадр (ethernet frame)
