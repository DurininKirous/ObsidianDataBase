#sr-due 
Network - сетевой (IP, маршрутизация, ICMP)
- Для чего: доставляет пакеты от узла к узлу через многие сети
- Что делает: 
	- Адресация IP-адресами (к кому идти)
	- Маршрутизация: выбор следующего узла/пути
	- ICMP: служебные сообщения (ошибки, pind/echo)
- Единица данных: пакет (IP-пакет)
