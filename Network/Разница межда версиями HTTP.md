#sr-due 
**HTTP/1.0 (1996)**
- Одно соединение — один запрос (по умолчанию закрывается).
- Нет обязательного `Host` (виртуальный хостинг неудобен).
- Ограниченный кэш/заголовки.

**HTTP/1.1 (1997 → de-facto стандарт)**
- **Persistent connections** по умолчанию (keep-alive), несколько запросов подряд в одном TCP.
- Обязателен заголовок **`Host`**.
- **Chunked transfer encoding** (потоковая передача без заранее известной длины).
- Улучшен кэш/условные запросы (`ETag`, `If-None-Match`, `If-Modified-Since`), **pipelining** (почти не используется из-за head-of-line).

**HTTP/2 (2015)**
- Один TCP-коннект → **мультиплексирование потоков** (нет HOL-блокировки на уровне HTTP).
- **Бинарный** формат фреймов (вместо текстового).
- **HPACK** — сжатие заголовков.
- **Приоритизация** потоков, сервер может **push** (сейчас редко применяют).

**HTTP/3 (IETF, на базе QUIC/UDP)**
- Транспорт не TCP, а **QUIC (UDP)** → нативное **мультиплексирование без HOL** на транспорте и быстрый ресюм/0-RTT.
- Встроенное шифрование (TLS 1.3 внутри QUIC).
- Меньше задержки при потере пакетов (нет «общего» TCP-потока).
