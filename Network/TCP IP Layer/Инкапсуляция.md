#sr-due 
Отправитель (сверху вниз):
1. **Application**: приложение создаёт, напр., HTTP-запрос/DNS-вопрос/SSH-сообщение.
2. **Transport**: упаковывает данные приложения в **TCP/UDP** с **портами** (кто говорит с кем на хосте).
3. **Internet**: добавляет заголовок **IP** с **IP-адресами** источника/назначения; при необходимости формирует/обрабатывает **ICMP**; при отправке в локальной сети выясняет адрес канального уровня через **ARP**.
4. **Link**: оборачивает IP-пакет в **кадр** (Ethernet/Wi-Fi) с **канальными адресами** и отправляет по среде.
Короткая формула:
```css
APP-данные → TCP/UDP(порты) → IP(адреса) + [ICMP/ARP по ситуации] → L2-кадр → биты по среде
```
1 → 2: принимает кадр, проверяет целостность, снимает заголовок канального уровня.  
2 → 3: извлекает **IP-пакет**, смотрит **dst IP**; ICMP обрабатывает как служебный.  
3 → 4: передаёт в **TCP/UDP**, восстанавливает поток/сообщения по портам.  
4 → приложение: HTTP/DNS/SSH/FTP читают свои сообщения.
