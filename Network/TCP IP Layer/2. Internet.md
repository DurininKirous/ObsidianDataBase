#sr-due 
Internet - межсетевой (IP, ICMP, ARP)
- Для чего: доставка узел - узел через множество сетей
- Что делает:
	- IP: адресация (src/dst IP), маршрутизация, фрагментация
	- ICMP: служебные сообщения/диагностика (ошибки, echo)
	- ARP: сопоставляет IP адресу локальный канальный адрес, чтобы можно было отправить кадр следующему узлу
- Единица данных: пакет
