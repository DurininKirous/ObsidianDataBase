#sr-due 
Цель: 4 равные подсети → нужно добавить **ещё 2 бита** в часть сети (так как `2^2 = 4`).
- `/24` → **`/26`** (24+2).
- Размер каждой подсети: `2^(32−26) = 64` адреса (из них 62 хоста).

Подсети по шагу **64** (шаг = размер подсети):
- `192.168.1.0/26` → адреса `0–63`
    - network `192.168.1.0`, broadcast `192.168.1.63`, хосты `1–62`
- `192.168.1.64/26` → адреса `64–127`
    - network `192.168.1.64`, broadcast `192.168.1.127`, хосты `65–126`
- `192.168.1.128/26` → адреса `128–191`
    - network `192.168.1.128`, broadcast `192.168.1.191`, хосты `129–190`
- `192.168.1.192/26` → адреса `192–255`
    - network `192.168.1.192`, broadcast `192.168.1.255`, хосты `193–254`
