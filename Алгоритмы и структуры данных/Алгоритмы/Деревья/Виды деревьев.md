#sr-due 
**Full Binary Tree (полное бинарное дерево)**
- Каждый узел имеет либо **0**, либо **2** ребёнка.
- ❌ Не обязательно сбалансированное.
Пример:
```md
    1
   / \
  2   3
 / \
4   5
```

**Complete Binary Tree (полностью заполненное)**
- Все уровни заполнены **полностью**, кроме последнего.
- Последний уровень заполняется **слева направо** без пропусков.
- Используется в **heap** (куча).
```md
    1
   / \
  2   3
 / \   \
4   5   4
```

**Perfect Binary Tree (идеальное)**
- Все внутренние узлы имеют двух детей.
- Все листья находятся на **одном уровне**.
- Пример:
```md
     1
   /   \
  2     3
 / \   / \
4   5 6   7
```

**Balanced Binary Tree (сбалансированное)**
- Для любого узла: разница высот левого и правого поддерева ≤ 1.
- Не обязательно Complete или Perfect.
- Пример:
```md
     1
    / \
   2   3
  /
 4
```

**BST (Binary Search Tree, бинарное дерево поиска)**
- Для каждого узла:  
    `Left.Val < Node.Val < Right.Val`
- Inorder traversal даёт **отсортированный массив**.
- Пример:
```md
     8
    / \
   3   10
  / \    \
 1   6    14
```
