#sr-due 
## 📌 Определение
- Для любого узла:  
    `Left.Val < Node.Val < Right.Val`
- Это условие должно выполняться рекурсивно для всех поддеревьев.

---

## 📌 Свойства
1. **Inorder Traversal → отсортированный массив**
    - Если пройти дерево обходом _inorder (LNR)_, то получим значения по возрастанию.
    - Часто используется для проверки корректности BST (LeetCode 98).
2. **Операции поиска / вставки / удаления**
    - Поиск: идём влево, если `x < node.Val`, или вправо, если `x > node.Val`.
    - Вставка: аналогично поиску, пока не найдём пустое место.
    - Удаление:
        - если узел — лист → просто удаляем;
        - если один ребёнок → заменяем на ребёнка;
        - если два ребёнка → ищем inorder successor (минимум в правом поддереве).
3. **Сложность операций**
    - В среднем (сбалансированное BST):
        - Поиск / вставка / удаление = **O(log n)**
    - В худшем случае (дерево в линию):
        - Поиск / вставка / удаление = **O(n)**
4. **Связь с балансировкой**
    - Несбалансированное BST может деградировать в список.
    - Поэтому используют **AVL, Red-Black Tree** для поддержания баланса.
