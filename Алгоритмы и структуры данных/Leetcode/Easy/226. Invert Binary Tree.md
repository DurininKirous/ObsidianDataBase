```go
func invert(root *TreeNode) {
    if root == nil {
        return
    }
    // меняем поддеревья
    tmp := root.Left
    root.Left = root.Right
    root.Right = tmp

    // рекурсивно инвертируем детей
    invert(root.Left)
    invert(root.Right)
}

func invertTree(root *TreeNode) *TreeNode {
    invert(root)
    return root
}
```
## Идея решения
- Для каждого узла:
    - поменять местами `Left` и `Right`;
    - рекурсивно вызвать инвертирование для новых детей.
- Можно реализовать:
    - **DFS рекурсией** (самый короткий код).
    - **BFS через очередь** (итеративный вариант).
