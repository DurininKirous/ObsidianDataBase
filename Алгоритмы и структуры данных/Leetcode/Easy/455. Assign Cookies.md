```go
import "sort"

func findContentChildren(g []int, s []int) int {
    sort.Ints(g)
    sort.Ints(s)
    i, j := 0, 0
    for i < len(g) && j < len(s) {
        if s[j] >= g[i] { 
            i++           
        }
        j++               
    }
    return i
}
```
## Идея
- Сортируем жадности детей `g` и размеры печенек `s`.
- Двумя указателями идём слева направо: если печенька `s[j]` удовлетворяет текущего ребёнка `g[i]`, «кормим» и двигаем `i`. Иначе ищем следующую печеньку (`j++`).
- Жадный принцип: **наименее жадному — минимально подходящую печеньку**.
