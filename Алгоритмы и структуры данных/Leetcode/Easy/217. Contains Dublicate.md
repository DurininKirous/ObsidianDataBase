func containsDuplicate(nums []int) bool {
    numsh := make(map[int]int)
    for _, val := range nums {
        numsh[val]++
        if numsh[val] > 1 {
            return true
        }
    }
    return false
}

## Алгоритм
- Создать hash map.
- Пройти по массиву и считать вхождения.
- Если встречается число второй раз → вернуть `true`.
- Если прошли весь массив без повторов → `false`.
