```python
class Solution:
    def lemonadeChange(self, bills: List[int]) -> bool:
        five = 0
        ten = 0
        for i in bills:
            curr = i
            if curr == 5:
                five+=1
            if curr == 10:
                if five > 0:
                    ten +=1
                    five -=1
                else:
                    return False
            if curr == 20:
                if ten > 0 and five > 0:
                    five -= 1
                    ten -= 1
                elif five > 2:
                    five -= 3
                else:
                    return False
        return True
```
## Идея
- Храним количество купюр `$5` и `$10`.
- Для каждого платежа:
    - `$5` → увеличиваем `five`.
    - `$10` → нужен один `$5`: уменьшаем `five`, увеличиваем `ten`, иначе `False`.
    - `$20` → отдаём сдачу **сначала `$10+$5`**, иначе **тремя `$5`**; если нельзя — `False`.
- Жадный принцип: экономим `$5`, но при `$20` выгоднее расходовать одну `$10` + одну `$5`.
