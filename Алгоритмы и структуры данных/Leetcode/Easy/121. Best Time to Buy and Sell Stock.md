func maxProfit(prices []int) int {
    minBuy := prices[0]
    maxProf := 0
    for i := 1; i < len(prices); i++ {
        if prices[i] < minBuy {
            minBuy = prices[i]
        } else {
            maxProf = max(maxProf, prices[i]-minBuy)
        }
    }
    return maxProf
}

## Алгоритм
- Храним минимальную цену покупки (`minBuy`).
- Для каждого дня считаем потенциальную прибыль: `prices[i] - minBuy`.
- Обновляем максимум.
- Если встречаем более низкую цену → обновляем `minBuy`.
