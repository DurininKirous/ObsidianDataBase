```python
class Solution:
    def reverseWords(self, s: str) -> str:
        words = s.split(" ")
        words_reversed = [x[::-1] for x in words]
        return " ".join(words_reversed)
```
**Идея:**  
Разбиваем строку по пробелам, каждое слово разворачиваем `[::-1]`, потом склеиваем обратно через пробел. Пробелы между словами сохраняются в соответствии с условием
