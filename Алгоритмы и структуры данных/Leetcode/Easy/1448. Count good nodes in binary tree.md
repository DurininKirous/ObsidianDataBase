# 💡 The What
*О чем задача? Что нужно сделать?*
Дано бинарное дерево, нужно найти все такие ноды, что по пути от корня к этой ноде не было элементов, которые больше по значению самой ноды


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Обычный DFS проход, возвращаем ноль, если дошли до null, проверяем, что текущая нода больше максимума, разветвляемся влево и вправо

**Time Complexity:** O(n)
**Space Complexity:** O(h)

---

## 💻 Code

```python
def findGoodNodes(root, max_curr):
	if not root:
		return 0
	is_good = 1 if root.val >= max_curr else 0
	new_max = max(root.val, max_curr)
	left = findGoodNodes(root, new_max)
	right = findGoodNodes(root, new_max)
	return is_good + left + right
return findGoodNodes(root, root.val)
```
