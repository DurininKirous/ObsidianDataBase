func removeDuplicates(nums []int) int {
    if len(nums) == 0 {
        return 0
    }

    k := 1 // индекс для записи следующего уникального
    for i := 1; i < len(nums); i++ {
        if nums[i] != nums[i-1] {
            nums[k] = nums[i]
            k++
        }
    }
    return k
}

### Как это работает
- Массив уже **отсортирован** — значит, все дубликаты идут подряд.
- Двигаем один указатель (`i`) по массиву.
- Если встречаем новый элемент — пишем его на позицию `k` и увеличиваем `k`.
- В итоге:
    - `nums[:k]` содержит уникальные элементы.
    - `nums[k:]` можно не трогать (LeetCode не проверяет).
