```go
func hammingWeight(n int) int {
    if n == 0 {
        return 0
    }
    countBits := 0
    for n > 0 {
        if n%2 == 1 {  // проверяем последний бит
            countBits++
        }
        n /= 2  // сдвигаем вправо
    }
    return countBits
}
```
**Сложность:**
- Время: O(log n) или O(32) для 32-битных чисел
- Память: O(1)

```go
func hammingWeight(n int) int {
    countBits := 0
    for n > 0 {
        n &= (n - 1)  // убирает самый правый бит 1
        countBits++
    }
    return countBits
}
```

**Почему это работает:**
- При вычитании 1: самая правая `1` становится `0`, все биты справа переворачиваются
- AND оставляет только общие единицы → правая единица исчезает

**Сложность:**
- Время: O(k), где k = количество единиц
- Память: O(1)
