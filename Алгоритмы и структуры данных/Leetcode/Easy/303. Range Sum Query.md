```go
type NumArray struct {
    nums []int
}

func Constructor(nums []int) NumArray {
    sum := 0
    for i := range nums {
        nums[i] += sum
        sum = nums[i]
    }
    return NumArray{nums: nums}
}

func (this *NumArray) SumRange(left int, right int) int {
    if left == 0 {
        return this.nums[right]
    }
    return this.nums[right] - this.nums[left-1]
}
```
💡 Идея решения
**Ключевая идея:** Prefix Sum (Префиксные суммы)

Вместо того чтобы считать сумму каждый раз заново O(n), **предварительно** вычисляем накопленные суммы за O(n), а потом отвечаем на запросы за O(1).
**Формула:**
sum[left..right] = prefixSum[right] - prefixSum[left-1]
