# 💡 The What
*О чем задача? Что нужно сделать?*
Дано бинарное дерево поиска и число, нужно вернуть ноду этого дерева, равного по значению этому числу

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем свойства  бинарного дерева поиска и просто проходимся по дереву, по нахождении ноды возвращаем результат

**Time Complexity:** O(n)
**Space Complexity:** O(h)

---

## 💻 Code

```python
def searchBST(root, val):
	if not root:
		return None
	if root.val > key:
		return searchBST(root.left, val)
	if root.val < key:
		return searchBST(root.right, val)
	return root
```
