```python
from collections import defaultdict

class Solution:
    def uniqueOccurrences(self, arr: List[int]) -> bool:
        dick = defaultdict(int)
        for i in arr:
            dick[i] += 1
        return len(dick.values()) == len(set(dick.values()))
```
**Идея решения:**
1. Подсчитываем частоту каждого элемента в массиве с помощью defaultdict
2. Сравниваем количество всех частот с количеством **уникальных** частот (через set)
3. Если они равны — значит все частоты уникальны, возвращаем True

**Временная сложность:** O(n)  
**Пространственная сложность:** O(n)
