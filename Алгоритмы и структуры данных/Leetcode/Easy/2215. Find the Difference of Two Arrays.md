```python
class Solution:
	def findDifference(self, nums1: List[int], nums2: List[int]) -> List[List[int]]:
		a = set(nums1)
		b = set(nums2)
		xor = a ^ b
		return [list(xor&a), list(xor&b)]
```
**Идея:**  
превращаем в множества и берём разность множеств `a - b` и `b - a`.
