```python
class Solution:
    def mergeAlternately(self, word1: str, word2: str) -> str:
        i = 0
        j = 0
        res = ""
        while i < len(word1) or j < len(word2):
            if i < len(word1):
                res += word1[i]
                i += 1
            if j < len(word2):
                res += word2[j]
                j += 1
        return res
```
_Задача:_ Объединить две строки, чередуя символы поочередно. Если одна строка короче, добавить оставшиеся символы другой строки.

_Подход:_ Два указателя
- Используем два указателя `i` и `j` для отслеживания позиций в `word1` и `word2`
- Условие цикла: `while i < len(word1) or j < len(word2)` — продолжаем, пока есть символы в любой строке
- На каждой итерации: если есть символ в текущей позиции, добавляем его в результат и двигаем указатель
- Порядок важен: сначала добавляем из `word1`, затем из `word2` (так обеспечивается правильное чередование)

_Сложность:_
- Время: O(n + m), где n и m — длины строк
- Память: O(n + m) для результирующей строки

_Пример:_ word1 = "abc", word2 = "pqr" → "apbqcr"
