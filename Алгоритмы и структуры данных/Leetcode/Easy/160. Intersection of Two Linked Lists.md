func getIntersectionNode(headA, headB *ListNode) *ListNode {
    if headA == nil || headB == nil {
        return nil
    }
    pA, pB := headA, headB
    for pA != pB {
        if pA == nil {
            pA = headB
        } else {
            pA = pA.Next
        }
        if pB == nil {
            pB = headA
        } else {
            pB = pB.Next
        }
    }
    return pA
}

### Алгоритм (Two Pointers)
1. Завести два указателя `pA` и `pB` в головы списков.
2. Пока `pA != pB`:
    - Если `pA == nil` → пересадить в `headB`, иначе `pA = pA.Next`.
    - Если `pB == nil` → пересадить в `headA`, иначе `pB = pB.Next`.
3. Когда они встретятся → вернуть узел (или `nil`, если пересечения нет).

### Концепция
- Каждый указатель проходит **одинаковую дистанцию = m+n**.
- Если пересечение есть → встретятся в общем узле.
- Если нет → оба одновременно станут `nil`.
