```python
class Solution:
    def numJewelsInStones(self, jewels: str, stones: str) -> int:
        dick = set(jewels)
        res = 0
        for i in stones:
            if i in dick:
                res += 1
        return res
```
**Идея:** нужно только проверять принадлежность символа к множеству «драгоценностей». Используем `set` и считаем вхождения.
