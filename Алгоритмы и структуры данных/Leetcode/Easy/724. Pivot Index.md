```python
class Solution:
    def pivotIndex(self, nums: List[int]) -> int:
        if not nums:
            return -1
        sm = sum(nums)
        curr = 0
        for x, i in enumerate(nums):
            if curr == (sm - i) / 2:
                return x
            curr += i
        return -1
```
**Основная идея:**

- Pivot index: левая сумма = правая сумма
- Формула: `left_sum = (total_sum - pivot_element) / 2`
- Идем слева направо, накапливая левую сумму
- Проверяем условие перед добавлением текущего элемента
- Time: O(n), Space: O(1)
- Возвращаем первый найденный pivot index
