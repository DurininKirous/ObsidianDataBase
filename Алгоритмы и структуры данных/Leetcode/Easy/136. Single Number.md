```python
class Solution:
    def singleNumber(self, nums: List[int]) -> int:
        res = 0
        for i in nums:
            res ^= i
        return res
```
## Ключевая идея:
**XOR свойства:**
1. `a ^ a = 0` — число XOR себя = 0
2. `a ^ 0 = a` — число XOR с 0 = само число
3. XOR коммутативен: `a ^ b ^ c = c ^ a ^ b`

**Все парные числа обнулятся, останется только уникальное!**
