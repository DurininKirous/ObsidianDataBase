```python
class Solution:
    def gcdOfStrings(self, str1: str, str2: str) -> str:
        # Если нет общего паттерна - порядок конкатенации будет разный
        if str1 + str2 != str2 + str1:
            return ""
        
        # Длина общего делителя = НОД длин
        from math import gcd
        gcd_length = gcd(len(str1), len(str2))
        
        # Возвращаем первые gcd_length символов
        return str1[:gcd_length]
```
### Основная идея:
1. **Проверка существования:** Если `str1 + str2 == str2 + str1` → общий делитель существует
2. **Длина делителя:** НОД длин строк = длина наибольшего делителя
3. **Результат:** Первые `gcd(len(str1), len(str2))` символов
