#sr-due 
```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        count = 0
        while x > 0 or y > 0:
            if (x & 1) != (y & 1):
                count += 1
            x >>= 1
            y >>= 1
        return count

```
### 💡 **Основная идея**
- Сравниваем числа **побитово**.
- `(x & 1)` и `(y & 1)` берут **последний бит** каждого числа.
- Если биты разные → увеличиваем счётчик `count`.
- Затем сдвигаем оба числа вправо (`>>= 1`), чтобы перейти к следующему биту.
- Повторяем, пока не пройдём все биты обоих чисел.

или

```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        return (x ^ y).bit_count()
```
### 💡 **Идея**
Хэммингово расстояние — это количество различающихся бит между двумя числами.  
Если сделать XOR (`x ^ y`), то в нём будут **1** только в позициях, где биты отличаются.  
Остаётся посчитать количество единиц.

### 🧠 **Основная мысль**
> Различающиеся биты = количество единиц в `x ^ y`.
