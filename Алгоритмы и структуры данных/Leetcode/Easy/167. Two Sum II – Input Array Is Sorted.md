```python
class Solution:
    def twoSum(self, numbers: List[int], target: int) -> List[int]:
        nums = {}
        for i in range(len(numbers)):
            if nums.get(target - numbers[i], -1) != -1:
                return [nums.get(target - numbers[i]), i+1]
            else:
                nums[numbers[i]] = i+1
        return []
```
**Идея:**  
Хеш-таблица: для каждого числа проверяем, видели ли уже `target - numbers[i]`. Если да — возвращаем сохранённый индекс и текущий. Индексы в задаче 1-based, поэтому сохраняем `i+1`.
