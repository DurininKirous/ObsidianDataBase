```go
func missingNumber(nums []int) int {
    n := len(nums)
    sum := n * (n + 1) / 2  // формула Гаусса
    for _, val := range nums {
        sum -= val
    }
    return sum
}
```
**Идея:** 
- Сумма чисел 0..n: `n*(n+1)/2` 
- Вычитаем все элементы массива 
- Остаток = пропущенное число

**Сложность:**
- Время: O(n)
- Память: O(1)
**⚠️ Недостаток:** Возможно переполнение при больших n.


```go
func missingNumber(nums []int) int {
    missing := len(nums)
    for i, val := range nums {
        missing ^= i ^ val
    }
    return missing
}
```

**Свойства XOR:**
1. `a ^ a = 0` (число XOR само с собой = 0)
2. `a ^ 0 = a` (число XOR с 0 = само число)
3. XOR коммутативен: `a ^ b ^ c = c ^ a ^ b`

**Как работает:**
```
nums = [3, 0, 1], n = 3

missing = 3

i=0, val=3:
  missing = 3 ^ 0 ^ 3 = 0  // 3 и 3 обнулились

i=1, val=0:
  missing = 0 ^ 1 ^ 0 = 1  // 0 и 0 обнулились

i=2, val=1:
  missing = 1 ^ 2 ^ 1 = 2  // 1 и 1 обнулились

Результат: 2 ✓
```

**Визуализация:**
```
XOR всех индексов и значений:
0 ^ 1 ^ 2 ^ 3 ^ 3 ^ 0 ^ 1
│   │   │   │   └───┴───┴─ значения из массива
└───┴───┴───┴─────────────── индексы (0,1,2) + n (3)

Группируем пары:
= (0^0) ^ (1^1) ^ 2 ^ (3^3)
=   0   ^   0   ^ 2 ^   0
= 2  ← пропущенное число!
```
