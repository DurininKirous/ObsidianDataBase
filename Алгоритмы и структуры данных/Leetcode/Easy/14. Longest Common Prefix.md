func longestCommonPrefix(strs []string) string {
    var res string
    passed := true
    for i, letter := range strs[0] {
        for _, str := range strs {
            if i > len(str)-1 {
                passed = false
                break
            }
            if letter != rune(str[i]) {
                passed = false
                break
            } 
        }
        if passed == false {
            break
        }
        res += string(letter)
    }
    return res
}
## Концепция
- **Строка (`string`)** — неизменяемая последовательность байтов (UTF-8).
- Индексация `s[i]` → `byte`, а не `rune`.  
    → Для ASCII безопасно, для Unicode лучше `[]rune`.
- `range s` → индекс байта + `rune`.

## Алгоритм
1. Берём первую строку как эталон.
2. Идём по символам (байтам/rune).
3. Для каждой позиции проверяем все строки:
    - если индекс вне диапазона → прерываем;
    - если символ отличается → прерываем.
4. Собираем общий префикс.
