```python
class Solution:
    def guessNumber(self, n: int) -> int:
        left, right = 1, n

        while left <= right:
            mid = left + (right - left) // 2
            res = guess(mid)

            if res == 0:
                return mid
            elif res < 0:      # mid > pick
                right = mid - 1
            else:              # mid < pick
                left = mid + 1

        return -1  # не должно случиться

```
### Идея

Классический бинарный поиск по диапазону **[1, n]**:
- Вызываем `guess(mid)`.
- Если ответ:
    - `0` → угадали;
    - `< 0` → число меньше `mid`, сдвигаем `right`;
    - `> 0` → число больше `mid`, сдвигаем `left`.
