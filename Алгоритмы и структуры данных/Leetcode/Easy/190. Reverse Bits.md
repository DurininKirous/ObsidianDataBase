```go
func reverseBits(n uint32) uint32 {
    var res uint32
    for i := 0; i < 32; i++ {
        res = (res << 1) | (n & 1)
        n >>= 1                 
    }
    return res
}
```
## 💡 Основная идея
- Берём число `n` и читаем **младшие биты** по одному.
- Постепенно переносим их в `res`,  
    сдвигая результат **влево** каждый раз на 1 (чтобы освободить место).

То есть “переносим” биты с конца в начало.
