```python
class Solution:
    def largestAltitude(self, gain: List[int]) -> int:
        if not gain:
            return 0
        max_gain = 0
        sm = 0
        for i in gain:
            sm += i
            max_gain = max(max_gain, sm)
        return max_gain
```
**Основная идея:**

- Начинаем с высоты 0
- Используем prefix sum: накапливаем изменения высоты
- На каждом шаге обновляем максимальную высоту
- Time: O(n), Space: O(1)
- Ключевой момент: сравниваем с 0 (начальная высота может быть максимальной)
