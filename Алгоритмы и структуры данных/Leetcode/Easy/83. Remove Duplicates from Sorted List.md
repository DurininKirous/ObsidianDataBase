func deleteDuplicates(head *ListNode) *ListNode {
    dummy := head
    for dummy != nil {
        for dummy.Next != nil && dummy.Next.Val == dummy.Val {
            dummy.Next = dummy.Next.Next
        }
        dummy = dummy.Next
    }
    return head
}
## Алгоритм
- Завести указатель `dummy := head`.
- Пока `dummy` не пустой:
    - Если следующий элемент существует и равен текущему (`dummy.Next.Val == dummy.Val`):
        - пропускаем его: `dummy.Next = dummy.Next.Next`.
    - Иначе — просто двигаем `dummy` дальше.
- Вернуть `head` как результат.
