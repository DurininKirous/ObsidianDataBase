```python
class Solution:
    def fib(self, n: int) -> int:
        a, b = 0, 1
        for i in range(n):
            a, b = b, a + b
        return a
```
### **Основная идея**
- Используем **итеративный подход с двумя переменными**.
- Храним только последние два значения Фибоначчи, чтобы экономить память.
- На каждой итерации сдвигаем значения: `a` ← `b`, `b` ← `a+b`.
- Возвращаем `a` после n итераций — это `F(n)`.
