```python
class Solution:
    def intersect(self, nums1: List[int], nums2: List[int]) -> List[int]:
        dick = dict()
        res = []
        for i in nums1:
            dick[i] = dick.get(i,0) + 1
        for i in nums2:
            if dick.get(i,0) > 0:
                res.append(i)
                dick[i] -= 1
        return res
```
**Идея (частоты):** посчитать частоты по более короткому массиву, затем идти по второму и забирать элементы, пока частота > 0.
