func reverseList(head *ListNode) *ListNode {
    var prev *ListNode = nil
    curr := head
    for curr != nil {
        dummy := curr.Next   // сохранить остаток списка
        curr.Next = prev     // развернуть стрелку
        prev = curr          // продвинуть prev
        curr = dummy         // перейти дальше
    }
    return prev
}

## Алгоритм (итеративный, три указателя)
1. Завести три указателя:
    - `prev = nil` (будущий хвост),
    - `curr = head` (текущий узел),
    - `dummy` (вспомогательный, хранит «следующий»).
2. Пока `curr != nil`:
    - сохранить `dummy = curr.Next` (чтобы не потерять список),
    - развернуть ссылку: `curr.Next = prev`,
    - сдвинуть `prev = curr`,
    - перейти дальше: `curr = dummy`.
3. Вернуть `prev` как новый `head`.
