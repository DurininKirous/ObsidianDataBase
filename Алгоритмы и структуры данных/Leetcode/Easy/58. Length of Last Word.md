# 💡 The What
*О чем задача? Что нужно сделать?*
Given a string with words, return len of last word


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Use split() with string and return len() of [-1] object

**Time Complexity:** O(n)
**Space Complexity:** O(1)

---

## 💻 Code

```python
def lengthOfLastWord(s):
	return len(s.split()[-1])
```
