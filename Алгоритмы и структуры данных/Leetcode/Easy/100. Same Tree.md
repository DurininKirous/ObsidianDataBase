## Идеи решения
- **DFS (рекурсия):** просто и коротко, проверяем узлы рекурсивно.
- **BFS (итеративно с очередью):** можно обрабатывать дерево уровнями, сохраняя пары узлов.

```go
func isSameTree(p *TreeNode, q *TreeNode) bool {
    if p == nil && q == nil {
        return true
    }
    if p == nil || q == nil {
        return false
    }
    if p.Val != q.Val {
        return false
    }
    return isSameTree(p.Left, q.Left) && isSameTree(p.Right, q.Right)
}
```
### Разбор
- База: два `nil` → деревья одинаковые.
- Один `nil`, другой нет → разные.
- Проверяем значения.
- Рекурсивно сравниваем детей.

```go
func isSameTree(p *TreeNode, q *TreeNode) bool {
    queue := [][2]*TreeNode{{p, q}}

    for len(queue) > 0 {
        pair := queue[0]
        queue = queue[1:]
        n1, n2 := pair[0], pair[1]

        if n1 == nil && n2 == nil {
            continue
        }
        if n1 == nil || n2 == nil || n1.Val != n2.Val {
            return false
        }

        queue = append(queue, [2]*TreeNode{n1.Left, n2.Left})
        queue = append(queue, [2]*TreeNode{n1.Right, n2.Right})
    }
    return true
}
```
### Разбор
- Храним пары узлов в очереди.
- Если оба `nil` → пропускаем.
- Если только один `nil` или разные значения → `false`.
- Добавляем детей в очередь парами.
