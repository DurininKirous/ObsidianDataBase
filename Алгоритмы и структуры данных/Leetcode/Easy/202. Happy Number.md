```go
func isHappy(n int) bool {
    sum := 0
    visited := make(map[int]struct{})
    for {
        sum = 0
        num := 0
        for n > 0 {
            num = n % 10
            sum += num * num
            n /= 10
        }
        if sum == 1 {
            return true
        } else {
            if _, exists := visited[sum]; exists {
                return false
            } else {
                visited[sum] = struct{}{}
            }
            n = sum
        }
    }
}
```
## Идея
Итерируем функцию `next(n)` = сумма квадратов цифр.  
Если дошли до `1` — число «счастливое». Если сумма повторилась — образовался цикл → не «счастливое».

## Сложность
- Время: `O(k)` (пока дойдём до `1` или цикла).
- Память: `O(k)` из-за `visited`.
