```python
from collections import deque

class RecentCounter:
    def __init__(self):
        self.q = deque()

    def ping(self, t: int) -> int:
        self.q.append(t)
        bound = t - 3000
        while self.q and self.q[0] < bound:
            self.q.popleft()
        return len(self.q)
```
**Идея**  
Очередь вызовов (монотонно возрастающие `t`). На `ping(t)` добавляем `t` и удаляем из головы все значения `< t-3000`.  
Размер очереди — число вызовов за последние 3000 мс. Амортизированно `O(1)` на операцию.
