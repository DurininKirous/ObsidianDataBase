# 💡 The What
*О чем задача? Что нужно сделать?*
Given two strings `ransomNote` and `magazine`, return `true` _if_ `ransomNote` _can be constructed by using the letters from_ `magazine` _and_ `false` _otherwise_.

Each letter in `magazine` can only be used once in `ransomNote`


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Use hash-table to find at first statistics of all symbols in ransomNote
- Then iterate in managazine and delete from hash-table one symbol per apperance
- If there are symbols at the end with positive values then False, otherwise True

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 💻 Code

```python
res = defaultdict(int)
for i in ransomNote:
	res[i] += 1
for i in magazine:
	res[i] -= 1
for value in res.values():
	if value > 0:
		return False
return True
```
