```go
func minCostClimbingStairs(cost []int) int {
    dp := []int{cost[0], cost[1]}
    for i := 2; i < len(cost); i++ {
        dp = append(dp, min(dp[i-1], dp[i-2]) + cost[i])
    }
    return min(dp[len(dp)-1], dp[len(dp)-2])
}

```
### Основная идея
- Пусть `dp[i]` — минимальная стоимость, чтобы добраться до ступени `i`.
- Можно прийти либо со ступени `i-1`, либо `i-2`.
- Тогда:
    dp[i]=cost[i]+min⁡(dp[i−1],dp[i−2])dp[i] = cost[i] + \min(dp[i-1], dp[i-2])dp[i]=cost[i]+min(dp[i−1],dp[i−2])
- Ответ: минимальная стоимость между последними двумя `dp` (на вершину можно шагнуть с них обоих).
