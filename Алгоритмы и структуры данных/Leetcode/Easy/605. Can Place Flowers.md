```python
class Solution:
    def canPlaceFlowers(self, flowerbed: List[int], n: int) -> bool:
        k = n
        for i, val in enumerate(flowerbed):
            if val == 0 and ((i - 1 < 0 or flowerbed[i - 1] == 0) and (i + 1 >= len(flowerbed) or flowerbed[i+1] == 0) ):   
                k -= 1
                flowerbed[i] = 1
            if k <= 0:
                break
        return k <= 0
```
## Идея решения (жадный алгоритм)

Основная идея — пройтись по клумбе один раз и сажать цветы в каждую доступную ячейку. Это "жадный" подход, потому что мы принимаем локально оптимальное решение (сажаем цветок при первой же возможности), и это приводит к глобально оптимальному результату.
