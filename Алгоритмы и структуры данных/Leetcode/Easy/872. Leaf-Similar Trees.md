# 💡 The What
*О чем задача? Что нужно сделать?*
Даны два дерева, нужно получить список листьев слева-направо для каждого из них и сравнить их с учетом порядка


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем стандартный bfs, добавляем в итоговый массив ноду если это лист. Получится справа-налево вид, но для проверки не имеет значения, относительный порядок сохраняется и так

**Time Complexity:** O(n1+n2)
**Space Complexity:** O(n1+n2)

### Key Insights:
- Порядок обхода не имеет значения, относительный порядок тот же будет, поэтому можно не обдумывать эту часть решения

def fillWithLeaves(root):
	q = [root]
	res = []
	while q:
		node = q.pop()
		if node.left:
			q.append(node.left)
		if node.right:
			q.append(node.right)
		if not node.left and not node.right:
			res.append(node.val)
