func hasCycle(head *ListNode) bool {
    slow := head
    fast := head
    for fast != nil && fast.Next != nil {
        slow = slow.Next
        fast = fast.Next.Next
        if slow == fast {
            return true
        }
    }
    return false
}

## Алгоритм (Floyd’s Cycle Detection)
- Завести два указателя:
    - `slow` — двигается на 1 шаг.
    - `fast` — двигается на 2 шага.
- Пока `fast != nil` и `fast.Next != nil`:
    - сдвигаем `slow` и `fast`.
    - если `slow == fast` → найден цикл.
- Если `fast` дошёл до `nil` → цикла нет.
