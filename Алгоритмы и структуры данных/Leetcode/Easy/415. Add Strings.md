```python
class Solution:
    def addStrings(self, num1: str, num2: str) -> str:
        res = ""
        i = len(num1) - 1
        j = len(num2) - 1
        carry = 0
        while i >= 0 or j >= 0 or carry:
            a = ord(num1[i])-ord("0") if i >= 0 else 0
            b = ord(num2[j])-ord("0") if j >= 0 else 0
            s = a + b + carry
            res = str(s%10) + res
            carry = s // 10
            i -= 1
            j -= 1
        return res
```
**Идея:**  
Сложение в столбик с конца строк. Держим перенос `carry`, на каждом шаге берём по цифре из `num1` и `num2`, складываем, кладём последнюю цифру в результат и обновляем `carry`. Результат собираем слева (или можно было бы в списке и потом развернуть).
