```python
class Solution:
    def findTheDifference(self, s: str, t: str) -> str:
        res = 0
        for ch in s + t:
            res ^= ord(ch)
        return chr(res)
```
### 💡 **Идея**
Вторая строка `t` — это первая строка `s`, но с добавленной одной буквой.  
Если применить побитовое XOR ко всем символам обеих строк, одинаковые буквы «уничтожатся» (`a ^ a = 0`), и останется только добавленная.

### 🧠 **Основная мысль**
> Используем свойство XOR: одинаковые символы обнуляются, разный остаётся.
