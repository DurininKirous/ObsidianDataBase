```python
class Solution:
    def search(self, nums: List[int], target: int) -> int:
        left = 0
        right = len(nums) - 1

        while left <= right:
            middle = left + (right - left) // 2

            if nums[middle] == target:
                return middle

            if nums[middle] > target:
                right = middle - 1
            else:
                left = middle + 1

        return -1
```
**Идея:**
- Классический бинарный поиск по **отсортированному** массиву.
- Держим два указателя: `left` и `right`.
- Пока `left <= right`:
    - берём `middle`,
    - если `nums[middle] == target` → возвращаем индекс,
    - если `nums[middle] > target` → целевое значение слева → сдвигаем `right = middle - 1`,
    - иначе → `left = middle + 1`.
- Если не нашли — возвращаем `-1`.
**Сложность:**  
O(log n) по времени, O(1) по памяти.
