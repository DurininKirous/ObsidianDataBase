```go
func climbStairs(n int) int {
    a, b := 0, 1 // F(0)=0, F(1)=1
    for i := 0; i < n; i++ {
        a, b = b, a+b
    }
    return b // = F(n+1)
}
```

### Идея
Чтобы попасть на ступеньку `n`,  
можно сделать шаг:
- с `n−1` (шаг на 1),
- или с `n−2` (шаг на 2).

Следовательно:
ways(n)=ways(n−1)+ways(n−2)ways(n)=ways(n-1)+ways(n-2)ways(n)=ways(n−1)+ways(n−2)
Базовые случаи:
- `ways(1)=1`
- `ways(2)=2`

Это **последовательность Фибоначчи**, только сдвинутая на 1:
ways(n)=Fn+1ways(n)=F_{n+1}ways(n)=Fn+1​
