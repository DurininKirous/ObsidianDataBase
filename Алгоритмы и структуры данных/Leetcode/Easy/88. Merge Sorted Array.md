```go
// Слияние nums1[:m] и nums2[:n] в nums1 (длина nums1 = m+n)
func merge(nums1 []int, m int, nums2 []int, n int) {
    i := m - 1
    j := n - 1
    k := m + n - 1
    for j >= 0 {
        if i >= 0 && nums1[i] > nums2[j] {
            nums1[k] = nums1[i]
            i--
        } else {
            nums1[k] = nums2[j]
            j--
        }
        k--
    }
}
```
## Идея
- Идём **с конца** трёмя индексами `i, j, k`.
- Кладём **больший** из хвостов в `nums1[k]`.
- Нет сдвигов массива ⇒ `O(m+n)`.

## Краевые случаи
- `n == 0` → ничего не делаем.
- `m == 0` → весь `nums2` перепишется в `nums1`.
- Повторы/равные значения — порядок не критичен.

## Частые ошибки
- Идти «вперёд» и сдвигать массив (квадратично).
- Неверные стартовые индексы `i, j, k`.
- Цикл с условием `i >= 0 || j >= 0` без аккуратных проверок.
