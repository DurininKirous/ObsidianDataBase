```python
class Solution:
    def diagonalSum(self, mat: List[List[int]]) -> int:
        n = len(mat)
        res = 0
        for i in range(n):
            res += mat[i][i] + mat[i][n - 1 - i]
        if n % 2 == 1:
            res -= mat[n // 2][n // 2]
        return res
```
**Идея:**  
обе диагонали в одном цикле, потом вычесть центральный элемент, если размер нечётный.
