```python
class Solution:
    def sortedSquares(self, nums: List[int]) -> List[int]:
        n = len(nums)
        res = [0] * n
        l, r, k = 0, n - 1, n - 1
        while l <= r:
            left, right = abs(nums[l]), abs(nums[r])
            if left > right:
                res[k] = left * left
                l += 1
            else:
                res[k] = right * right
                r -= 1
            k -= 1
        return res
```
**Идея:**  
Массив уже отсортирован. Наибольший по модулю элемент всегда на одном из концов.  
Два указателя `l` и `r`, заполняем новый массив с конца (`k` от `n-1` до `0`), каждый раз берём больший по модулю из `nums[l]` и `nums[r]`, возводим в квадрат и кладём в `res[k]`.
