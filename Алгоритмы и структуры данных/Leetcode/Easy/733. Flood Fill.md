```go
func Fill(image *[][]int, sr int, sc int, color int, originColor int) {
    if sr < 0 || sr >= len(*image) || sc < 0 || sc >= len((*image)[sr]) {
        return
    }
    if (*image)[sr][sc] != originColor || (*image)[sr][sc] == color {
        return
    }

    (*image)[sr][sc] = color

    Fill(image, sr+1, sc, color, originColor)
    Fill(image, sr-1, sc, color, originColor)
    Fill(image, sr, sc+1, color, originColor)
    Fill(image, sr, sc-1, color, originColor)
}

func floodFill(image [][]int, sr int, sc int, color int) [][]int {
    originColor := image[sr][sc]
    Fill(&image, sr, sc, color, originColor)
    return image
}
```
## Идея

Flood Fill — это алгоритм "заливки области" (аналог инструмента "заливка" в Paint).  
Задача: начиная с пикселя `(sr, sc)`, закрасить все смежные (по 4 сторонам) пиксели того же цвета новым `color`.
### Алгоритм (DFS):
1. Запоминаем исходный цвет `originColor = image[sr][sc]`.
2. Запускаем рекурсивную функцию `Fill`:
    - если вышли за границы → остановка;
    - если цвет не равен `originColor` или уже перекрашен → остановка;
    - иначе перекрашиваем текущий пиксель в `color` и идём в 4 стороны.
3. Возвращаем итоговую матрицу.
