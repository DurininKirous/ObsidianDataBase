```python
class MyHashMap:

    def __init__(self):
        self.size = 2069
        self.buckets = [[] for _ in range(self.size)]
    
    def _hash(self, key: int) -> int:
        return key % self.size

    def put(self, key: int, value: int) -> None:
        b = self.buckets[self._hash(key)]
        for pair in b:
            if pair[0] == key:
                pair[1] = value
                return
        b.append([key, value])

    def get(self, key: int) -> int:
        b = self.buckets[self._hash(key)]
        for k, v in b:
            if k == key:
                return v
        return -1

    def remove(self, key: int) -> None:
        b = self.buckets[self._hash(key)]
        for i, (k, _) in enumerate(b):
            if k == key:
                b.pop(i)
                return
```
## Основная идея
- Структура: массив `buckets` из `size` бакетов; каждый бакет — список пар `[key, value]` (separate chaining).
- Хеш-функция: `_hash(key) = key % size`.
- Операции:
    - **put**: ищем ключ в своём бакете → обновляем значение, иначе добавляем новую пару.
    - **get**: ищем ключ в бакете → возвращаем значение или `-1`, если нет.
    - **remove**: находим ключ в бакете и удаляем элемент по индексу.
- Инварианты: один ключ ↔ одно значение; в одном бакете могут лежать **разные** ключи (коллизии).
- Сложность: амортизированно `O(1)` на операции; худший случай — `O(L)`, где `L` — длина цепочки в бакете.
- Нюансы/улучшения:
    - Выбор простого `size` (2069) для лучшего распределения.
    - При росте нагрузки можно добавить **rehash** (увеличение `size` и перераспределение элементов).
