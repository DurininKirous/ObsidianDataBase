# 💡 The What
*О чем задача? Что нужно сделать?*
Дан массив элементов, нужно найти число, которое встречается в массиве более [n/2] раз


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- We will hold variables current and count. The first one represents current voting number, the second one represents number of votes to this number. 
- We will get at the end in current var majority number because it appears more than the half of other elements in array

**Time Complexity:** O(n)
**Space Complexity:** O(1)

---

## 💻 Code

```python
current = None
count = 0
for num in nums:
	if count == 0:
		current = num
	count += (1 if num == candidate else -1)
	
return current
```
