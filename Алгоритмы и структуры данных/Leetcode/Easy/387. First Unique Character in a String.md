```python
class Solution:
    def firstUniqChar(self, s: str) -> int:
        chars = {}
        for i in s:
            chars[i] = chars.get(i,0) + 1
        for i in range(len(s)):
            if chars[s[i]] == 1:
                return i
        return -1
```
**Идея:**  
Сначала один проход — считаем частоты символов. Второй проход — находим первый индекс, где частота == 1. Если такого нет — возвращаем -1.
