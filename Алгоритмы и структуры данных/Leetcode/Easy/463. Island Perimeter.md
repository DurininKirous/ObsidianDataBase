# 💡 The What
*О чем задача? Что нужно сделать?*

You are given `row x col` `grid` representing a map where `grid[i][j] = 1` represents land and `grid[i][j] = 0` represents water.

Grid cells are connected **horizontally/vertically** (not diagonally). The `grid` is completely surrounded by water, and there is exactly one island (i.e., one or more connected land cells).

The island doesn't have "lakes", meaning the water inside isn't connected to the water around the island. One cell is a square with side length 1. The grid is rectangular, width and height don't exceed 100. Determine the perimeter of the island.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- У каждой клетки 4 стороны, когда мы попадаем на 1, если хотя бы одна соседняя клетка не 1, то это граничная клетка -> +1 к периметру. и так надо обойти весь стров

**Time Complexity:** O(n\*m)
**Space Complexity:** O(1)

### Algorithm:
1. Проходим по каждой клетке матрицы.
2. Если клетка = `1`, то у неё есть максимум 4 стороны.
3. Для каждой из сторон проверяем:
    - если сосед вне границ матрицы **или** сосед равен `0` → это часть периметра.
4. Суммируем все такие стороны.

## 💻 Code

```go
func islandPerimeter(grid [][]int) int {
    num := 0
    rows, cols := len(grid), len(grid[0])

    for i := 0; i < rows; i++ {
        for j := 0; j < cols; j++ {
            if grid[i][j] == 1 {
                // верх
                if i-1 < 0 || grid[i-1][j] == 0 {
                    num++
                }
                // низ
                if i+1 >= rows || grid[i+1][j] == 0 {
                    num++
                }
                // лево
                if j-1 < 0 || grid[i][j-1] == 0 {
                    num++
                }
                // право
                if j+1 >= cols || grid[i][j+1] == 0 {
                    num++
                }
            }
        }
    }
    return num
}
```
