```go
func islandPerimeter(grid [][]int) int {
    num := 0
    rows, cols := len(grid), len(grid[0])

    for i := 0; i < rows; i++ {
        for j := 0; j < cols; j++ {
            if grid[i][j] == 1 {
                // верх
                if i-1 < 0 || grid[i-1][j] == 0 {
                    num++
                }
                // низ
                if i+1 >= rows || grid[i+1][j] == 0 {
                    num++
                }
                // лево
                if j-1 < 0 || grid[i][j-1] == 0 {
                    num++
                }
                // право
                if j+1 >= cols || grid[i][j+1] == 0 {
                    num++
                }
            }
        }
    }
    return num
}
```
## Идея
Дан двумерный массив `grid`, где:
- `1` = суша
- `0` = вода
Нужно найти периметр острова.
### Алгоритм
1. Проходим по каждой клетке матрицы.
2. Если клетка = `1`, то у неё есть максимум 4 стороны.
3. Для каждой из сторон проверяем:
    - если сосед вне границ матрицы **или** сосед равен `0` → это часть периметра.
4. Суммируем все такие стороны.
