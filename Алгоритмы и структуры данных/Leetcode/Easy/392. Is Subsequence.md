```python
class Solution:
    def isSubsequence(self, s: str, t: str) -> bool:
        if len(s) > len(t):
            return False
        k = 0
        for i in t:
            if k < len(s) and i == s[k]:
                k += 1
            if len(s) == k:
                break
        return k == len(s) 
```
**Идея:**  
Два указателя: идём по `t` и пытаемся последовательно «собрать» `s`.  
Храним индекс `k` в `s`. Когда символ `t` совпадает с `s[k]`, двигаем `k`.  
Если смогли довести `k` до `len(s)`, значит `s` — подпоследовательность `t`.
