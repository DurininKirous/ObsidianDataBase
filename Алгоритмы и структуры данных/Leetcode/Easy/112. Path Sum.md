```go
func hasPathSum(root *TreeNode, targetSum int) bool {
    if root == nil {
        return false
    }
    // если это лист — проверяем, совпадает ли значение
    if root.Left == nil && root.Right == nil {
        return root.Val == targetSum
    }
    // рекурсия: уменьшаем targetSum на текущий узел
    return hasPathSum(root.Left, targetSum-root.Val) || 
           hasPathSum(root.Right, targetSum-root.Val)
}
```
## 🧠 Идея решения
- На каждом шаге рекурсии вычитаем из `targetSum` текущее значение узла.
- Когда доходим до листа:
    - если `node.Val == targetSum` → нашли путь → `true`;
    - иначе → `false`.
- Если не лист → рекурсивно идём влево и вправо.
