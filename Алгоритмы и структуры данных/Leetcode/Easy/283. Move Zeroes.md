```python
def moveZeroes(nums):
    k = 0
    for i in range(len(nums)):
        if nums[i] != 0:
            if k != i:
                nums[k] = nums[i]
                nums[i] = 0
            k += 1
```
## Идея
- `k` — позиция для следующего ненулевого элемента.
- Идём слева направо: переносим ненулевые в начало, их старые позиции обнуляем.
- Стабильность по ненулевым сохраняется, доп.память не нужна.
