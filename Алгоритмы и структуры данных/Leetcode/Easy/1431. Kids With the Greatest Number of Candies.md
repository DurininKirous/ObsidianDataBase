```python
class Solution:
    def kidsWithCandies(self, candies: List[int], extraCandies: int) -> List[bool]:
        if not candies:
            return []
        
        max_candies = candies[0]
        for i in candies:
            max_candies = max(i, max_candies)
        
        res = []
        for i in candies:
            if i + extraCandies >= max_candies:
                res.append(True)
            else:
                res.append(False)
        
        return res
```
Алгоритм 
1. Найти максимальное количество конфет среди всех детей 
2. Для каждого ребёнка проверить: его конфеты + extra ≥ максимум? 
3. Вернуть список результатов
