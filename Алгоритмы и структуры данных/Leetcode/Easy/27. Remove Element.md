func removeElement(nums []int, val int) int {
    k := 0
    for _, x := range nums {
        if x != val {
            nums[k] = x
            k++
        }
    }
    return k
}
## Алгоритм
1. Заводим индекс `k := 0` — куда будем писать «разрешённые» элементы.
2. Проходим по массиву:
    - Если `nums[i] != val` → переписываем его на `nums[k]`, увеличиваем `k`.
    - Если равно `val` → пропускаем.
3. Возвращаем `k` — новую длину массива без `val`.
## Ключевые моменты
- **Работаем in-place** — элементы переписываются в начале массива.
- **Не нужно удалять элементы** — важно только вернуть длину `k`.
- Элементы после `k` могут быть любыми — LeetCode их не проверяет.
- **Сложность:** O(n) по времени, O(1) по памяти.
