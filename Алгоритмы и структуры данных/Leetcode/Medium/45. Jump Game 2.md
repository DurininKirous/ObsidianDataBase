# 💡 The What
*О чем задача? Что нужно сделать?*

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return minimum number of jumps you have to do to achieve n-1 index.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Жадно поддерживаем самый дальний **достижимый** индекс `farthest`

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Algorithm:
Идём слева направо:
- обновляем `farthest = max(farthest, i + nums[i])`;
- смотрим, до какого максимального индекса можем добраться без доп прыжков
- если `farthest >= n-1` → можно добраться до конца → `return count`.
---

## 💻 Code

```python
class Solution:  
	def jump(self, nums: List[int]) -> int:  
		count = 0  
		farthest = 0  
		current_end = 0  
		last = len(nums) - 1  
		for i in range(len(nums)-1):  
			farthest = max(farthest, i + nums[i])  
			if i == current_end:  
				count += 1  
			current_end = farthest  
			if current_end >= last:  
				break  
		return count
```
