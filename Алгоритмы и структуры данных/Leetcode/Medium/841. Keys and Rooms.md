# 💡 The What
*О чем задача? Что нужно сделать?*
Дан двумерный массив, каждый массив представляешь собой дверь, значения внутри массива - ключи в другие двери. Нужно определить, можно ли попасть из первой двери во все остальные двери

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Идем в первую дверь и рекурсией ходим во все остальные двери

**Time Complexity:** O(N + E)
**Space Complexity:** O(N)

### Algorithm:
1. Попали в дверь, в которой уже были - возвращаем False
2. Возвращаем true, если размер seen равен количеству дверей
3. Итерируемся по всем ключам в текущей двери, вызываем следующую рекурсию для каждой следующей двери
---

## 💻 Code

```python
def visit(rooms, seen, curr):
	if curr in seen:
		return False
	seen[curr]=1
	if len(seen)==len(rooms):
		return True
	res = False
	for i in rooms[curr]:
		res |= visit(rooms, seen, i)
	return res
```
