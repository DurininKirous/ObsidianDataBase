```python
class Solution:
    def maxVowels(self, s: str, k: int) -> int:
        if len(s) < k:
            return 0
        vow = {'a', 'e', 'i', 'o', 'u'}
        curr = 0
        
        for i in range(k):
            if s[i] in vow:
                curr += 1
        max_vow = curr
        
        # Скользящее окно
        for i in range(k, len(s)):
            if s[i] in vow: 
                curr += 1
            if s[i-k] in vow:
                curr -= 1
            max_vow = max(max_vow, curr)
        
        return max_vow
```
**Идея:**
- **Sliding Window фиксированного размера k**
- Считаем гласные в первом окне
- Двигаем окно: +1 если новый символ гласная, -1 если ушедший символ гласная
- Отслеживаем максимум
**Сложность:**
- Time: O(n) — один проход
- Space: O(1) — константа для set
