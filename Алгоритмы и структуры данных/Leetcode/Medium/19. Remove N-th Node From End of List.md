# 💡 The What
*О чем задача? Что нужно сделать?*
Given the `head` of a linked list, remove the `nth` node from the end of the list and return its head

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Проходим список один раз, считаем его длину. Потом во второй раз обрубаем N-тую ноду. 

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Algorithm:
1. Создать фиктивный узел (`dummy`), указывающий на `head`.
2. Пройти список и посчитать длину.
3. Пройти ещё раз до узла **перед тем, что нужно удалить**.
4. Удалить его: `curr.Next = curr.Next.Next`.
5. Вернуть `dummy.Next`.
---

## 💻 Code

```go
func removeNthFromEnd(head *ListNode, n int) *ListNode {
    dummy := &ListNode{Next: head}
    lenList := 0
    curr := dummy

    // считаем длину
    for curr != nil {
        lenList++
        curr = curr.Next
    }

    // доходим до узла перед удаляемым
    curr = dummy
    for i := 0; i < lenList-n-1; i++ {
        curr = curr.Next
    }

    // удаляем
    curr.Next = curr.Next.Next

    return dummy.Next
}
```

## ⚔️ VS / Trade-offs

_Альтернативные подходы. Плюсы/Минусы._
- **Trade-off:** Проходим два раза список. Возможно есть однопроходный вариант решения, я его не искал
