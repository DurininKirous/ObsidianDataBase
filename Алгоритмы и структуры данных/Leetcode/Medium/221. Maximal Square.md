```go
func maximalSquare(matrix [][]byte) int {
    dp := make([][]int, len(matrix))
    maxSide := 0
    for i := range dp {
        dp[i] = make([]int, len(matrix[0]))
    }
    for i := 0; i < len(matrix); i++ {
        for j := 0; j < len(matrix[0]) ; j++ {
            if matrix[i][j] == '1' {
                if i == 0 || j == 0 {
                    dp[i][j] = 1
                } else {
                   dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])+1         
                }
            }
            maxSide = max(maxSide, dp[i][j])
        }
    }
    return maxSide * maxSide
}
```
**Основная идея:**
- Динамическое программирование
- `dp[i][j]` = максимальная сторона квадрата с правым нижним углом в позиции `(i, j)`
- Если `matrix[i][j] == '1'`:
    - Если первая строка или столбец: `dp[i][j] = 1`
    - Иначе: `dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1`
- Формула работает, потому что для квадрата нужно, чтобы сверху, слева и по диагонали тоже были квадраты

**Сложность:** O(m × n)
