```python
n = len(seats)
prev = -1
ans = 0
for i, x in enumerate(seats):
	if x == 1:
		if prev == -1:
			ans = max(ans, i)
		else:
			ans = max(ans, (i - prev) // 2)
		prev = i
if prev != -1:
	ans = max(ans, n - 1 - prev)    
return ans
```
# Короткий конспект (идея)
- В массиве есть три вида «пустот» из нулей:
    1. **Префикс** до первой `1` → расстояние = длина префикса.
    2. **Между двумя `1`** → садимся посередине → расстояние = половина промежутка (целая часть).
    3. **Суффикс** после последней `1` → расстояние = длина суффикса.
- Один линейный проход: держим индекс последней `1` (`prev`), на каждой новой `1` обновляем ответ для случая (2); отдельно учитываем (1) и (3).
- Сложность: **O(n)** по времени, **O(1)** по памяти.
