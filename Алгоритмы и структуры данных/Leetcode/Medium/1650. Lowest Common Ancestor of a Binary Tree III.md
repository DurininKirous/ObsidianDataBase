```python
class Node:
    def __init__(self, val):
        self.val = val
        self.left = None
        self.right = None
        self.parent = None

def func(p, q):
    seen = set()
    while p or q:
        if p:
            if p in seen:
                return p
            else:
                seen.add(p)
                p = p.parent
        if q:
            if q in seen:
                return q
            else:
                seen.add(q)
                q = q.parent
    return None
```
**Идея:**  
Поднимаемся вверх от `p`, кладём всех предков в множество. Потом поднимаемся вверх от `q`: первый узел, который уже есть в множестве, и есть LCA. Если ничего не нашли (в теории) — возвращаем `None`.
