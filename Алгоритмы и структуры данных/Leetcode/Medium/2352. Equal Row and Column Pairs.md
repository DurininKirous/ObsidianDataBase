```python
from collections import defaultdict

class Solution:
    def equalPairs(self, grid: List[List[int]]) -> int:
        # 1. Считаем частоту каждой строки
        rows = defaultdict(int)
        for i in range(len(grid)):
            # list нельзя использовать как ключ словаря, приводим к tuple
            rows[tuple(grid[i])] += 1
            
        k = 0
        # 2. Транспонируем матрицу "на месте" (меняем строки и столбцы местами)
        for i in range(len(grid)):
            for j in range(i, len(grid[0])):
                grid[i][j], grid[j][i] = grid[j][i], grid[i][j]
                
        # 3. Теперь grid[i] — это бывшие столбцы. Проверяем их совпадения со строками
        for i in range(len(grid)):
            key = tuple(grid[i])
            if key in rows:
                k += rows[key]
        return k
```
**Идея:**
1. **Частотный словарь:** Используем `defaultdict` (или хеш-таблицу), чтобы запомнить, сколько раз встречается каждая строка. Обычный `set` не подходит, так как нужно учитывать дубликаты для подсчета всех пар.
2. **Приведение типов:** Списки в Python нехешируемы (изменяемы), поэтому перед сохранением в словарь конвертируем их в `tuple`.
3. **In-place Transpose:** Чтобы получить столбцы, физически разворачиваем матрицу относительно диагонали. Это позволяет не выделять память под новый массив для столбцов.
4. **Подсчет:** После разворота проходим по "новым" строкам (которые являются исходными столбцами) и суммируем их количество из словаря `rows`.
