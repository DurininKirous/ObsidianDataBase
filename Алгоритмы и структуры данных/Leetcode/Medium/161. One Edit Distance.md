```python
def dist(s, t):
    if len(s) > len(t):
        s, t = t, s
    a = b = diff = 0
    while a < len(s) and b < len(t):
        if s[a] != t[b]:
            diff += 1
            if diff > 1:
                return False
            if len(s) < len(t):
                b += 1
                continue
        a += 1
        b += 1
    if b < len(t):
        diff += 1
    return diff == 1
```
### 💡 Основная идея
1. Всего возможны **три типа правки**:
    - 🔤 **замена** (пример: `ab → ac`)
    - ➕ **вставка** (пример: `ab → acb`)
    - ➖ **удаление** (пример: `abc → ac`)
2. Если длины строк отличаются больше чем на 1 → сразу `False`.
3. Сравниваем символы по порядку:
    - при несовпадении увеличиваем счётчик различий;
    - если строка короче — пропускаем один символ в длинной;
    - если длины равны — просто идём дальше (замена).
4. Если различий больше одного → `False`.
5. Если одно → `True`.
