```python
def rand10():
    while True:
        row = rand7()
        col = rand7()
        num = (row - 1) * 7 + col  # 1..49
        if num <= 40:
            return (num - 1) % 10 + 1
```
**Идея**: Rejection sampling. Генерим 1-49, берем только 1-40 (делится на 10), остальное reject. `(num-1)%10+1` дает 1-10.
