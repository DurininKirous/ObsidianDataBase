```python
class Solution:
    def spiralOrder(self, matrix: List[List[int]]) -> List[int]:
        i, j = 0, 0
        n = 0
        wall_down = len(matrix)
        wall_right = len(matrix[0])
        wall_left = 0
        wall_up = 0
        out = []
        while n != len(matrix)*len(matrix[0]):
            while j < wall_right and n < len(matrix)*len(matrix[0]):
                out.append(matrix[i][j])
                j+=1
                n += 1
            j -= 1
            i += 1
            wall_up += 1
            while i < wall_down and n < len(matrix)*len(matrix[0]):
                out.append(matrix[i][j])
                i += 1
                n += 1
            j -= 1
            i -= 1
            wall_right -= 1

            while j >= wall_left and n < len(matrix)*len(matrix[0]):
                out.append(matrix[i][j])
                j -= 1
                n += 1
            wall_down -= 1
            
            j += 1
            i -= 1
            while i >= wall_up and n < len(matrix)*len(matrix[0]):
                out.append(matrix[i][j])
                i -= 1
                n += 1
            wall_left += 1
            j += 1
            i += 1
        return out
```
## Идея
Проходим матрицу «слоями» по периметру: вправо → вниз → влево → вверх, после каждого прохода **сжимаем границы** (`top/wall_up`, `bottom/wall_down`, `left/wall_left`, `right/wall_right`).  
Чтобы не выйти за границы и не продублировать элементы, ведём счётчик уже добавленных ячеек `n` и сравниваем с `total = m*n`.

## Шаги алгоритма
1. **Вправо:** фиксируем текущую верхнюю строку `i`, идём `j = left..right-1`. Затем `wall_up += 1`, старт для следующей фазы — `i += 1`, `j -= 1`.
2. **Вниз:** фиксируем текущий правый столбец `j`, идём `i = top..bottom-1`. Затем `wall_right -= 1`, подвигаем `i -= 1`, `j -= 1`.
3. **Влево:** фиксируем текущую нижнюю строку `i`, идём `j = right..left`. Затем `wall_down -= 1`, подвигаем `j += 1`, `i -= 1`.
4. **Вверх:** фиксируем текущий левый столбец `j`, идём `i = bottom..top`. Затем `wall_left += 1`, подвигаем `i += 1`, `j += 1`.

Во всех четырёх фазах добавляем элементы в `out` и инкрементим `n`. Цикл продолжаем, пока `n < total`.
