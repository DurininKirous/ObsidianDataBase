```go
func findMin(nums []int) int {
    lo, hi := 0, len(nums)-1
    for lo < hi {
        if nums[lo] < nums[hi] {
            return nums[lo] // уже отсортирован
        }
        mid := lo + (hi-lo)/2
        if nums[mid] > nums[hi] {
            lo = mid + 1
        } else {
            hi = mid
        }
    }
    return nums[lo]
}
```
**Идея:**  
Сравниваем середину с **правым концом** и сужаем диапазон к стороне минимума.
- Если массив уже отсортирован ( `nums[lo] < nums[hi]` ) → минимум `nums[lo]`.
- Иначе:
    - `nums[mid] > nums[hi]` → минимум справа: `lo = mid + 1`
    - `nums[mid] < nums[hi]` → минимум слева/включая mid: `hi = mid`
