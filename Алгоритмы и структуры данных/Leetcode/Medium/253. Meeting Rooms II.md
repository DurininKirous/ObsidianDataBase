```python
def rooms(meet):
    if not meet:
        return 0
    starts = sorted(s for s, _ in meet)
    ends   = sorted(e for _, e in meet)
    i = j = used = ans = 0
    while i < len(starts):
        if starts[i] < ends[j]:      # начало раньше ближайшего конца → нужна новая комната
            used += 1
            ans = max(ans, used)
            i += 1
        else:                        # есть окончание → освобождаем комнату
            used -= 1
            j += 1
    return ans
```
## Идея
- Разделяем интервалы на два списка: все **начала** (`starts`) и все **окончания** (`ends`), сортируем оба.
- Держим два индекса `i` и `j` и счётчик занятых комнат `used`.
- На каждом шаге сравниваем ближайшие события:
    - Если `starts[i] < ends[j]`, новая встреча начинается **до** ближайшего конца → `used += 1`.
    - Иначе (включая `==`) — какая-то встреча закончилась → `used -= 1`.
- Поддерживаем максимум `ans = max(ans, used)` — это число требуемых комнат.
- Почему строго `<`: при равенстве начало в момент окончания не конфликтует — комнату можно переиспользовать.
