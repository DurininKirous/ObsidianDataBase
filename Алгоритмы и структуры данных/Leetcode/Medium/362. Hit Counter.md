```python
import bisect

class HitCounter:
    def __init__(self):
        self.t = []

    def hit(self, timestamp: int) -> None:
        self.t.append(timestamp)  # монотонность гарантирует порядок

    def getHits(self, timestamp: int) -> int:
        L = timestamp - 299
        left = bisect.bisect_left(self.t, L)
        right = bisect.bisect_right(self.t, timestamp)
        return right - left
```
**Идея:** хранить **все timestamps** (они уже отсортированы); для окна [L, R] взять:
- `left = bisect_left(t, L)` — первый индекс с `>= L`
- `right = bisect_right(t, R)` — первый индекс с `> R`
- ответ = `right - left`
