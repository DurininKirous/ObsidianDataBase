```python
from collections import deque
class Solution:
    def rangeSumBST(self, root: Optional[TreeNode], low: int, high: int) -> int:
        q = deque()
        q.append(root)
        res = 0
        while q:
            node = q.popleft()
            if low <= node.val <= high:
                res += node.val
            if node.left and node.val > low:
                q.append(node.left)

            if node.right and node.val < high:
                q.append(node.right)
        return res
```
**Идея:**  
Делаем BFS по дереву через очередь (`deque`).  
Используем свойство BST, чтобы не ходить в лишние ветки:

- если `node.val > low`, то слева **могут** быть значения в диапазоне → идём в `left`;
    
- если `node.val < high`, то справа **могут** быть значения в диапазоне → идём в `right`;
    
- если `low <= node.val <= high`, добавляем `node.val` в сумму.
