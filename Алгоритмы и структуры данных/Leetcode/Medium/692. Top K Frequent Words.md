```python
from collections import defaultdict

class Solution:
    def topKFrequent(self, words: List[str], k: int) -> List[str]:
        freq = defaultdict(int)
        for w in words:
            freq[w] += 1

        words_unique = list(freq.keys())
        words_unique.sort(key=lambda w: (-freq[w], w))
        return words_unique[:k]
```
**Идея:**  
считаем частоты, сортируем уникальные слова по ключу `(-freq, word)`, берём первые k.
