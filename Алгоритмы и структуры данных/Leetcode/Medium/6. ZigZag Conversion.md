# 💡 The What
*О чем задача? Что нужно сделать?*
The string `"PAYPALISHIRING"` is written in a zigzag pattern on a given number of rows like this: (you may want to display this pattern in a fixed font for better legibility)

P   A   H   N
A P L S I I G
Y   I   R

And then read line by line: `"PAHNAPLSIIGYIR"`

Write the code that will take a string and make this conversion given a number of rows:

string convert(string s, int numRows);


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Make numRows empty strings in array - that's result strings
- Iterate by symbols in string, change row val it from zero to numRows, then numRows to zero and so on, that's position of symbol by row
- Add all symbols to it's row and return join of this strings 

**Time Complexity:** O(n)
**Space Complexity:** O(numRows)

---

## 💻 Code

```python
def convert(self, s: str, numRows: int) -> str:
        if numRows == 1:
            return s
        res = [""] * numRows
        row = 0
        direction = 1
        for i in s:
            res[row] += i
            row += direction
            if row == numRows - 1 or row == 0:
                direction *= -1
        return "".join(res)
```
