# 💡 The What
*О чем задача? Что нужно сделать?*
Дан связный список четной длины, нужно найти максимальную сумму пар близнецов: для i ноды её близнец - n - i -1 нода
Пример: список 1 2 4 5, набор пар: 1 5, 2 4 


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Проходим до середины, реверсим вторую половину, потом проходимся до каждой половины и ищем максимум

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Key Insights:
- Пары по концам -> с большой вероятностью реверс
### Algorithm:
1. Создаем fast и slow итератор, находим середину, fast с двумя шагами ходит, slow с одним
2. Реверсим вторую половину списка ([[206. Reverse Linked List]])
3. Проходимся одновременно по реверснотому списку и первой половине списка изначального, собираем суммы пар

## 💻 Code

```python
def pairSum(self, root: Optional[ListNode]) -> int:
	slow = head
	fast = head
	while fast and fast.next:
		slow = slow.next
		fast = fast.next.next
	prev = None		
	while slow:
		next = slow.next
		slow.next = prev
		prev = slow
		slow = next
	fast = head

	max_sum = 0
	while prev:
		max_sum = max(max_sum, fast.val + prev.val)
		fast = fast.next
		prev = prev.next	
	return max_sum	
```
