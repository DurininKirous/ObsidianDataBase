```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        maxSum = 0
        minCurr = prices[0]
        maxCurr = prices[0]
        for i in range(1, len(prices)):
            if prices[i] < minCurr or prices[i] < maxCurr:
                maxSum += maxCurr - minCurr
                minCurr = prices[i]
                maxCurr = prices[i]
            elif prices[i] > maxCurr:
                maxCurr = prices[i]
        maxSum += maxCurr - minCurr
        return maxSum
```
### 💡 Идея

Можно совершать неограниченное число сделок.  
Нужно суммировать **все положительные разницы** между соседними днями.  
Эквивалентно: покупать в начале каждого роста и продавать в его конце.
### 🧩 Алгоритм
1. Инициализировать прибыль = 0.
2. Для каждой пары соседних дней:
    - если `prices[i] > prices[i-1]` → добавить разницу к прибыли.
3. Вернуть сумму.
