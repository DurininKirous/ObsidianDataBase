# 💡 The What
*О чем задача? Что нужно сделать?*
Дано бинарное дерево, нужно найти минимальный по номеру уровень с максимальной суммой всех нод


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем BFS и очередь, собираем сумму на каждом уровне и сравниваем с максимумом

**Time Complexity:** O(n)
**Space Complexity:** O(h)

---

## 💻 Code

```python
from collections import deque  
  
class Solution:  
def maxLevelSum(self, root: Optional[TreeNode]) -> int:  
	if not root:  
		return 0  
	  
	max_level = 1  
	max_sum = root.val  
	q = deque([root])  
	level = 1  
	  
	while q:  
		n = len(q)  
		level_sum = 0  
		  
		for i in range(n):  
			node = q.popleft()  
			level_sum += node.val  
			if node.left:  
				q.append(node.left)  
			if node.right:  
				q.append(node.right)  
	  
	if level_sum > max_sum:  
		max_sum = level_sum  
		max_level = level  
	  
	level += 1  
  
	return max_level
```
