# 💡 The What
*О чем задача? Что нужно сделать?*
Дан сенат Dota2 из двух партий (Radiant 'R' и Dire 'D'). Сенаторы голосуют раундами в порядке очереди. Каждый может либо забанить другого сенатора (лишить прав во всех раундах), либо объявить победу (если остались только союзники). Все играют оптимально. Нужно предсказать, какая партия победит.


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Cимулируем раунды голосования с помощью двух очередей

**Time Complexity:** O(n)
**Space Complexity:** O(n)

### Key Insights:
- **Оптимальная стратегия:** Банить ближайшего противника, который **еще не сходил** в текущем раунде (т.е. идет после тебя)
- **Почему?** Если забанить того, кто уже сходил - он уже использовал свой голос. Если забанить того, кто не сходил - предотвращаем его действие
- **Циклическая природа:** После каждого раунда сенаторы, которые выжили, переходят в следующий раунд
- **Индексы решают:** Кто ходит раньше (меньший индекс) - тот и банит
### Algorithm:
 - **Инициализация:** Создаем две очереди (deque) для R и D сенаторов, заполняем их индексами из исходной строки
- **Симуляция раундов:** Пока обе очереди не пусты:
    - Извлекаем первого сенатора из каждой очереди
    - Сравниваем их индексы: у кого меньше - тот ходит первым и банит другого
    - Победитель возвращается в свою очередь с индексом `+n` (для следующего раунда)
- **Определение победителя:** Какая очередь осталась непустой - та партия и победила 
---

## 💻 Code

```python
def predictPartyVictory(senate: str) -> str:
    from collections import deque
    
    # Очереди с индексами сенаторов каждой партии
    radiant = deque()
    dire = deque()
    n = len(senate)
    
    # Заполняем очереди начальными позициями
    for i in range(n):
        if senate[i] == 'R':
            radiant.append(i)
        else:
            dire.append(i)
    
    # Симулируем раунды голосования
    while radiant and dire:
        r_index = radiant.popleft()
        d_index = dire.popleft()
        
        # Тот, кто идет раньше (меньший индекс), банит другого
        # Победитель идет в следующий раунд (+n к индексу)
        if r_index < d_index:
            radiant.append(r_index + n)
        else:
            dire.append(d_index + n)
    
    return "Radiant" if radiant else "Dire"
```
