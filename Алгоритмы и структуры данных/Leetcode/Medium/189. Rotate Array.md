# 💡 The What
*О чем задача? Что нужно сделать?*
Дан массив и число k, нужно переставить все элементы на k позиций вперед


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем функцию разворачивания части массива
- Применяем на весь массив один раз
- Потом разворачиваем первые k элементов
- Потом разворачиваем оставшиеся  n-k элементов

**Time Complexity:** O(n)
**Space Complexity:** O(1)

---

## 💻 Code

```python
def reverse(start, end):
	while start < end:
		nums[start], nums[end] = nums[end], nums[start]
		start += 1
		end -= 1
n = len(nums)
k %= n
reverse(0, n-1)
reverse(0, k-1)
reverse(k, n-1)
```

---
## ⚔️ VS / Trade-offs

_Альтернативные подходы. Плюсы/Минусы._
- **VS Итеративная ротация:** Можно написать функцию которая за один раз смещает все элементы на одну позицию и запустить эту функцию k раз, но такой подход неэффективен, он O(n^2) по ассимптотике
