#sr-due 
```go
func generateParenthesis(n int) []string {
    res := []string{}
    gen(n, 0, "", &res)
    return res
}

func gen(n int, currNum int, currStr string, res *[]string) {
    if len(currStr) == 2*n && currNum == 0 {
        *res = append(*res, currStr)
        return
    }
    r := 2*n - len(currStr) // сколько позиций осталось
    if currNum < 0 || currNum > r {
        return
    }
    gen(n, currNum+1, currStr+"(", res) // поставить '('
    gen(n, currNum-1, currStr+")", res) // поставить ')'
}
```
# Идея (коротко)
- Используем **баланс** `currNum` = сколько открытых скобок ещё надо закрыть.
- База: когда длина `2*n` и `currNum == 0` — добавляем результат.
- **Отсечки (pruning):**
    - `currNum < 0` → закрыли больше, чем открыли (некорректно).
    - `currNum > r` (где `r` — оставшиеся позиции) → не хватит места закрыть все «(».
- Рекурсивно пробуем `(` (увеличиваем баланс) и `)` (уменьшаем баланс).
- Сложность по выходу: **Θ(Cₙ)** (Каталановы числа); глубина стека **O(n)**.
- Замечание: проверка `currNum > r` эквивалентна классическому правилу «общее число '(' не превышает `n`».
