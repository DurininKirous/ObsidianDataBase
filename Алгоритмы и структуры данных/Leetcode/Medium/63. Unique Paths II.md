```python
class Solution:
    def uniquePathsWithObstacles(self, obstacleGrid: List[List[int]]) -> int:
        if len(obstacleGrid) == 0 or obstacleGrid[0][0] == 1:
            return 0
        
        obstacleGrid[0][0] = 1  # стартовая точка
        
        # Инициализация первой колонки
        for i in range(1, len(obstacleGrid)):
            obstacleGrid[i][0] = 0 if obstacleGrid[i][0] == 1 else obstacleGrid[i-1][0]
        
        # Инициализация первой строки
        for j in range(1, len(obstacleGrid[0])):
            obstacleGrid[0][j] = 0 if obstacleGrid[0][j] == 1 else obstacleGrid[0][j-1]
        
        # Заполнение остальной сетки
        for i in range(1, len(obstacleGrid)):
            for j in range(1, len(obstacleGrid[0])):
                obstacleGrid[i][j] = 0 if obstacleGrid[i][j] == 1 else obstacleGrid[i-1][j] + obstacleGrid[i][j-1]
        
        return obstacleGrid[-1][-1]
```
### **Основная идея**
- Используем **динамическое программирование (DP)**.
- Каждая клетка хранит количество способов дойти до неё.
- Препятствие = 0 путей.
- Для клетки `(i,j)` без препятствия:
```
paths[i][j] = paths[i-1][j] + paths[i][j-1]
```
- (сумма путей сверху и слева)
- Инициализируем первую строку и колонку отдельно — учитываем препятствия.
- Решение можно делать **in-place**, модифицируя исходную сетку.
