# 💡 The What
*О чем задача? Что нужно сделать?*
Given an array which represents citations of papers of one scientist. The task is to find H-index of this papers


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Sort array in non-ascending order
- Then adjust current h-index in loop if current min element greater or equal to i+1 h-index

**Time Complexity:** O(n)
**Space Complexity:** O(1)

---

## 💻 Code

```python
def hIndex(citations):
	if not citations:
		return 0
	citations.sort(reverse=True)
	curr_h = 0
	for i in range(len(citations)):
		if i+1 <= citations[i]:
			curr_h += 1
		else:
			break
	return curr_h
```
