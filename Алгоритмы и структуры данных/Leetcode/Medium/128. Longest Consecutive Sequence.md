# 💡 The What
*О чем задача? Что нужно сделать?*
Given an unsorted array of integers `nums`, return _the length of the longest consecutive elements sequence._

You must write an algorithm that runs in `O(n)` time.


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Кладём все числа в `set`. Для каждого `x` начинаем считать длину последовательности только если **`x-1` нет** в множестве (значит, `x` — левый край). Затем увеличиваем `y = x+1, x+2, ...`, пока `y` в `set`. Обновляем максимум.

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 💻 Code

```python
func longestConsecutive(nums []int) int {
    if len(nums) == 0 {
        return 0
    }

    set := make(map[int]struct{}, len(nums))
    for _, v := range nums {
        set[v] = struct{}{}
    }

    best := 0
    for x := range set {
        // запускаем цепочку только от "левого края"
        if _, ok := set[x-1]; ok {
            continue
        }
        length := 1
        y := x + 1
        for {
            if _, ok := set[y]; !ok {
                break
            }
            length++
            y++
        }
        if length > best {
            best = length
        }
    }
    return best
}
```
