# 💡 The What
*О чем задача? Что нужно сделать?*
Дано бинарное дерево, нужно найти максимальный по длине путь если ходить зигзагом

---

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 💻 Code

```python
def longestZigZag(self, root: Optional[TreeNode]) -> int:  
	def dfs(node, left_length, right_length):  
		if not node:  
			return 0  
		max_current = max(left_length, right_length)  
		max_left = 0  
		max_right = 0  
		if node.left:  
			max_left = dfs(node.left, right_length + 1, 0)  
		if node.right:  
			max_right = dfs(node.right, 0, left_length + 1)  
		return max(max_current, max_left, max_right)  
		
	return dfs(root, 0, 0)
```
