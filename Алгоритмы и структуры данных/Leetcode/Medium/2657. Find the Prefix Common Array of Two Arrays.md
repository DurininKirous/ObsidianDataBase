```python
class Solution:
    def findThePrefixCommonArray(self, A: List[int], B: List[int]) -> List[int]:
        C = []
        dick = set()
        curr = 0

        for i in range(len(A)):
            if A[i] in dick:
                curr += 1
            else:
                dick.add(A[i])

            if B[i] in dick:
                curr += 1
            else:
                dick.add(B[i])

            C.append(curr)

        return C
```
**Идея:**
- Даны две перестановки A и B длины n.
- На каждом префиксе `0..i` нужно знать, **сколько чисел уже встретилось и в A, и в B** (не позиции, а именно значения).
- Ключевая мысль: так как это **перестановки**, каждое число встречается ровно два раза в сумме — один раз в A, один раз в B.
- Поэтому если мы держим один `set` всех уже встреченных чисел (из обеих массивов), то:
    - первый раз, когда видим число → просто добавляем в set;
    - второй раз, когда видим то же число (в другом массиве или позже) → это значит, что теперь оно уже было и в A-префиксе, и в B-префиксе → увеличиваем счётчик `curr`.

На каждом i:
1. Обрабатываем `A[i]`
2. Обрабатываем `B[i]`
3. Записываем текущее значение `curr` в `C[i]`.

**Сложность:**  
O(n) по времени, O(n) по памяти (сет).
