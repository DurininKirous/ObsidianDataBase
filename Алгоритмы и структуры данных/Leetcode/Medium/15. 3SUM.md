import "sort"
func threeSum(nums []int) [][]int {
    res := [][]int {}
    sort.Ints(nums)
    var left int
    var right int
    var sum int
    for i,val := range nums {
        left = i+1
        right = len(nums)-1
        if i > 0 && nums[i] == nums[i-1] {
            continue
        }
        for left < right {
            sum = nums[left] + nums[right]
            if sum < -val {
                left++
            } else if sum > -val {
                right--
            } else {
                res = append(res, []int{val,nums[left],nums[right]})
                for left < right && nums[left] == nums[left+1] {
                    left++
                }
                for left < right && nums[right] == nums[right-1] {
                    right--
                }
                left++
                right--
            }
        }
    }
    return res
}
## Концепция
- Найти все уникальные триплеты `(a, b, c)` в массиве, где `a+b+c=0`.
- **Сначала сортируем массив**, чтобы:
    - было проще избегать дубликатов
    - можно было использовать метод **двух указателей** (two pointers)

## Алгоритм
1. `sort.Ints(nums)` — сортируем массив на месте (O(n log n))
2. Фиксируем первый элемент `nums[i]` в цикле
    - если `i>0 && nums[i] == nums[i-1]` → пропускаем (skip duplicates по i)
3. Два указателя:
    - `left := i+1`
    - `right := len(nums)-1`
4. Считаем `sum := nums[i] + nums[left] + nums[right]`
    - если `sum == 0` → добавляем триплет в результат, **пропускаем дубликаты** слева и справа
    - если `sum < 0` → `left++`
    - если `sum > 0` → `right--`
