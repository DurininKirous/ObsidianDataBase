```
func lengthOfLongestSubstring(s string) int {
    runes := []rune(s)
    letters := make(map[rune]int)

    left, lenMax := 0, 0
    for right, val := range runes {
        letters[val]++
        for letters[val] > 1 {
            letters[runes[left]]--
            left++
        }
        if right-left+1 > lenMax {
            lenMax = right - left + 1
        }
    }
    return lenMax
}
```

## Концепция (паттерн)

- Используем **sliding window** (скользящее окно) + **две границы окна (left, right)**.
- Храним количество символов в окне с помощью `map[rune]int` (или массива для ASCII).
- Расширяем `right`, добавляя новый символ.
- Если символ повторился (`letters[val] > 1`) → сдвигаем `left`, пока повтор не исчезнет.
- Текущее окно `[left..right]` всегда содержит **только уникальные символы**.
- Максимум обновляется как `lenMax = max(lenMax, right-left+1)`.
