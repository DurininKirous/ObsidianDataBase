```go
import (
    "strings"
    "unicode"
)

func decodeString(s string) string {
    stackLetters := []string{}
    stackDigits := []int{}
    res := ""
    num := 0

    for _, val := range s {
        if val == '[' {
            // Сохраняем текущий контекст
            stackLetters = append(stackLetters, res)
            stackDigits = append(stackDigits, num)
            // Обнуляем, начинаем новый уровень
            res = ""
            num = 0
        } else if val == ']' {
            repeatCount := stackDigits[len(stackDigits)-1]
            stackDigits = stackDigits[:len(stackDigits)-1]

            prev := stackLetters[len(stackLetters)-1]
            stackLetters = stackLetters[:len(stackLetters)-1]

            res = prev + strings.Repeat(res, repeatCount)
        } else if unicode.IsDigit(val) {
            num = num*10 + int(val-'0')
        } else {
            res += string(val)
        }
    }
    return res
}
```

### 💡 Концепция (идея решения)
Используем **два стека**:
- `stackDigits` — храним количество повторений для каждого уровня вложенности.
- `stackLetters` — храним строку, которая была собрана до входа в текущий уровень `[...]`.

Алгоритм проходит строку слева направо, "строит" результат снизу вверх:
1. Если встречаем **число** — накапливаем его (учёт многоцифровых чисел).
2. Если встречаем **`[`**:
   - сохраняем текущий `res` в стек (`stackLetters`),
   - сохраняем текущее число в стек (`stackDigits`),
   - обнуляем `res` (начинаем собирать внутренний фрагмент).
3. Если встречаем **букву** — добавляем её в `res`.
4. Если встречаем **`]`**:
   - достаём число повторений и строку до текущего уровня,
   - повторяем `res` `repeatCount` раз,
   - конкатенируем с предыдущей строкой → получаем новый `res`.
5. В конце возвращаем `res`.
