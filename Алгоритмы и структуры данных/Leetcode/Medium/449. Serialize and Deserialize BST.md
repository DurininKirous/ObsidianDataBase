# 💡 The What
*О чем задача? Что нужно сделать?*

Serialization is converting a data structure or object into a sequence of bits so that it can be stored in a file or memory buffer, or transmitted across a network connection link to be reconstructed later in the same or another computer environment.

Design an algorithm to serialize and deserialize a **binary search tree**. There is no restriction on how your serialization/deserialization algorithm should work. You need to ensure that a binary search tree can be serialized to a string, and this string can be deserialized to the original tree structure.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем **preorder** (root–left–right) + свойство **BST**

**Time Complexity:** O(n)
**Space Complexity:** O(n)

### Key Insights:
- 
### Algorithm:
- При сериализации делаем preorder и пишем только значения (без `None`).
- При десериализации берём значения по очереди и для каждого узла держим допустимый диапазон `[min_val, max_val]`.  
    Если следующее значение не в диапазоне — оно относится к другому поддереву.
---

## 💻 Code

```python
class Codec:

    def serialize(self, root: 'TreeNode') -> str:
        vals = []

        def preorder(node: 'TreeNode'):
            if not node:
                return
            vals.append(str(node.val))
            preorder(node.left)
            preorder(node.right)

        preorder(root)
        return ",".join(vals)

    def deserialize(self, data: str) -> 'TreeNode':
        if not data:
            return None

        vals = list(map(int, data.split(",")))
        index = 0

        def build(min_val: int, max_val: int) -> 'TreeNode | None':
            nonlocal index
            if index == len(vals):
                return None

            val = vals[index]
            if val < min_val or val > max_val:
                return None

            index += 1
            node = TreeNode(val)
            node.left = build(min_val, val)
            node.right = build(val, max_val)
            return node

        return build(float("-inf"), float("inf"))
```
