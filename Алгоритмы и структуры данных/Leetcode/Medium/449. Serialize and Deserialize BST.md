```python
class Codec:

    def serialize(self, root: 'TreeNode') -> str:
        vals = []

        def preorder(node: 'TreeNode'):
            if not node:
                return
            vals.append(str(node.val))
            preorder(node.left)
            preorder(node.right)

        preorder(root)
        return ",".join(vals)

    def deserialize(self, data: str) -> 'TreeNode':
        if not data:
            return None

        vals = list(map(int, data.split(",")))
        index = 0

        def build(min_val: int, max_val: int) -> 'TreeNode | None':
            nonlocal index
            if index == len(vals):
                return None

            val = vals[index]
            if val < min_val or val > max_val:
                return None

            index += 1
            node = TreeNode(val)
            node.left = build(min_val, val)
            node.right = build(val, max_val)
            return node

        return build(float("-inf"), float("inf"))

```
### Идея
Используем **preorder** (root–left–right) + свойство **BST**:
- При сериализации делаем preorder и пишем только значения (без `None`).
- При десериализации берём значения по очереди и для каждого узла держим допустимый диапазон `[min_val, max_val]`.  
    Если следующее значение не в диапазоне — оно относится к другому поддереву.

Так мы однозначно восстанавливаем исходное BST.
