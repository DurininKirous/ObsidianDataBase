# 💡 The What
*О чем задача? Что нужно сделать?*
You are a professional robber planning to rob houses along a street. Each house has a certain amount of money stashed. All houses at this place are **arranged in a circle.** That means the first house is the neighbor of the last one. Meanwhile, adjacent houses have a security system connected, and **it will automatically contact the police if two adjacent houses were broken into on the same night**.

Given an integer array `nums` representing the amount of money of each house, return _the maximum amount of money you can rob tonight **without alerting the police**_.


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
Массив `nums` — кольцевой, то есть первый и последний дома связаны.
> Нельзя грабить **оба** одновременно.  
> Поэтому нужно рассмотреть два варианта:
1. Грабим диапазон **[0…n−2]** (пропускаем последний).
2. Грабим диапазон **[1…n−1]** (пропускаем первый).

Ответ — максимум из двух. 

**Time Complexity:** O(n)
**Space Complexity:** O(n)

## 💻 Code

```go
func rob(nums []int) int {
    n := len(nums)
    if n == 0 {
        return 0
    }
    if n == 1 {
        return nums[0]
    }
    if n == 2 {
        return max(nums[0], nums[1])
    }

    // Вариант 1: дома [0..n-2]
    dp1 := []int{nums[0], max(nums[0], nums[1])}
    maxN1 := dp1[0]
    for i := 2; i < n-1; i++ {
        maxN1 = max(maxN1, dp1[i-2])
        dp1 = append(dp1, nums[i]+maxN1)
    }

    // Вариант 2: дома [1..n-1]
    dp2 := []int{nums[1], max(nums[1], nums[2])}
    maxN2 := dp2[0]
    for i := 3; i < n; i++ {
        maxN2 = max(maxN2, dp2[i-3])
        dp2 = append(dp2, nums[i]+maxN2)
    }

    // Финальный результат
    res := max(dp1[len(dp1)-1], dp2[len(dp2)-1])
    if len(dp1) > 1 {
        res = max(res, dp1[len(dp1)-2])
    }
    if len(dp2) > 1 {
        res = max(res, dp2[len(dp2)-2])
    }
    return res
}
```
