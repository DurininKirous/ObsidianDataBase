```python
class Solution:
    def checkSubarraySum(self, nums: List[int], k: int) -> bool:
        if len(nums) < 2:
            return False

        if k == 0:
            return any(nums[i] == 0 and nums[i + 1] == 0 for i in range(len(nums) - 1))

        mods = {0: -1}
        s = 0

        for i, x in enumerate(nums):
            s += x
            r = s % k

            if r in mods:
                if i - mods[r] >= 2:
                    return True
            else:
                mods[r] = i

        return False
```
**Идея:**  
Используем префиксные суммы по модулю `k`. Если два префикса имеют одинаковый `sum % k`, то сумма подмассива между ними кратна `k`. Сохраняем для каждого остатка самый ранний индекс, и проверяем, что длина подмассива ≥ 2. Отдельно обрабатываем `k == 0`: ищем два подряд нуля.
