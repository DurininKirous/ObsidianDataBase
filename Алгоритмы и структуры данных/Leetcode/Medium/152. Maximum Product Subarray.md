```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        maxProd = minProd = result = nums[0]
        for n in nums[1:]:
            if n < 0:
                maxProd, minProd = minProd, maxProd
            maxProd = max(n, maxProd * n)
            minProd = min(n, minProd * n)
            result = max(result, maxProd)
        return result
```
### **Идея**
Произведение отличается от суммы:  
отрицательные числа могут **перевернуть** максимум и минимум.
Поэтому на каждой позиции храним:
- `maxProd[i]` — максимум произведения подмассива, заканчивающегося в `i`
- `minProd[i]` — минимум (важно при отрицательных)

Если текущее число отрицательное → `max` и `min` **меняются местами**
