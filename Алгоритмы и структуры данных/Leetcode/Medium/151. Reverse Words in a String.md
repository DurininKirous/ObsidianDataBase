```python
class Solution:
    def reverseWords(self, s: str) -> str:
        return " ".join(s.split()[::-1])
```
Решение строится на трех встроенных методах Python, выполняемых последовательно:
1. **`s.split()`** (без аргументов):
    - Главный "трюк". Автоматически удаляет пробелы в начале и конце (`strip` не нужен).
    - Сжимает любые последовательности пробелов (2, 3 и более) в один разделитель.
    - Возвращает чистый список слов: `['the', 'sky', 'is', 'blue']`.
2. **`[::-1]`**:
    - Разворачивает список слов задом наперёд.
3. **`" ".join(...)`**:
    - Собирает слова обратно в единую строку, гарантируя ровно один пробел между ними.

**Сложность:**
- Время: **O(N)**
- Память: **O(N)**
