```python
from typing import List

class Solution:
    def findClosestElements(self, arr: List[int], k: int, x: int) -> List[int]:
        left, right = 0, len(arr) - k

        while left < right:
            mid = (left + right) // 2
            # сравниваем два соседних окна: [mid:mid+k] и [mid+1:mid+1+k]
            if x - arr[mid] > arr[mid + k] - x:
                left = mid + 1
            else:
                right = mid

        return arr[left:left + k]
```
### Идея
Массив отсортирован. Ответ — **подотрезок длины k**.  
Задача: найти **левый индекс окна длины k**, которое "лучше всего" подходит по близости к `x`.
- Возможные левые границы: от `0` до `len(arr) - k`.  
    Значит можно сделать **бинарный поиск по left**.
- Рассматриваем окна:
    - `A = arr[mid : mid + k]`
    - `B = arr[mid+1 : mid+1+k]`
- Эти окна почти одинаковые, различаются только:
    - левым элементом `A` → `arr[mid]`
    - правым элементом `B` → `arr[mid + k]`
- Сравниваем, кто ближе к `x`:
    - если `x - arr[mid] > arr[mid + k] - x`, лучше окно справа → `left = mid + 1`
    - иначе лучше (или не хуже) текущее → `right = mid`

В конце `left == right` — это оптимальное начало окна.
