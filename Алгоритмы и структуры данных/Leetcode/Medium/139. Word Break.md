```go
func wordBreak(s string, wordDict []string) bool {
    if len(s) == 0 {
        return false
    }
    words := make(map[string]bool)
    for _, val := range wordDict {
        words[val] = true
    }
    dp := make([]bool, len(s)+1)
    dp[0] = true
    for i := 1; i <= len(s); i++ {
        for j := 0; j < i; j++ {
            if dp[j] == true {
                if _ ,exists := words[string(s[j:i])]; exists {
                    dp[i]=true
                    break
                }
            }
        }
    }
    
    return dp[len(s)]
}
```
**Основная идея:**
- Динамическое программирование
- `dp[i]` = `true`, если подстроку `s[:i]` можно разбить на слова из словаря
- `dp[0] = true` (пустая строка - базовый случай)
- Для каждой позиции `i` проверяем все возможные разбиения через позиции `j < i`
- Если `dp[j] == true` и `s[j:i]` есть в словаре → `dp[i] = true`

**Сложность:** O(n² × m), где n - длина строки, m - средняя длина слова
