# 💡 The What
*О чем задача? Что нужно сделать?*

Given an array of positive integers `nums` and a positive integer `target`, return _the **minimal length** of a_ _whose sum is greater than or equal to_ `target`. If there is no such subarray, return `0` instead.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Use window to keep the current min subarray with target sum

**Time Complexity:** O(n)
**Space Complexity:** O(1)

## 💻 Code

```python
class Solution:
    def minSubArrayLen(self, target: int, nums: List[int]) -> int:
        curr_start = 0
        curr_sum = 0
        min_length = float('inf')
        if not nums:
            return 0
        for i in range(len(nums)):
            curr_sum += nums[i]
            while curr_sum >= target:
                min_length = min(min_length, i - curr_start + 1)
                curr_sum -= nums[curr_start]
                curr_start += 1
        return 0 if min_length == float('inf') else min_length
```
