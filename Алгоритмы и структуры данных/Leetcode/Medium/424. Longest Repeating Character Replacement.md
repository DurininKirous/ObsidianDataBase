```python
class Solution:
    def characterReplacement(self, s: str, k: int) -> int:
        dick = dict()
        left = 0
        right = 0
        maxS = 0
        maxV = 0
        for i in range(len(s)):
            dick[s[i]] = dick.get(s[i],0) + 1
            right += 1 
            maxV = max(maxV, dick[s[i]])
            while right - left - maxV > k:
                dick[s[left]] -= 1
                left += 1
            maxS = max(maxS, right - left)
        return maxS
```
**Идея**  
Скользящее окно + частоты. Пусть `maxFreq` — максимальная частота буквы в окне.  
Сделать все одинаковыми стоит `len(window) - maxFreq` замен; если это `> k`, сужаем слева. `maxFreq` держим “лениво” (не уменьшаем).
