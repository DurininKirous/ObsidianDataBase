```python
def intToRoman(num):
    values = [1000, 900, 500, 400, 100, 90, 50, 40, 10, 9, 5, 4, 1]
    symbols = ["M", "CM", "D", "CD", "C", "XC", "L", "XL", "X", "IX", "V", "IV", "I"]
    
    result = ""
    for i in range(len(values)):
        count = num // values[i]
        if count:
            result += symbols[i] * count
            num -= values[i] * count
    return result
```
**Идея**: Greedy. Массив всех значений (включая вычитающие: 4,9,40,90,400,900) от большего к меньшему. Берем максимально возможное, повторяем.
