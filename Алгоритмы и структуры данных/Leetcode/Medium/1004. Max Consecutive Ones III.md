```python
class Solution:
    def longestOnes(self, nums: List[int], k: int) -> int:
        if not nums:
            return 0
        left = 0
        currZeros = 0
        maxZeros = 0
        for i in range(len(nums)):
            if nums[i] == 0:
                currZeros += 1
            while currZeros > k:
                if nums[left] == 0:
                    currZeros -= 1
                left += 1
            maxZeros = max(maxZeros, i - left + 1)
        return maxZeros
```
**Идея:** скользящее окно. Разрешаем до `k` нулей внутри окна. Если нулей стало больше `k`, сужаем окно слева, пока снова не станет ≤ `k`. Максимизируем длину окна.
