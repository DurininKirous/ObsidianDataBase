```python
class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        dick = {}
        have = {}
        res = []
        opn = 0
        left = 0
        for i in s:
            dick[i] = dick.get(i,0) + 1
        for i in range(len(s)):
            have[s[i]] = have.get(s[i],0)+1
            if have[s[i]] == 1:
                opn += 1
            if have[s[i]] == dick[s[i]]:
                opn -= 1
            if opn == 0:
                res.append(i-left+1)
                left = i + 1
        return res
```
**Идея:**  
Сначала считаем общее количество каждого символа. Потом идём по строке и считаем, сколько раз каждый символ уже встретили. `opn` — сколько «типов» символов открыто (ещё не встретили все их вхождения). Когда `opn` снова становится 0 — завершили партицию.
