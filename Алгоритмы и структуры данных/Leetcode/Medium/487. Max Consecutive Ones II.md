```python
def ones(s):
    maxL = left = currZero = 0
    for i in range(len(s)):
        if s[i] == 0:
            currZero += 1
        while currZero > 1:
            if s[left] == 0:
                currZero -= 1
            left += 1
        maxL = max(maxL, i - left + 1)
    return maxL
```
**Идея:**
- Разрешаем максимум **один ноль** в окне.
- При втором нуле — двигаем левый указатель, пока в окне не останется ≤ 1 ноль.
- На каждом шаге фиксируем максимальную длину окна.
