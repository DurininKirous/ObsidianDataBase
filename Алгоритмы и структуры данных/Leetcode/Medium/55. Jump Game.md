# 💡 The What
*О чем задача? Что нужно сделать?*

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return `true` _if you can reach the last index, or_ `false` _otherwise_.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Жадно поддерживаем самый дальний **достижимый** индекс `farthest`

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Algorithm:
Идём слева направо:
- если `i > farthest` → до `i` добраться нельзя → `False`;
- обновляем `farthest = max(farthest, i + nums[i])`;
- если `farthest >= n-1` → можно добраться до конца → `True`.
---

## 💻 Code

```python
func canJump(nums []int) bool {
    farthest := 0
    last := len(nums) - 1
    for i, x := range nums {
        if i > farthest { // упёрлись в недостижимый индекс
            return false
        }
        if i+x > farthest {
            farthest = i + x
        }
        if farthest >= last { // уже можем дотянуться до конца
            return true
        }
    }
    return true
}
```
