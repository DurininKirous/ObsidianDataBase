#sr-due 
```go
func canJump(nums []int) bool {
    farthest := 0
    last := len(nums) - 1
    for i, x := range nums {
        if i > farthest { // упёрлись в недостижимый индекс
            return false
        }
        if i+x > farthest {
            farthest = i + x
        }
        if farthest >= last { // уже можем дотянуться до конца
            return true
        }
    }
    return true
}
```
## Идея
Жадно поддерживаем самый дальний **достижимый** индекс `farthest`.  
Идём слева направо:
- если `i > farthest` → до `i` добраться нельзя → `False`;
- обновляем `farthest = max(farthest, i + nums[i])`;
- если `farthest >= n-1` → можно добраться до конца → `True`.
