```python
from collections import defaultdict

class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        count = defaultdict(int)
        operations = 0
        
        for num in nums:
            complement = k - num
            if count[complement] > 0:
                operations += 1
                count[complement] -= 1
            else:
                count[num] += 1
        
        return operations
```
## Идея
Проходим массив один раз. Для каждого числа ищем его комплемент (k - num). Если комплемент уже встречался и есть в запасе — формируем пару и уменьшаем счётчик. Если нет — сохраняем текущее число для будущих пар.
