# 💡 The What
*О чем задача? Что нужно сделать?*
You are given an integer array `nums` and an integer `k`.

In one operation, you can pick two numbers from the array whose sum equals `k` and remove them from the array.

Return _the maximum number of operations you can perform on the array_.


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Проходим массив один раз. Для каждого числа ищем его комплемент (k - num). Если комплемент уже встречался и есть в запасе — формируем пару и уменьшаем счётчик. Если нет — сохраняем текущее число для будущих пар.

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 💻 Code

```python
from collections import defaultdict

class Solution:
    def maxOperations(self, nums: List[int], k: int) -> int:
        count = defaultdict(int)
        operations = 0
        
        for num in nums:
            complement = k - num
            if count[complement] > 0:
                operations += 1
                count[complement] -= 1
            else:
                count[num] += 1
        
        return operations
```

## ⚔️ VS / Trade-offs

_Альтернативные подходы. Плюсы/Минусы._
- **VS Brute Force:** O(n^2) сложность, неэффективно
- **Trade-off:** Особенности, которые вытекают из работы с Hash-table
