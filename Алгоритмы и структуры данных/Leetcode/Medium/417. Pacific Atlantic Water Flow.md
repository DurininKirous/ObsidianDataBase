```python
class Solution:
    def pacificAtlantic(self, heights: List[List[int]]) -> List[List[int]]:
        pac = [[False]*len(heights[0]) for _ in range(len(heights))]
        atl = [[False]*len(heights[0]) for _ in range(len(heights))]
        dirs = ((1,0),(-1,0),(0,1),(0,-1))

        def dfs(seen, r, c):
            if seen[r][c]:
                return
            seen[r][c] = True
            h = heights[r][c]
            for dr, dc in dirs:
                nr, nc = r+dr, c+dc
                if 0 <= nr < len(heights) and 0 <= nc < len(heights[0]) and not seen[nr][nc] and heights[nr][nc] >= h:
                    dfs(seen, nr, nc)
        
        for i in range(len(heights)):
            dfs(pac, i, 0)
            dfs(atl, i, len(heights[0])-1)

        for i in range(len(heights[0])):
            dfs(pac, 0, i)
            dfs(atl, len(heights)-1, i)

        res = []
        for i in range(len(heights)):
            for j in range(len(heights[0])):
                if pac[i][j] and atl[i][j]:
                    res.append([i,j])
        return res

```
## Идея
- Запускаем DFS **от океанов внутрь**:
    - Pacific: весь левый столбец и верхняя строка.
    - Atlantic: весь правый столбец и нижняя строка.
- Переходим из `(r,c)` в соседа `(nr,nc)`, **если** `heights[nr][nc] >= heights[r][c]` (вода могла бы стекать обратно к океану).
- `pac` и `atl` — матрицы посещений от каждого океана.  
    Ответ — все клетки, где `pac[r][c] and atl[r][c]`.
