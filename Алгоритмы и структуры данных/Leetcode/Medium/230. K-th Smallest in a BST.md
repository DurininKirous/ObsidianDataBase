```python
def kthSmallest(root, k):
    stack = []       # наш "ручной" стек вместо рекурсии
    cur = root       # текущий узел
    count = 0        # сколько узлов мы уже "посетили" в inorder-порядке

    while stack or cur:
        # 1) Идём максимально влево, как это делала бы рекурсия.
        while cur:
            stack.append(cur)
            cur = cur.left

        # 2) Левее уже некуда — посещаем верхушку стека.
        cur = stack.pop()
        count += 1

        # Это ровно следующий элемент отсортированной последовательности BST.
        if count == k:
            return cur.val

        # 3) После посещения узла идём в его правое поддерево
        #    (и снова по нему — максимально влево на следующей итерации).
        cur = cur.right

    raise ValueError("k вне диапазона")
```
## Почему это работает
- **Inorder для BST** (лево → узел → право) возвращает значения **по возрастанию**.
- Мы **симулируем рекурсию стеком**:
    - Внутренний цикл `while cur:` проталкивает всю левую цепочку в стек.
    - `pop()` даёт следующий по порядку узел.
    - После узла переходим вправо и повторяем.
- Как только мы «посетили» `k` узлов, текущий — и есть **k-й минимум**.
