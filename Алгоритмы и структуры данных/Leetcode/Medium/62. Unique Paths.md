## 🧰 Код (Go)
```go
func uniquePaths(m int, n int) int {
    dp := make([][]int, m)
    for i := 0; i < m; i++ {
        dp[i] = make([]int, n)
        dp[i][0] = 1
    }
    for j := 0; j < n; j++ {
        dp[0][j] = 1
    }

    for i := 1; i < m; i++ {
        for j := 1; j < n; j++ {
            dp[i][j] = dp[i-1][j] + dp[i][j-1]
        }
    }

    return dp[m-1][n-1]
}
```
## ⚙️ Идея (Dynamic Programming)
Каждая клетка `(i, j)` достижима:
- сверху `(i-1, j)`
- слева `(i, j-1)`

Следовательно:
\[
dp[i][j] = dp[i-1][j] + dp[i][j-1]
\]

**База:**
- `dp[0][j] = 1` (первая строка — можно идти только вправо)
- `dp[i][0] = 1` (первый столбец — можно идти только вниз)
