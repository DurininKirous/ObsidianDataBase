```go
func insert(intervals [][]int, newInterval []int) [][]int {
    res := [][]int{}
    l, r := newInterval[0], newInterval[1]
    i, n := 0, len(intervals)

    // 1) слева (не пересекаются)
    for i < n && intervals[i][1] < l {
        res = append(res, intervals[i])
        i++
    }

    // 2) слияние пересечений
    for i < n && intervals[i][0] <= r {
        if intervals[i][0] < l { l = intervals[i][0] }
        if intervals[i][1] > r { r = intervals[i][1] }
        i++
    }
    res = append(res, []int{l, r})

    // 3) справа (хвост)
    for i < n {
        res = append(res, intervals[i])
        i++
    }
    return res
}
```
## Идея
Даны **отсортированные, непересекающиеся** интервалы и новый `[l, r]`. Делаем один проход:
1. Добавляем все интервалы **левае**: `end < l`.
2. **Сливаем** все пересекающиеся: пока `start ≤ r` →  
    `l = min(l, start)`, `r = max(r, end)`.
3. Кладём слитый `[l, r]`.
4. Докидываем остальные интервалы (те, что **правее**).
