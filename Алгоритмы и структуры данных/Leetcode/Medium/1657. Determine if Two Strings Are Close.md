```python
from collections import defaultdict

class Solution:
    def closeStrings(self, word1: str, word2: str) -> bool:
        dick1 = defaultdict(int)
        dick2 = defaultdict(int)
        for i in word1:
            dick1[i] += 1
        for i in word2:
            dick2[i] += 1
        return dick1.keys() == dick2.keys() and sorted(dick1.values()) == sorted(dick2.values())
```
**Идея решения:**
1. Подсчитываем частоту каждого символа в обеих строках
2. Проверяем два условия:
    - **Одинаковый набор символов** (`dick1.keys() == dick2.keys()`) — операция Transform может менять только существующие символы
    - **Одинаковые отсортированные частоты** (`sorted(values)`) — операция Transform позволяет "переносить" частоты между символами

**Временная сложность:** O(n log n) — сортировка частот  
**Пространственная сложность:** O(1) — максимум 26 символов для lowercase английских букв
