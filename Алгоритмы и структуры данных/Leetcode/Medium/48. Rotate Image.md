```python
class Solution:
    def rotate(self, matrix: List[List[int]]) -> None:
        for i in range(len(matrix)):
            for j in range(i+1, len(matrix[0])):
                matrix[i][j], matrix[j][i] = matrix[j][i], matrix[i][j]
        for i in range(len(matrix)):
            matrix[i].reverse()
```
## Идея
Поворот на 90° по часовой стрелке делается в 2 шага:
1. **Транспонирование** матрицы: меняем местами `matrix[i][j]` и `matrix[j][i]` для `j > i`.
2. **Разворот каждой строки** (reverse) — получаем итоговый поворот.

Сложность: **O(n²)** по времени, **O(1)** доп.памяти.
