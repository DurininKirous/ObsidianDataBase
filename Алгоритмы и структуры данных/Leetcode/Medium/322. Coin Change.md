```python
from typing import List

class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        if amount == 0:
            return 0

        number = 0
        curr = {0}
        visited = {0}

        while curr:
            number += 1
            next_curr = set()

            for i in curr:
                for j in coins:
                    new_sum = i + j
                    if new_sum == amount:
                        return number
                    if new_sum < amount and new_sum not in visited:
                        visited.add(new_sum)
                        next_curr.add(new_sum)

            curr = next_curr

        return -1
```
## 💡 **Ключевая мысль**

Это задача на **поиск в ширину (BFS)** в пространстве возможных сумм.
- Каждый уровень BFS = количество монет, использованных до этого.
- Каждый узел = сумма, которую можно собрать.
- На каждом уровне добавляем к каждой текущей сумме `i` все возможные `i + coin`.
- Как только достигаем `amount` — возвращаем текущий уровень.
