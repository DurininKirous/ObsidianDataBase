```python
def compress(chars):
    write = 0
    i = 0
    while i < len(chars):
        char = chars[i]
        count = 0
        while i < len(chars) and chars[i] == char:
            count += 1
            i += 1
        chars[write] = char
        write += 1
        if count > 1:
            for digit in str(count):
                chars[write] = digit
                write += 1
    return write
```
**Идея**: Two pointers (read/write). Читаем блок одинаковых символов, пишем символ + count если >1. In-place.
