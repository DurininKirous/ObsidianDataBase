```python
class NestedIterator:
    def __init__(self, nestedList):
        self.stack = nestedList[::-1]  # reverse для pop()
    
    def next(self):
        return self.stack.pop().getInteger()
    
    def hasNext(self):
        while self.stack:
            top = self.stack[-1]
            if top.isInteger():
                return True
            self.stack.pop()
            self.stack.extend(top.getList()[::-1])  # раскрываем список
        return False
```
**Идея**: Stack-based DFS. hasNext() делает всю работу - раскрывает списки в стеке. next() просто берет готовый integer.
