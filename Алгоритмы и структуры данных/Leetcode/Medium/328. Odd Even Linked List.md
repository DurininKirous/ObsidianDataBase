# 💡 The What
*О чем задача? Что нужно сделать?*
Дан связный список, нужно сгруппировать ноды на чётных и нечётных позициях так, чтобы сначала в списке шли ноды с нечётными позициями, а потом  с чётными.
Пример: 
	До: 1 2 3 4 5 
	После: 1 3 5 2 4

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Создаем два итератора - один для чётных позиций, другой для нечётных
- Итерируемся в цикле по ним, следующему значению каждого итератора присваиваем следующее значение другого итератора

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Key Insights:
- Не надо создавать доп список или делать что-то ещё, достаточно завести итератор для чётных позиций и для нечётны и итерироваться по ним
---

## 💻 Code

```python
def oddEvenList(self, head: Optional[ListNode]) -> Optional[ListNode]:
	if not head or not head.next:
		return head
	odd = head
	even = head.next
	dummy_even = even
	while even and even.next:
		odd.next = even.next
		odd = odd.next
		
		even.next = odd.next
		even = even.next	
	odd.next = dummy_even
	
	return head
```
