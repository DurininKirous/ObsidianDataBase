# 💡 The What
*О чем задача? Что нужно сделать?*
Дан массив чисел nums и число k, верните число подмассивов, сумма чисел в которых делится на k.
Подмассив - непрерывная непустая последовательность элементов массива 


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем hash-мапу и prefix-суммы

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 💻 Code

```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        dick = {}
        sumRes = 0
        num = 0
        for i in nums:
            sumRes += i
            if sumRes == k:
                num += 1
            num += dick.get(sumRes - k, 0)
            dick[sumRes] = dick.get(sumRes, 0) + 1
        return num
```
