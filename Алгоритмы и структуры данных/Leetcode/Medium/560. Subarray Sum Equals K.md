```python
class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        dick = {}
        sumRes = 0
        num = 0
        for i in nums:
            sumRes += i
            if sumRes == k:
                num += 1
            num += dick.get(sumRes - k, 0)
            dick[sumRes] = dick.get(sumRes, 0) + 1
        return num
```
Идея: Prefix Sum + HashMap
Если обозначить:

prefix[j]=сумма nums[0..j]
prefix[j]=сумма nums[0..j]

Тогда подмассив (i..j) имеет сумму k, если:

prefix[j]−prefix[i−1]=k⇒prefix[i−1]=prefix[j]−k
prefix[j]−prefix[i−1]=k⇒prefix[i−1]=prefix[j]−k

Мы считаем, сколько раз встречалась каждая prefix-сумма,
чтобы быстро узнать, сколько подмассивов с суммой k заканчивается в текущей позиции.
