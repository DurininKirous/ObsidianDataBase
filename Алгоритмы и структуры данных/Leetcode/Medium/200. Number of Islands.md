# 💡 The What
*О чем задача? Что нужно сделать?*
Given an `m x n` 2D binary grid `grid` which represents a map of `'1'`s (land) and `'0'`s (water), return _the number of islands_.

An **island** is surrounded by water and is formed by connecting adjacent lands horizontally or vertically. You may assume all four edges of the grid are all surrounded by water.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
Нужно посчитать количество «островов» в матрице, где:
- `'1'` = земля
- `'0'` = вода

Каждый раз, когда находим единицу, мы будем запускать рекурсию, которая будет затоплять сушу (менять 1 на 0). Так мы каждый остров засчитаем ровно один раз

**Time Complexity:** O(n\*m)
**Space Complexity:** O(1)

### Algorithm:
1. Заводим счётчик `num = 0`.
2. Проходим всю матрицу.
3. Если встречаем `'1'`, это новый остров:
    - увеличиваем `num` на 1;i
    - запускаем `Fill`, чтобы затопить этот остров (заменить все `'1'` на `'0'`).
4. В конце возвращаем `num`.
---

## 💻 Code

```go
func numIslands(grid [][]byte) int {
    num := 0
    for i := 0; i < len(grid); i++ {
        for j := 0; j < len(grid[i]); j++ {
            if grid[i][j] == '1' {
                Fill(&grid, i, j)
                num++
            }
        }
    }
    return num
}

func Fill(grid *[][]byte, i, j int) {
    if i < 0 || i >= len(*grid) || j < 0 || j >= len((*grid)[0]) || (*grid)[i][j] == '0' {
        return
    }

    // затопляем землю
    (*grid)[i][j] = '0'

    // рекурсивно во все стороны
    Fill(grid, i+1, j)
    Fill(grid, i-1, j)
    Fill(grid, i, j+1)
    Fill(grid, i, j-1)
}
```

## ⚔️ VS / Trade-offs

_Альтернативные подходы. Плюсы/Минусы._
- **VS Brute Force:** Трудно учесть случаи повторного попадания на уже пройденную сушу
- **Trade-off:** Рекурсия затратна. Легко в написании, но будет есть больше ресурсов
