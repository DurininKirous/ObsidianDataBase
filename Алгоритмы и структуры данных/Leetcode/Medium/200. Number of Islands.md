#sr-due 
```go
func numIslands(grid [][]byte) int {
    num := 0
    for i := 0; i < len(grid); i++ {
        for j := 0; j < len(grid[i]); j++ {
            if grid[i][j] == '1' {
                Fill(&grid, i, j)
                num++
            }
        }
    }
    return num
}

func Fill(grid *[][]byte, i, j int) {
    if i < 0 || i >= len(*grid) || j < 0 || j >= len((*grid)[0]) || (*grid)[i][j] == '0' {
        return
    }

    // затопляем землю
    (*grid)[i][j] = '0'

    // рекурсивно во все стороны
    Fill(grid, i+1, j)
    Fill(grid, i-1, j)
    Fill(grid, i, j+1)
    Fill(grid, i, j-1)
}
```
## Идея
Нужно посчитать количество «островов» в матрице, где:
- `'1'` = земля
- `'0'` = вода

**Остров** = связная компонента единиц, соединённых по 4 сторонам (вверх, вниз, влево, вправо).
### Алгоритм (DFS flood fill):
1. Заводим счётчик `num = 0`.
2. Проходим всю матрицу.
3. Если встречаем `'1'`, это новый остров:
    - увеличиваем `num` на 1;
    - запускаем `Fill`, чтобы затопить этот остров (заменить все `'1'` на `'0'`).
4. В конце возвращаем `num`.
