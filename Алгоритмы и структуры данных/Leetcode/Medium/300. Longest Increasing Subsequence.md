```python
class Solution:
    def lengthOfLIS(self, nums):
        tails = []

        def lower_bound(a, x):
            lo, hi = 0, len(a)
            while lo < hi:
                mid = (lo + hi) // 2
                if a[mid] < x:
                    lo = mid + 1
                else:
                    hi = mid
            return lo

        for x in nums:
            i = lower_bound(tails, x)
            if i == len(tails):
                tails.append(x)
            else:
                tails[i] = x
        return len(tails)
```
**Идея**  
Метод “хвостов” (patience sorting): `tails[k]` — минимальный возможный **хвост** возрастающей подпоследовательности длины `k+1`.  
Для каждого `x` находим `lower_bound` (первую позицию `>= x`) и обновляем `tails`. Итоговая длина `tails` — ответ. `O(n log n)`.
