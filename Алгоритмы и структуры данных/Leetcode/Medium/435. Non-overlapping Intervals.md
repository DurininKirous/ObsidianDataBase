```python
class Solution:
    def eraseOverlapIntervals(self, intervals: List[List[int]]) -> int:
        if not intervals:
            return 0
        intervals.sort() 
        removals = 0
        prev_end = intervals[0][1]

        for i in range(1, len(intervals)):
            s, e = intervals[i]
            if s < prev_end: 
                removals += 1
                prev_end = min(prev_end, e)
            else:
                prev_end = e

        return removals


```
**Идея**  
Жадно по правым границам (activity selection): сортируем по `end`, выбираем как можно больше **неперекрывающихся** интервалов; ответ — `n - kept`.
