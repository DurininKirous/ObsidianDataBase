```python
def is_reflected(points):
    if not points:
        return True
    min_x = min(x for x, _ in points)
    max_x = max(x for x, _ in points)
    s = min_x + max_x                # это 2*c, где c — абсцисса оси
    pts = {(x, y) for x, y in points}  # множество для O(1) проверок

    return all((s - x, y) in pts for x, y in pts)
```
Идея:
- Если существует вертикальная ось отражения, то она неизбежно проходит через x=(min⁡+ma⁡x)/2​​.
- Для каждой точки (x,y) в множестве должна существовать точка (min⁡x+max⁡x−x,y).
- Чтобы не возиться с дробями, храним сумму s=min⁡x+max⁡xs и проверяем точку-отражение как (s−x,y).
- Дубликаты в исходном списке не влияют на ответ (сравниваем именно множество точек).
