```python
def increasingTriplet(nums: list[int]) -> bool:
    first = float('inf')   # минимум из всех
    second = float('inf')  # минимум из элементов > first
    
    for num in nums:
        if num <= first:
            # Обновляем первый минимум
            first = num
        elif num <= second:
            # num > first, но <= second
            # Обновляем второй минимум
            second = num
        else:
            # num > second и second > first
            # Нашли тройку!
            return True
    
    return False
```
## Идея (ключевая инсайт)
**Не отслеживай три элемента — отслеживай два минимума!**
Храни:
- `first` = наименьший элемент, встреченный до текущей позиции
- `second` = наименьший элемент, который **больше first** и встречен раньше текущей позиции

**Если найдешь элемент > `second` → тройка существует.**
