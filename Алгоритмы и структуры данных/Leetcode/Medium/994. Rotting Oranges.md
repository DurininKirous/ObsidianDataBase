# 💡 The What
*О чем задача? Что нужно сделать?*
You are given an `m x n` `grid` where each cell can have one of three values:

- `0` representing an empty cell,
- `1` representing a fresh orange, or
- `2` representing a rotten orange.

Every minute, any fresh orange that is **4-directionally adjacent** to a rotten orange becomes rotten.

Return _the minimum number of minutes that must elapse until no cell has a fresh orange_. If _this is impossible, return_ `-1`.


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем BFS, стартуем от всех гнилых апельсинов сразу, пытаемся от них заразить всевозможные дальше 

**Time Complexity:** O(n)
**Space Complexity:** O(n)

### Algorithm:
- **Multi-source BFS:** стартуем от всех гнилых апельсинов сразу (кладём их координаты в очередь).
- Идём **послойно**: каждая итерация внешнего цикла — это **1 минута**. За эту минуту все текущие гнилые заражают соседей по четырём направлениям.
- Ведём счётчик `fresh` (кол-во свежих). Каждый раз, когда свежий становится гнилым, уменьшаем `fresh`.  
    Когда `fresh` станет 0 — все протухли, ответ = накопленные `minutes`.

## 💻 Code

```python
from collections import deque
class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        oranges = deque()
        fresh = 0
        for i in range(len(grid)):
            for j in range(len(grid[0])):
                if grid[i][j] == 2:
                    oranges.append([i,j])
                elif grid[i][j] == 1:
                    fresh +=1
        
        if fresh == 0:
            return 0

        minutes = 0
        while len(oranges) > 0 and fresh > 0:
            n  = len(oranges)
      ķ     for i in range(n):
                r, c = oranges.popleft()

                if r+1 < len(grid) and grid[r+1][c] == 1:
                    grid[r+1][c] = 2
                    oranges.append([r+1, c])
                    fresh -= 1

                if r-1 >= 0 and grid[r-1][c] == 1:
                    grid[r-1][c] = 2
                    oranges.append([r-1, c])
                    fresh -= 1

                if c+1 < len(grid[0]) and grid[r][c+1] == 1:
                    grid[r][c+1] = 2
                    oranges.append([r, c+1])
                    fresh -= 1

                if c-1 >= 0 and grid[r][c-1] == 1:
                    grid[r][c-1] = 2
                    oranges.append([r, c-1])
                    fresh -=1

            minutes += 1

        if fresh > 0:
            return -1
        return minutes
```
