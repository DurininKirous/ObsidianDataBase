```python
def func(s):
    print(s)
    dick = dict()
    left = 0
    curr_unique = 0
    max_len = 0
    for i in range(len(s)):
        dick[s[i]] = dick.get(s[i], 0) + 1
        if dick[s[i]] == 1:
            curr_unique += 1
        while curr_unique > 2:
            dick[s[left]] -= 1
            if dick[s[left]] == 0:
                curr_unique -= 1
            left += 1
        max_len = max(max_len, i - left + 1)
    return max_len
print(func("eceba"))
print(func("ccaabbb"))
```
**Идея:**  
Скользящее окно + словарь частот. Расширяем правую границу, считаем, сколько разных символов в окне. Если их стало больше 2 — двигаем левую границу, уменьшая частоты, пока снова не будет ≤ 2, и обновляем максимум длины.
