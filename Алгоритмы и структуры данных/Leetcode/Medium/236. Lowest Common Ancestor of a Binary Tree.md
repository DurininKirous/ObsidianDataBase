# 💡 The What
*О чем задача? Что нужно сделать?*
Дано бинарное дерево и две ноды её, нужно найти ближайшего к обоим предка


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Делаем через рекурсию, возвращаем none, если дошли до конца, возвращаем root, если нашли одну из нод
- Идем влево и вправо
- Нашли по ноде в левой и правой ветке - предок
- Нашли только в одной из веток - идём внутрь неё
- Не нашли ничего - возвращаем None

**Time Complexity:** O(n)
**Space Complexity:** O(n)

---

## 💻 Code

```python
def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':  
	def findLowestAncestor(root, p, q):  
		if not root:  
			return None  
		if root == p or root == q:  
			return root  
		left = findLowestAncestor(root.left, p, q)  
		right = findLowestAncestor(root.right, p, q)  
		if left and right:  
			return root  
		elif left:  
			return left  
		elif right:  
			return right  
		return None  
	return findLowestAncestor(root, p, q)
```
