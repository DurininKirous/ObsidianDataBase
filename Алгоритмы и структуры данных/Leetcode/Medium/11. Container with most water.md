func maxArea(height []int) int {
    left := 0
    right := len(height) - 1
    maxS := min(height[left],height[right])*(right-left)
    for left < right {
     if height[left] < height[right] {
         left++
     } else {
         right--
        }
      maxS=max(min(height[left],height[right])*(right-left), maxS)
    }
    return maxS
}

## Концепция
- Используем **две границы (two pointers)**: `left=0`, `right=n-1`.
- На каждом шаге считаем площадь.
- Двигаем **меньшую стенку**, т.к. именно она ограничивает высоту.
- Продолжаем, пока `left < right`.
