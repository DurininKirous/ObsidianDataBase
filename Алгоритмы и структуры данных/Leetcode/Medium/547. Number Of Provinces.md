# 💡 The What
*О чем задача? Что нужно сделать?*
Дана матрица связности, нужно найти количество компонент связности в графе

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Через рекурсию обходим все вершины, собираем их в словаре

**Time Complexity:** O(n+e)
**Space Complexity:** O(n)

---

## 💻 Code

```python
def dfs(isConnected, seen, curr):
	if curr in seen:
		return
	seen[curr]=1
	for i in range(len(isConnected[curr])):
		if i not in seen and isConnected[curr][i] == 1:
			dfs(isConnected, seen, i)
res = 0
seen = defaultdict(int)
for i in range(len(isConnected)):
	if i not in seen:
		dfs(isConnected, seen, i)
		res += 1
return res
```
