# 💡 The What
*О чем задача? Что нужно сделать?*

You are given an `m x n` binary matrix `grid`. An island is a group of `1`'s (representing land) connected **4-directionally** (horizontal or vertical.) You may assume all four edges of the grid are surrounded by water.

The **area** of an island is the number of cells with a value `1` in the island.

Return _the maximum **area** of an island in_ `grid`. If there is no island, return `0`.

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Проходимся по графу, если находим 1 - запускаем Fill функцию, она затопит остров и вернёт его размер. И так по всем клеткам идём

**Time Complexity:** O(n\*m)
**Space Complexity:** O(n\*m)

---

## 💻 Code

```go
func maxAreaOfIsland(grid [][]int) int {
    maxN := 0
    for i := 0; i < len(grid); i++ {
        for j := 0; j < len(grid[i]); j++ {
            if grid[i][j] == 1 {
                res := Fill(&grid, i, j)
                maxN = max(maxN, res)
            }
        }
    }
    return maxN
}

func Fill(grid *[][]int, i, j int) int {
    if i < 0 || i >= len(*grid) || j < 0 || j >= len((*grid)[0]) || (*grid)[i][j] == 0 {
        return 0
    }

    (*grid)[i][j] = 0 // затопили клетку

    return 1 +
        Fill(grid, i+1, j) +
        Fill(grid, i-1, j) +
        Fill(grid, i, j+1) +
        Fill(grid, i, j-1)
}
```
