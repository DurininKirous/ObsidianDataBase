```go
func minPathSum(grid [][]int) int {
    // Инициализация первого столбца
    for i := 1; i < len(grid); i++ {
        grid[i][0] += grid[i-1][0]
    }
    
    // Инициализация первой строки
    for j := 1; j < len(grid[0]); j++ {
        grid[0][j] += grid[0][j-1]
    }
    
    // Заполнение остальных ячеек
    for i := 1; i < len(grid); i++ {
        for j := 1; j < len(grid[0]); j++ {
            grid[i][j] += min(grid[i-1][j], grid[i][j-1])
        }
    }
    
    return grid[len(grid)-1][len(grid[0])-1]
}
```
💡 Идея решения

**Ключевая идея:** Dynamic Programming (DP)

**Логика:**
Минимальный путь до ячейки `(i, j)` = текущее значение + минимум из:
- Пути сверху `(i-1, j)`
- Пути слева `(i, j-1)`

**Формула DP:**
dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])

**Инициализация:** 
- Первая строка: можно идти только вправо 
- Первый столбец: можно идти только вниз 
**Оптимизация памяти:** Модифицируем `grid` in-place → O(1) дополнительной памяти.
