```python
from collections import defaultdict
from typing import List

class Solution:
    def subarraysDivByK(self, nums: List[int], k: int) -> int:
        dick = defaultdict(int)
        dick[0] = 1
        curr = 0
        count = 0

        for i in nums:
            curr += i
            r = curr % k
            count += dick[r]
            dick[r] += 1

        return count
```
### Идея
Берём префиксные суммы и считаем остатки по модулю `k`.
- Пусть `prefix[i]` — сумма `nums[:i]`.
- Сумма подмассива `nums[l..r]` делится на k, если:  
    `prefix[r+1] % k == prefix[l] % k`.
- Храним в словаре, сколько раз уже встречался каждый остаток.  
    Для каждого нового префикса с остатком `r` добавляем к ответу `cnt[r]`, потом `cnt[r] += 1`.

Это твой код — он корректный.
