```python
class Solution:
    def checkInclusion(self, s1: str, s2: str) -> bool:
        n, m = len(s1), len(s2)
        if n > m:
            return False

        need = [0]*26
        have = [0]*26
        base = ord('a')

        for i in range(n):
            need[ord(s1[i]) - base] += 1
            have[ord(s2[i]) - base] += 1

        matches = sum(1 for c in range(26) if need[c] == have[c])
        if matches == 26:
            return True

        for i in range(n, m):
            r = ord(s2[i]) - base        # добавляем справа
            l = ord(s2[i-n]) - base      # убираем слева

            if have[r] == need[r]: matches -= 1
            have[r] += 1
            if have[r] == need[r]: matches += 1

            if have[l] == need[l]: matches -= 1
            have[l] -= 1
            if have[l] == need[l]: matches += 1

            if matches == 26:
                return True

        return False
```
**Идея**  
Скользящее окно длины `len(s1)` по `s2`. Храним частоты букв `a..z` в массивах `need` и `have`.  
Поддерживаем `matches` — сколько позиций совпадает (`need[c] == have[c]`).  
При сдвиге окна обновляем только две буквы (вошла/вышла) и корректируем `matches` за `O(1)`.  
Если `matches == 26`, окно — перестановка `s1`.
