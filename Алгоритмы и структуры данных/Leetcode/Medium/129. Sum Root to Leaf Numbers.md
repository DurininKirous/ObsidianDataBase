# 💡 The What
*О чем задача? Что нужно сделать?*

You have a binary tree where each node contains a single digit (0-9). Your task is to find the sum of all numbers formed by paths from the root to leaf nodes

A path from root to leaf forms a number by concatenating the digits along the path. For instance, if you traverse from root to leaf through nodes with values `1 → 2 → 3`, this path represents the number `123`

---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
-  Через DFS пройтись от корней к листьям, на каждом шагу добавляя новое значение.

**Time Complexity:** O(n)
**Space Complexity:** O(n)

### Algorithm:
1.  Идём DFS от корня к листьям.
2. На каждом шаге строим число:
	curr = curr * 10 + root.Val
3. Если дошли до листа → добавляем число к сумме.
---

## 💻 Code

```python
func findPaths(root *TreeNode, curr int, sum *int) {
    if root == nil {
        return
    }

    curr = curr*10 + root.Val

    if root.Left == nil && root.Right == nil {
        *sum += curr
        return
    }
    findPaths(root.Left, curr, sum)
    findPaths(root.Right, curr, sum)
}

func sumNumbers(root *TreeNode) int {
    if root == nil {
        return 0
    }
    sum := 0
    findPaths(root, 0, &sum)
    return sum
}
```
