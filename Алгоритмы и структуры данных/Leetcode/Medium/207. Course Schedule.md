```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        adj = [[] for _ in range(numCourses)]  # b -> a
        indeg = [0] * numCourses               # входящая степень

        for a, b in prerequisites:
            adj[b].append(a)
            indeg[a] += 1

        q = deque([i for i in range(numCourses) if indeg[i] == 0])
        seen = 0

        while q:
            u = q.popleft()
            seen += 1
            for v in adj[u]:
                indeg[v] -= 1
                if indeg[v] == 0:
                    q.append(v)

        return seen == numCourses
```
## Основная идея
- Для зависимости `[a, b]` рисуем ребро **b → a** (сначала `b`, потом `a`).
- Всегда берем курсы с **indegree == 0** (ничего не требуют), «удаляем» их, уменьшая входящую степень соседям.
- Если в конце обработали все `numCourses`, циклов нет → можно закончить.

## Шаги
1. Построить `adj[b].append(a)` и массив `indeg[a]++`.
2. В очередь положить все курсы с `indeg == 0`.
3. Пока очередь не пуста: вытащить `u`, увеличить `seen`, для всех соседей `v` уменьшить `indeg[v]`; если стало 0 — в очередь.
4. Ответ: `seen == numCourses`.

- Время: `O(V + E)`
- Память: `O(V + E)`
