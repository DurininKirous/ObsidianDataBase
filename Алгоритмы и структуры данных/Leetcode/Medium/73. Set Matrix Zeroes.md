```python
class Solution:
    def setZeroes(self, matrix: List[List[int]]) -> None:
        rows = set()
        columns = set()
        for i in range(len(matrix)):
            for j in range(len(matrix[0])):
                if matrix[i][j] == 0:
                    rows.add(i)
                    columns.add(j)

        for i in rows:
            for j in range(len(matrix[0])):
                matrix[i][j] = 0

        for i in columns:
            for j in range(len(matrix)):
                matrix[j][i] = 0
```
# Идея
- За один проход найти все позиции нулей.
- Запомнить индексы **строк** и **столбцов** с нулями в множества `rows` и `columns`.
- Вторым и третьим проходом обнулить все отмеченные **строки**, затем все отмеченные **столбцы**.
- Такой «двухфазный» подход не даёт нулям «расползаться» во время сканирования.
