```go
func getSum(a int, b int) int {
    for b != 0 {
        carry := (a & b) << 1
        a = a ^ b 
        b = carry
    }
    return a
}
```
## 💡 Основная идея
Обычное сложение можно выразить через **побитовые операции**:
- `XOR (^)` — складывает, **не учитывая перенос** (0+1=1, 1+0=1, 1+1=0).
- `AND (&)` — показывает, где нужно сделать **перенос** (1+1=1 перенос).
- Сдвиг `<<` — переносим этот “carry” в следующий разряд.

Алгоритм повторяет процесс сложения “в столбик” — пока перенос не исчезнет.
