```python
class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        prev_mins = [triangle[0][0]]
        curr_mins = []
        for i in range (1, len(triangle)):
            for j in range(len(triangle[i])):
                if j == 0:
                    curr_mins.append(triangle[i][j] + prev_mins[0])
                elif j == len(triangle[i])-1:
                    curr_mins.append(triangle[i][j] + prev_mins[len(prev_mins)-1])
                else:
                    curr_mins.append(triangle[i][j] + min(prev_mins[j-1], prev_mins[j]))
            prev_mins = curr_mins
            curr_mins = []
        return min(prev_mins)
```
### 💡 Идея
Используем **динамическое программирование сверху вниз**.  
Для каждой строки считаем минимальные суммы путей до её элементов:
- первый и последний элемент зависят только от одного значения из предыдущей строки;
- остальные — от минимума из двух возможных предыдущих путей.  
    В конце берём минимум из последней строки.
