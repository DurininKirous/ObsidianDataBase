```python
class Solution:
    def findAnagrams(self, s: str, p: str) -> List[int]:
        if len(p) > len(s):
            return []
        n, m = len(p), len(s)

        need = [0] * 26
        have = [0] * 26
        base = ord('a')
        res = []

        # стартовое окно
        for i in range(n):
            need[ord(p[i]) - base] += 1
            have[ord(s[i]) - base] += 1

        # сколько букв совпало по частоте
        matches = sum(1 for c in range(26) if need[c] == have[c])
        if matches == 26:
            res.append(0)

        # двигаем окно
        for i in range(n, m):
            r = ord(s[i]) - base        # символ, который приходит справа
            l = ord(s[i - n]) - base    # символ, который уходит слева

            # обновляем для r (приход)
            if have[r] == need[r]:
                matches -= 1
            have[r] += 1
            if have[r] == need[r]:
                matches += 1

            # обновляем для l (уход)
            if have[l] == need[l]:
                matches -= 1
            have[l] -= 1
            if have[l] == need[l]:
                matches += 1

            if matches == 26:
                res.append(i - n + 1)

        return res
```
## Идея (скользящее окно + счётчик совпадений)
- Держим окно длиной `len(p)` по строке `s`.
- Подсчитываем частоты букв в `p` (`need`) и в текущем окне (`have`) в массивах на 26 букв.
- Храним `matches` — сколько букв сейчас имеют **точно одинаковые** частоты в `need` и `have`.  
    Инвариант: если `matches == 26`, текущее окно — анаграмма `p`.
- При сдвиге окна на 1 позицию:
    - Добавляем правый символ `r`, корректно обновляя `matches` только для него.
    - Убираем левый символ `l`, корректно обновляя `matches` только для него.
- Так мы избегаем сравнения 26 позиций на каждом шаге.
