```go
func lowestCommonAncestor(root, p, q *TreeNode) *TreeNode {
	if root == nil {
        return nil
    }
     
    curr := root
    for curr != nil {
        if curr.Val <= max(p.Val, q.Val) && curr.Val >= min(p.Val, q.Val) {
            return curr
        }
        if curr.Val > max(p.Val, q.Val) {
            curr = curr.Left
        } else if curr.Val < min(p.Val, q.Val) {
            curr = curr.Right
        }
    }
   
    return nil
}
```
## 🧠 Идея решения
- Идём по дереву **итеративно** начиная от корня.
- Проверяем текущее значение `curr.Val` относительно `p.Val` и `q.Val`:
    1. Если `curr.Val` находится **между** `p.Val` и `q.Val` (включая равенство) → это LCA.
    2. Если `curr.Val` больше обоих → оба узла слева → спускаемся влево.
    3. Если `curr.Val` меньше обоих → оба узла справа → спускаемся вправо.
- Когда нашли «разделяющий» узел → возвращаем его.
