# 💡 The What
*О чем задача? Что нужно сделать?*
Дан массив чисел неубывающий, необходимо сократить там количество элементов, у которых дубликатов больше двух, до двух


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Держим индекс в массиве, который указывает на текущий элемент, до которого все элементы остальные встречаются не более двух раз
- Когда встречаем новый элемент, проверяем, что этот элемент не равен элементу, который стоит на 2 индекса раньше чем индекс результирующего массива
- Если не равен, то ставим туда новый элемент и двигаем индекс

**Time Complexity:** O(n)
**Space Complexity:** O(1)

---

## 💻 Code

```python
def removeDuplicates(nums):
	if len(nums) <= 2:
		return len(nums)
	i = 2
	for j in range(2, len(nums)):
		if nums[i-2] != nums[j]:
			nums[i]=nums[j]
			i += 1
	return i	
```
