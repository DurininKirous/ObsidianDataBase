```python
import math
class Solution:
    def numSquares(self, n: int) -> int:
        squares = [i*i for i in range(1, math.isqrt(n)+1)] 
        dp = [0] + [n+1] * n
        for x in range(1,n+1):
            for i in squares:
                if i > x:
                    break
                dp[x] = min(dp[x], dp[x - i] + 1)
        return dp[n]
```
**Идея (DP):**  
Сначала генерируем все квадраты `≤ n`.  
Дальше `dp[x]` — минимальное количество квадратов, дающих сумму `x`.  
Переход: `dp[x] = min(dp[x], dp[x - i] + 1)` для всех квадратов `i ≤ x`.  
Ответ — `dp[n]`.
