```python
import bisect
from typing import List

class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        if not matrix or not matrix[0]:
            return False

        first_col = [row[0] for row in matrix]

        # индекс последней строки, где первый элемент <= target
        row = bisect.bisect_right(first_col, target) - 1
        if row < 0:
            return False

        # бинарный поиск внутри строки
        pos = bisect.bisect_left(matrix[row], target)
        return pos < len(matrix[row]) and matrix[row][pos] == target
```
### Идея
Матрица такая, что:
- каждая строка отсортирована;
- первый элемент следующей строки > последнего предыдущей.

Это значит, что если смотреть на **первые элементы строк**, то можно понять, в какой строке может лежать `target`:
1. Собираем массив первых элементов: `first_col = [row[0] for row in matrix]`.
2. Находим **последнюю строку, чей первый элемент ≤ target**:  
    `row = bisect_right(first_col, target) - 1`.
3. Если `row < 0` — значит target меньше всех, возвращаем `False`.
4. В найденной строке делаем обычный бинарный поиск (`bisect_left`).

Твой вариант с `bisect_left` по строкам был почти ок, но ломался, когда `target` меньше самого первого элемента (получался `row = -1` и обращение к последней строке).
