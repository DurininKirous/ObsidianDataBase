# 💡 The What
*О чем задача? Что нужно сделать?*
Дана голова связного списка, нужно удалить середину этого списка


---

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем подход с быстрым итератором и медленным итератором. Быстрый ходит с шагом два, пока медленный - с шагом один. Когда быстрый дойдет до конца, медленный будет посередине

**Time Complexity:** O(n)
**Space Complexity:** O(1)

### Algorithm:
1.  Создаем быстрый итератор на голове, медленный на ноде перед головой
2. Начинае итерацию до тех пор, пока быстрый итератор не пустой и следующий элемент быстрого итератора не пустой
3. После цикла slow находится перед серединой списка, пропускаем середину и возвращаем следующий элемент фиктивной головы (ответ)
---

## 💻 Code

```python
class Solution:  
	def deleteMiddle(self, head: Optional[ListNode]) -> Optional[ListNode]:  
		dummy = ListNode(next=head)  
		slow = dummy  
		fast = head  
		while fast and fast.next:  
			slow = slow.next
			fast = fast.next.next
		slow.next = slow.next.next
	  
		return dummy.next
```

## ⚔️ VS / Trade-offs

_Альтернативные подходы. Плюсы/Минусы._
- **VS Изначальный подход:** Пройтись один раз по списку - получить его длину, после этого снова пойти по списку и пропустить элемент посередине. Минусы: лишний проход, лишний итераторы
