#sr-due 
```go
func pathSum(root *TreeNode, targetSum int) int {
    prefix := map[int]int{0: 1} // пустой путь с суммой 0 встречается один раз
    return dfs(root, 0, targetSum, prefix)
}

func dfs(node *TreeNode, currSum, target int, prefix map[int]int) int {
    if node == nil {
        return 0
    }

    currSum += node.Val
    count := prefix[currSum - target] // пути, которые заканчиваются здесь
    prefix[currSum]++

    count += dfs(node.Left, currSum, target, prefix)
    count += dfs(node.Right, currSum, target, prefix)

    prefix[currSum]-- // бэктрекинг
    return count
}
```
💡 Идея решения
- Используем **префиксные суммы** и хэш-таблицу (map).  
- На каждом узле считаем текущую сумму от корня (`currSum`).  
- Путь с суммой `targetSum`, заканчивающийся в текущем узле, существует тогда и только тогда, когда ранее на пути встречался префикс `currSum - targetSum`.  
- В `map` (`prefix`) храним, сколько раз встречалась каждая префикс-сумма.  
**Ключевые моменты:**
1. Инициализируем `prefix[0] = 1` (пустой путь, позволяет считать пути, начинающиеся прямо с корня).  
2. В каждом узле:
   - `count := prefix[currSum - targetSum]` — локальные пути, оканчивающиеся здесь.  
   - Рекурсивно считаем пути в левом и правом поддереве.  
   - После обхода детей откатываем (`prefix[currSum]--`), чтобы соседние ветки не видели «чужие» префиксы.
