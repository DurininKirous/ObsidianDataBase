# 💡 The What
*О чем задача? Что нужно сделать?*

You are given an _absolute_ path for a Unix-style file system, which always begins with a slash `'/'`. Your task is to transform this absolute path into its **simplified canonical path**.

The _rules_ of a Unix-style file system are as follows:

- A single period `'.'` represents the current directory.
- A double period `'..'` represents the previous/parent directory.
- Multiple consecutive slashes such as `'//'` and `'///'` are treated as a single slash `'/'`.
- Any sequence of periods that does **not match** the rules above should be treated as a **valid directory or** **file** **name**. For example, `'...'` and `'....'` are valid directory or file names.

## 🔧 Approach & Solution
*Какой подход? Какая идея решения?*
- Используем стек: заносим новые элементы пути последовательно, если встречаем точку - пропускаем её, если две точки - удаляем предыдущий элемент пути. В конце собираем полученный результат

**Time Complexity:** O(n)
**Space Complexity:** O(n)

### Algorithm:
1. Разбить путь по `/` на части.
2. Для каждой части:
    - если пустая (`""`) или `"."` → пропустить;
    - если `".."` → удалить верх из стека (если он есть);
    - иначе добавить директорию в стек.
3. Собрать результат как `"/" + strings.Join(stack, "/")`.

## 💻 Code

```go
import "strings"

func simplifyPath(path string) string {
    stack := []string{}
    parts := strings.Split(path, "/")
    for _, val := range parts {
        if val != "" && val != "." {
            if val == ".." {
                if len(stack) > 0 {
                    stack = stack[:len(stack)-1]
                }
            } else {
                stack = append(stack, val)
            }
        }
    }
    return "/" + strings.Join(stack, "/")
}
```
