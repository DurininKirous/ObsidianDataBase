```go
func longestSubarray(nums []int) int {
    left := 0
    numZeros := 0 
    maxLength := 0
    for i, val := range nums {
        if val == 0 {
            numZeros += 1
        }

        for numZeros > 1 {
            if nums[left] == 0 {
                numZeros -= 1
            }
            left += 1
        }

        maxLength = max(maxLength, i - left)
    }
    return maxLength
}
```
**Идея**  
Скользящее окно с не более чем **одним нулём** внутри.  
Поддерживаем левую границу и счётчик нулей. Пока нулей > 1 — сдвигаем левую границу.  
Длина лучшего подмассива после удаления одного элемента равна `i - left`.

**Сложность**: `O(n)` времени, `O(1)` памяти.
