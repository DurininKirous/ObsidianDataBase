```python
class Solution:
    def asteroidCollision(self, asteroids: List[int]) -> List[int]:
        stack = []
        for asteroid in asteroids:
            alive = True
            while alive and asteroid < 0 and stack and stack[-1] > 0:
                if stack[-1] < abs(asteroid):
                    stack.pop()
                    continue
                elif stack[-1] == abs(asteroid):
                    stack.pop()
                alive = False
            if alive:
                stack.append(asteroid)
        return stack
```
Основная идея:
Используем стек для моделирования состояния ряда. Астероиды добавляются в стек всегда, кроме одного случая конфликта:
    Конфликт: Текущий астероид летит влево (< 0), а на вершине стека — астероид, летящий вправо (> 0).
    Разрешение конфликта (в цикле):
        Если новый больше (abs(new) > top): уничтожаем верхний (pop) и продолжаем проверку следующего в стеке.
        Если равны (abs(new) == top): уничтожаем верхний (pop) и сам новый астероид тоже разрушается.
        Если новый меньше (abs(new) < top): новый астероид разрушается, стек не меняем.
    Если конфликт не возник (или астероид "победил" всех в стеке), добавляем его в стек
