func swapPairs(head *ListNode) *ListNode {
    dummy := &ListNode{Next: head}
    prev := dummy

    for prev.Next != nil && prev.Next.Next != nil {
        first := prev.Next
        second := prev.Next.Next

        // перестановка
        prev.Next = second
        first.Next = second.Next
        second.Next = first

        // сдвигаем prev
        prev = first
    }

    return dummy.Next
}

## Алгоритм
- Завести **фиктивную голову** `dummy`, указывающую на `head`.
- Пусть `prev` указывает на `dummy`.
- Пока есть хотя бы два узла:
    - Пусть `first = prev.Next`, `second = prev.Next.Next`.
    - Меняем местами:
        - `prev.Next = second`
        - `first.Next = second.Next`
        - `second.Next = first`
    - Сдвигаем `prev = first`.
- Вернуть `dummy.Next` как новую голову.
