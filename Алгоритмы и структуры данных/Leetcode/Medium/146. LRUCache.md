```go
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cap = capacity
        self.od = OrderedDict()

    def get(self, key: int) -> int:
        if key not in self.od:
            return -1
        self.od.move_to_end(key, last=False)  # front=MRU
        return self.od[key]

    def put(self, key: int, value: int) -> None:
        if key in self.od:
            self.od[key] = value
            self.od.move_to_end(key, last=False)
        else:
            if len(self.od) == self.cap:
                self.od.popitem(last=True)  # drop LRU (back)
            self.od[key] = value
            self.od.move_to_end(key, last=False)

```
# Идея (коротко)

- Держим **порядок свежести** в двусвязном списке: голова — самый недавно использованный (MRU), хвост — LRU.
- В `idx` (map) за **O(1)** находим узел списка по ключу.
- **Get**: если есть — двигаем узел в голову (`MoveToFront`) и возвращаем значение; иначе `-1`.
- **Put**: если ключ есть — обновляем и в голову; если нет и кэш полон — удаляем хвост (`Back()`), выкидываем его из map, затем вставляем новый в голову.
- **Сложность**: `Get`/`Put` — амортизированно **O(1)**; память **O(cap)**.
