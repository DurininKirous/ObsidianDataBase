```python
import heapq

class MedianFinder:
    __slots__ = ("lo", "hi")  # микро-оптимизация

    def __init__(self):
        self.lo = []  # max-heap через отрицания (левая половина)
        self.hi = []  # min-heap (правая половина)

    def addNum(self, num: int) -> None:
        lo, hi = self.lo, self.hi
        push, pop = heapq.heappush, heapq.heappop

        # кладём сразу в правильную кучу
        if not lo or num <= -lo[0]:
            push(lo, -num)
        else:
            push(hi, num)

        # баланс размеров
        if len(lo) > len(hi) + 1:
            push(hi, -pop(lo))
        elif len(hi) > len(lo):
            push(lo, -pop(hi))

    def findMedian(self) -> float:
        if len(self.lo) > len(self.hi):
            return float(-self.lo[0])
        return (-self.lo[0] + self.hi[0]) / 2.0
```
## Идея
- Две кучи: **max-heap** (левая половина, через отрицание) и **min-heap** (правая).
- Инварианты:
    1. все `lo` ≤ все `hi`;
    2. `len(lo) == len(hi)` или `len(lo) == len(hi)+1`.
- Медиана: вершина `lo` (если левый длиннее) или среднее вершин `lo` и `hi`.
