Непрерывная область памяти заданного размера, хранит однотипные данные, которые расположены друг за другом.
Доступ к элементу массива выполняется с помощью целочисленного индекса за О(1).
Индексация начинается с нуля и размер массива должен быть заранее известен.

**Структура Массива**
*size* - количество элементов в массиве
*capacity* - объём массива, количество выделенной памяти (size <= capacity)
*type*  - тип данных

**Основные операции над элементами массива и  их сложность**
*get(index)* - получение элемента по индексу О(1)
*append()* - вставка в конец О(1)
*remove(index)* - удаление элемента из массива О(n)
