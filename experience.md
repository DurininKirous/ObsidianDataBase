### Аналитика данных
Стек: Python 3.x, pandas для чтения, очистки и джойнов данных из Excel/CSV/SQL, NumPy/SciPy для численных вычислений, Matplotlib/Seaborn для визуализаций и исследовательского анализа, Jupyter для прототипирования, SQL через psycopg2 для работы с PostgreSQL/MySQL.
Практика: сбор и обработка отчетности энергетических компаний, нормализация атрибутов, кодирование категориальных переменных, расчет агрегатов и трендов, подготовка витрин данных для отчетности и моделей ML.

### Машинное обучение
Стек: scikit-learn (Pipeline, GridSearchCV/RandomizedSearchCV, метрики оценки), XGBoost/LightGBM/CatBoost для задач на табличных данных, Statsmodels для регрессионного анализа, ARIMA-моделей и статистических тестов.
Практика: фичеринг для улучшения моделей, кросс-валидация, экспорт артефактов и развертывание инференса через простые REST-эндпоинты на FastAPI.

### NLP
Стек: Hugging Face Transformers для дообучения и инференса BERT-подобных моделей, Tokenizers/Datasets для подготовки текстовых корпусов, классические методы из scikit-learn (TF-IDF, логистическая регрессия/линейные SVM) для базовых задач классификации.
Практика: прототип ассистента на основе корпуса техподдержки, классификация пользовательских обращений, извлечение похожих ответов, расчет корреляций и семантического сходства, анализ тональности текстов.

### Разработка пайплайна (бот, Selenium и дистрибуция)
Стек: FastAPI как бэкенд-сервис по расписанию, aiogram для адресной рассылки, Selenium/BeautifulSoup для веб-скрапинга, pandas для трансформаций данных, Yandex.Disk API для хранения артефактов, Git для версионирования.
Docker: контейнеризация FastAPI-сервиса и бота, единый docker-compose (сеть, зависимости, healthcheck, рестарты), .env для секретов; отдельные контейнеры для Selenium-драйверов при необходимости.
Практика: регламентный ETL из баз данных и веб-источников, формирование итогового архива, публикация на Яндекс.Диск и точечная рассылка пользователям с логированием статусов и механизмами ретраев.

### Сервис на Django — DRF
Стек: Django, Django REST Framework (сериализаторы, представления, фильтры, пагинация), парсинг CSV через pandas, .env и requirements.txt для конфигурации, Git для версионирования.
Практика: разработка контент-сервиса с учетом лимитов показов и фильтрацией по категориям, быстрый запуск, воспроизводимые окружения и единые переменные окружения для всех инстансов.

### Скрипт перезаписи данных
Стек: pandas для обработки, psycopg2 (RealDictCursor) для взаимодействия с БД, python-dotenv для секретов, ThreadPoolExecutor для параллелизма, модульная архитектура (ExcelProcessor, DatabaseConnector, HttpClient, ProjectsAPI).
Практика: чтение и валидация Excel-файлов, сверка данных с PostgreSQL, подготовка payload для API, конкурентные PATCH/PUT/POST-запросы с ретраями, детализированный трекинг прогресса и отчет об ошибках.

### Полноценный сайт: Django + React + VPS
Стек: Django (бэкенд), DRF для API, React (SPA-фронтенд), Nginx как реверс-прокси, Gunicorn/Uvicorn как WSGI/ASGI-серверы, CI/CD, деплой на VPS; TCP-подключение через публикацию Uvicorn/Gunicorn/Nginx на нужном порту с настройкой firewall, домена и SSL.
Docker: контейнеризация бэкенда и фронтенда через docker-compose (web, nginx, static), разделение на prod/dev-профили, .env для секретов, health-checks и логирование.
Практика: сборка фронтенда, обслуживание статики/медиа через Nginx, проксирование API по TCP-порту, выполнение миграций и сбор статики на деплое, проверка доступности через health-эндпоинт.
