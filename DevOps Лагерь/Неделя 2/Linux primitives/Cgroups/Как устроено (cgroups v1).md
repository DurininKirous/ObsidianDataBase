#sr-due 
### Компоненты
- Hierarchy 
	Структура каталогов, смонитрованная в `/sys/fs/cgroup`, в которой можно создавать поддиректории - это и есть cgroups.
- Controllers
	Это "модули", который отвечают за конкретный ресурс. Например:

| Контроллер | Для чего                           |
| ---------- | ---------------------------------- |
| cpu        | Распределение времени CPU (shares) |
| cpuacct    | Учёт CPU time                      |
| cpuset     | Привязка к конкретным ядрам и NUMA |
| memory     | Лимиты памяти и swap               |
| blkio      | Дискова I/O нагрузка               |
| net_cls    | Маркировка пакетов для tc          |
| freezer    | Заморозка/разморозка процессов     |
- Tasks
	Каждый процесс можно поместить в cgroup, добавив его PID в файл `tasks`

Файловая система:
/sys/fs/cgroup
  ├── cpu/
  │   ├── myapp/
  │   │   ├── tasks
  │   │   ├── cpu.shares
  │   │   └── ...
  └── memory/
      ├── myapp/
      │   ├── tasks
      │   ├── memory.limit_in_bytes
      │   └── ...
