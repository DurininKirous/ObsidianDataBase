#sr-due 
Когда запускается новый контейнер, например:
`docker run -it alpine sh`
Docker:
1. Создаёт новый namespace через clone или через runc
2. Монтирует overlayFS в новом mount namespace
3. Подключает к Docker bridge в новом net namespace
4. Запускает sh в этих namespace
