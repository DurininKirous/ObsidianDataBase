#sr-due 
Namespaces - это механизм ядра Linux для изоляции ресурсов между процессами.
С помощью них процессы видят ограниченную часть системы. Это как запустить их в "виртуальной реальности", где они думают, что:
- у них свои процессы
- свой hostname
- своя сетевая карта
- своя root FS
- свои пользовательские uid/gid
