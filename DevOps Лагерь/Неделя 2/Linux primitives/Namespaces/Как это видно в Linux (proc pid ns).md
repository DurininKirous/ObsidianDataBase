#sr-due 
Docker контейнер - просто процесс, как и любой другой процесс в линуксе. Чтобы посмотреть его namespace, достаточно зайти на /proc/$PID/ns.
Чтобы найти pid контейнера, то достаточно написать docker inspect $container, там будет pid. 
Там будет примерно такой вывод:
ipc -> ipc:[4026531839]
mnt -> mnt:[4026531840]
net -> net:[4026532002]
pid -> pid:[4026531836]
uts -> uts:[4026531838]
user -> user:[4026531837]
Номера справа от обозначения namespace - это номер inode, под которым ядро зарегистрировало этот namespace.
В Linux **namespaces реализованы через VFS (виртуальную файловую систему)**, и каждый namespace — это как специальный файл в ядре с inode.

Если два процесса находятся в одном namespace, у них будет **один и тот же inode для этого namespace**.
