#sr-due 
runc - это
- бинарник, написанный на go
- он реализует стандарт  OCI Runtime Specification
- Используется Docker, containerd, kubernetes (через cri), podman
по сути это набор системных вызовов, упакованных в красивую cli обёртку

### Что важно помнить

| Свойство        | Описание                                                   |
| --------------- | ---------------------------------------------------------- |
| Stateless       | Сам runc ничего не менеджит, он просто запускает контейнер |
| Один процесс    | Каждый вызов - один контейнерный процесс                   |
| Ядровый уровень | Он ближе всех к ядру: syscalls напрямую                    |
| OCI-совместим   | Читает config.json по opencontainers/runtime-spec          |
