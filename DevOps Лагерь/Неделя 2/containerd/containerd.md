#sr-due 
containerd - это низкоуровневый контейнерный рантайм, который:
- управляет жизненным циклом контейнеров (create, start, stop, delete)
- работает как демон 
- использует runc для запуска изолированных контейнеров
- сам по себе не имеет ui - управляется через ctr или Docker
