#sr-due 

| Команда             | Назначение                         |
| ------------------- | ---------------------------------- |
| `docker run`        | create + start (+ pull если нужно) |
| `docker ps`         | список запущенных контейнеров      |
| `docker images`     | список локальных образов           |
| `docker pull`       | загрузка образа                    |
| `docker build`      | сборка образа из Dockerfile        |
| `docker exec`       | команда внутри контейнера          |
| `docker logs`       | вывод логов stdout/stderr          |
| `docker stop`       | остановка (SIGTERM)                |
| `docker rm` / `rmi` | удаление контейнера / образа       |
| `docker inspect`    | подробная JSON-инфа по объекту     |

### Важные флаги

- `-it` — интерактивный терминал
- `--rm` — удалить контейнер после завершения
- `--name` — указать имя
- `-p 8080:80` — проброс порта
- `-v host:container` — volume-монтирование
- `--env/-e` — переменные окружения
- `--network` — тип сети (`bridge`, `host`, ...)
- `--entrypoint` — переопределить entrypoint
- `--user` — UID:GID контейнера
