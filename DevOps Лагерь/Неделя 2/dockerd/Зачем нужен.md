#### Зачем нужен dockerd, если есть containerd?
Потому что containerd - это ядро, а dockerd - удобный и умный мозг:
- containerd умеет:
	- запускать контейнеры
	- снапшоты
	- образы
	- события
- Но не умеет:
	- работать с HTTP API
	- делать docker build
	- управлять образами, volume'ами, плагинами
	- автоперезапуск, логи и т.д.
- Всё это делает dockerd
#### Связь с containerd
- dockerd использует containerd через gRPC (через /run/containerd/containerd.sock)
- Docker не вызывает больше напрямую runc, это делает containerd
- Контейнеры теперь живут в `/run/containerd/...`, а не в Docker-специфичных папках
