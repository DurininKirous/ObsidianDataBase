#sr-due 
Утилита для изменеия мягких и жёстких лимитов для конкретной оболочки (на другие оболочки изменения не переносятся, только на дочерние процессы оболочки).
ulimit -n - показать лимит на открытие файловых дескрипторов в сессии
ulimit -u - показать лимит на максимальное количество процессов
ulimit -Hx - показать жёсткий лимит на какой-то лимит
ulimit -s - лимит на стек
ulimit -a - все лимиты
Если к каждой команде выше дописать число, то лимит поменяется.
