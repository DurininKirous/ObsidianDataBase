#sr-due 
Аналог htop, но показывает данные по трафику. Показывает кто куда подключается, порт, скорость входящего и выходящего трафиков и суммарно сколько прошло
sudo iftop - обычный запуск
sudo iftop -i eth0 - запуск по интерфейсу определённому
