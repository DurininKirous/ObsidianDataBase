#sr-due 
Аналог htop, но показывает нагрузку на чтение/ввод на дисках по процессам.
sudo iotop - просто запуск
sudo iotop -o - показывает только процессы с существующей нагрузкой, убирает пустые строки
sudo iotop -a - статистика за сессию
