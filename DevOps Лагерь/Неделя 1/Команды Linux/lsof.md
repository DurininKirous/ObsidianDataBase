Показывает список процессов, которые используют тот или иной файл. а файлом ожет быть сокет юникс, сокет тсп, обычный файл и так далее

lsof - просто список используемых файлов, вывод будет слишком большим

lsof -i - использование TCP/UDP сокетов процессами.
lsof -i :22 -  использование 22 порта
lsof -p 2222 - что использует 2222 процесс
lsof -U - использование UNIX-сокетов
lsof +D /path/to/folder - рекурсивно показывает все используемые файлы в указанной папке
lsof /path/to/file - показывает просто кто использует файл данный
