#sr-due 
SELinux (Security-Enhanced Linux) - это система Mandatory Access Contol (MAC), которая добавляет дополнительные ограчения доступа сверх стандартной модели UNIX.
Даже если процесс запущен от root, SELinux может запретить ему доступ к файлам, сокетам, портам, если это не предусмотрено политикой.

Каждый файл, процесс, сокет, порт имеют в системе security context:
`user:role:type:level`
В 99% случаев мы работаем с type, который определяет как процессы могут обращаться к объектам.

| Пример                                   | Описание       |
| ---------------------------------------- | -------------- |
| system_u:object_r:httpd_sys_content_t:s0 | Файл для nginx |
| system_u:system_r:sshd_t:s0              | Процесс sshd   |

### Основные режимы SELinux:

| Режим      | Что значит                                  |
| ---------- | ------------------------------------------- |
| enforcing  | Политики применяются, нарушения блокируются |
| permissive | Политики не блокируются, но логируются      |
| disabled   | SELinux полностью отключён                  |

## Основные команды SELinux

| Команда      | Для чего используется                                    |
| ------------ | -------------------------------------------------------- |
| getenforce   | Показать текущий режим (Enforcing, Permissive, Disabled) |
| setenforce 0 | Перевести в permissive                                   |
| setenforce 1 | Перевести в enforcing                                    |
| sestatus     | Подробная информация о статусе                           |
| ls -Z        | Показ контекста файлов                                   |
| ps -eZ       | Показ контекста процессов                                |
