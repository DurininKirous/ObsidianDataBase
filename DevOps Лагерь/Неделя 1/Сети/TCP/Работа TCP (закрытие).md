TCP закрывается двунаправленно, то есть каждый поток байтов закрывается отдельно.
Для закрытия отправляются специальные пакеты с флагом FIN.

| Этап закрытия | Какой тип флага отправляется | Что происходит                                                                                                                                        |
| ------------- | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1             | FIN                          | Клиент говорит, что больше не будет слать данные                                                                                                      |
| 2             | ACK                          | Сервер подтверждает приём FIN пакета, но сам может ещё слать данные.                                                                                  |
| 3             | FIN                          | Сервер говорит, что больше не будет слать данные                                                                                                      |
| 4             | ACK                          | Клиент подтверждает, что получил пакет FIN. Ждёт ~2MSL времени, потом закрывает соединение, то есть переходит в состояние TIME-WAIT, а потом в CLOSED |
