#sr-due 
TCP-флаги - это заголовки пакета, которые управляют установкой и разрывом соединения, они гарантируют установку и закрытие соединения

Основные флаги: 

| Флаг | Название    | За что отвечает                             |
| ---- | ----------- | ------------------------------------------- |
| SYN  | synchronize | Запрос установить соединение                |
| ACK  | acknowledge | Подтверждение получения пакета              |
| FIN  | finish      | Запрос закрыть соединение                   |
| RST  | reset       | Немедленно закрыть соединение, ошибка/сброс |
