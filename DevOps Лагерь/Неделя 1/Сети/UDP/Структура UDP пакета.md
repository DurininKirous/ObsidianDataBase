#sr-due 
Структура UDP пакета проще, чем TCP, нет никаких seq и ack номеров.

| Поле        | Размер |
| ----------- | ------ |
| Source Port | 16 бит |
| Dest Port   | 16 бит |
| Length      | 16 бит |
| Checksum    | 16 бит |
| Data        | ...    |
Примечательно наличие поля Length тут, которого нет в TCP пакете. Объясняется тем, что UDP работает как сообщение - одно сообщение отправлено и на этом всё. в TCP устанавливается соединение и непрерывно отправляются байты нарезкой, там длина не нужна целевого пакета.
