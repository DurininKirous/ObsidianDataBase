#sr-due 
Протокол для сопоставления адресных имён и их ip адресов. 
Особенность: база иерархическая, строится в виде дерева, каждая часть имени - это отдельная зона ответственности.
Основные роли:

| Кто                     | За что отвечает                                                                         |
| ----------------------- | --------------------------------------------------------------------------------------- |
| Root Servers            | Знают, где находятся сервера верхнего уровня                                            |
| TLD Servers             | Знают, где находятся сервера доменов второго уровня                                     |
| Authorative DNS Servers | Хранят конкретные записи для доменов                                                    |
| Resolvers               | Обычно это DNS сервер провайдера или Google (8.8.8.8), который делает recursion за тебя |
| Кэширующие              | сохраняет ответы, чтобы не спрашивать каждый раз                                        |
1) Пользователь → браузер/ОС → проверяет локальный DNS кеш
2) Если нет — спрашивает у resolver (8.8.8.8)
3) Resolver:
   - root: кто для .ru?
   - TLD (.ru): кто для ya.ru?
   - authoritative: какой IP у ya.ru?
4) Возвращает IP → кеширует
5) TCP+HTTP идёт на полученный IP
