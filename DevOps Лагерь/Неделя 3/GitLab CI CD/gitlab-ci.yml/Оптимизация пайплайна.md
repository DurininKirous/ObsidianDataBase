#sr-due 
parallel: - запуск нескольких одинаковых job'ов
job:
  script: echo "Job $CI_NODE_INDEX of $CI_NODE_TOTAL"
  parallel: 4
  
GitLab создаст 4 job’а с переменными:
- `$CI_NODE_INDEX` = 1, 2, 3, 4
- `$CI_NODE_TOTAL` = 4

parallel.matrix - запуск job по сетке параметров
test:
  stage: test
  script:
    - ./run-tests.sh $VERSION $OS
  parallel:
    matrix:
      - VERSION: [1.0, 1.1]
        OS: [ubuntu, alpine]
		
📌 GitLab создаст job’ы с комбинациями:
1.0 / ubuntu
1.0 / alpine
1.1 / ubuntu
1.1 / alpine

`rules: changes:` — запуск job только при изменении файлов
lint-go:
  script: golangci-lint run
  rules:
    - changes:
        - '**/*.go'
      when: always
    - when: never
Job запускается **только если были изменения в `.go` файлах**.
