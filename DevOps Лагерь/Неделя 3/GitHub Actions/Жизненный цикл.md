#sr-due 
## 🔄 Жизненный цикл

1. Trigger (on:) → GitHub запускает workflow
2. Парсится DAG → `jobs`, `needs`
3. Поднимается runner (VM)
4. Исполняются `jobs` → `steps` (по `run:` / `uses:`)
5. Логи отправляются в UI, статус возвращается в PR/commit

## ⚙️ Компоненты

- **Workflow** — набор jobs + triggers
- **Trigger** — `on:` (push, PR, manual)
- **Job** — исполняется изолированно
- **Step** — команда внутри job
- **Runner** — окружение (обычно `ubuntu-latest`)
- **Action** — переиспользуемый шаг (`uses:`)
- **Context** — переменные (`github`, `env`, `secrets`, `matrix`)

## 🔧 Пример

```yaml
on: [push]
jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: 1.22
      - run: go build ./...
```
