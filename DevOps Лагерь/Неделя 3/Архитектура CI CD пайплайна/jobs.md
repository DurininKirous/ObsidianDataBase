#sr-due 
>минимальный атом исполнения. Это один environment + один набор скриптов
- Изолированные: отдельный runner или контейнер (Ubuntu, Alpine, shell)
- Один скрипт, одна ответственность:
	- install-deps
	- run-lint
	- run-tests
	- build-docker

Важные поля:

| Поле            | Назначение                   |
| --------------- | ---------------------------- |
| runs-on         | Где выполняется              |
| steps           | Последовательные команды     |
| env             | Переменные окружения         |
| timeout-minutes | Защита от зависаний          |
| if:             | Условие выполнения job'а     |
| needs:          | Зависимости от других job'ов |
