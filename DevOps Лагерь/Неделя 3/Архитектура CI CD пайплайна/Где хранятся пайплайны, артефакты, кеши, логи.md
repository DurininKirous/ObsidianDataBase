#sr-due 

| Объект      | Где хранится                             | Как доступен                              |
| ----------- | ---------------------------------------- | ----------------------------------------- |
| Pipeline    | PostgreSQL (`ci_pipelines`, `ci_builds`) | Вся мета-информация                       |
| Артефакты   | На диске GitLab (или S3/NFS)             | `tmp/cache/artifacts/` или Object Storage |
| Кеши        | Shared cache (локальный/MinIO/S3)        | `tmp/cache/project/`                      |
| Runner логи | `POST /trace` → Redis/PostgreSQL         | Видны в Web UI                            |

🧠 GitLab поддерживает external object storage (S3, GCS), что важно для production.
