#sr-due 
- Каждый Pod живёт в своём сетевом namespace
- Все контейнеры Pod'а делят один Pod IP и сетевой стек
- Этот IP назначается при создании Pod через CNI Plugin
- Pause-контейнер держит netns, чтобы IP не пропадал при рестарте прилоежний
То есть Pod - маленькая виртуальная машина с IP внутри кластера
