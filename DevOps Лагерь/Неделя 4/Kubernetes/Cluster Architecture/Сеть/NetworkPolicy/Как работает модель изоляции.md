#sr-due 
- До применения политики: Pod принимает и отправляет трафик без ограничений
- Как только Pod выбран политикой: он становится изолированным по соответстующему направлению
	- Если в политике указан Ingress -> вход в Pod теперь разрешён только тем, кто явно прописан
	- Если указан Egress -> исходящий трафик Pod'а разрешён только по правилам
- Политики аддитивны: если несколько политик выбирают Pod, то все их "allow" правила складываются. Запрета как такового нет - есть не разрешено
