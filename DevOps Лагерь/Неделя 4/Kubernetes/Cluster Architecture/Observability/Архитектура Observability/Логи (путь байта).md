#sr-due 
```bash
stdout/stderr (app) → containerd CRI logging → 
/var/log/pods/...  → /var/log/containers/*.log → 
Promtail/Fluent Bit (tail → parse → label) → 
Loki/Elasticsearch → Grafana/Kibana
```
- Promtail/Fluent Bit добавляют лейблы: namespace, pod, container, app, cluster
- Loki хранит "чанги" логов и индекс по лейблам (не текст!), запросы - LogQL
- Корреляция: из Grafana на графике метрик "кликаешь" в логи той же сущности
Подводные сущности:
- разрастание лейблов -> больной индекс (дорого)
- парсинг больших JSON-логов -> CPU/IO
- падение Promtail/Fluent Bit = "слепя зона"
