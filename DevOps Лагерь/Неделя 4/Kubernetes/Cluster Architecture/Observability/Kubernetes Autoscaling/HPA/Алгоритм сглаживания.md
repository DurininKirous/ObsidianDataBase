#sr-due 
HPA v2beta2+ имеет "stabilization windows":
```yaml
behavior:
  scaleUp:
    stabilizationWindowSeconds: 0
  scaleDown:
    stabilizationWindowSeconds: 300
```
-- HPA усредняет метрики за окно (например, последние 5 минут), чтобы избежать "флапа" (частых колебаний вверх-вниз)
