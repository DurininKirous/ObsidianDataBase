#sr-due 
- В WorkQueue кладёт ключи, не объекты. Объект достаём из кеша информера.
- Done() должен быть вызван всегда.
- При ошибке - AddRateLimited. При успехе - Forget
- Reconcile должен быть быстрым и идемпотентным. Долгие операции - разбивать на шаги или выводить в фон. 
- Следить за метриками:
	- **queue_length** (сильно растёт → воркеров мало или баги),
	- **work_duration** (слишком долгие reconcile),
	- **retries** (массовые ошибки).
