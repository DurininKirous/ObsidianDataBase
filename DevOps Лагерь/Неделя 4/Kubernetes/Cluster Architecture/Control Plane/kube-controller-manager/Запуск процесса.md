containers:
- command:
    - kube-controller-manager
    - --cluster-signing-cert-file=/etc/kubernetes/pki/ca.crt
    - --cluster-signing-key-file=/etc/kubernetes/pki/ca.key
    - --root-ca-file=/etc/kubernetes/pki/ca.crt
    - --service-account-private-key-file=/etc/kubernetes/pki/sa.key
    - --leader-elect=true
    - --controllers=*,bootstrapsigner,tokencleaner

Основные флаги:

| Флаг                                                   | Назначение                                                      |
| ------------------------------------------------------ | --------------------------------------------------------------- |
| `--controllers=*`                                      | Какие контроллеры запускать (можно указать через запятую)       |
| `--leader-elect=true`                                  | Включить распределённое лидерство — нужен один активный процесс |
| `--root-ca-file`, `--service-account-private-key-file` | Для генерации токенов, CA и подписей                            |
| `--cluster-signing-cert-file`                          | Для подписывания CSRs                                           |
| `--use-service-account-credentials=true`               | Каждый контроллер работает от имени своей SA                    |
| `--allocate-node-cidrs=true`                           | Управление подсетями узлов (если включен cloud-controller)      |
| `--cluster-cidr=10.244.0.0/16`                         | CIDR кластера (для авто-назначения pod-сетей)                   |
