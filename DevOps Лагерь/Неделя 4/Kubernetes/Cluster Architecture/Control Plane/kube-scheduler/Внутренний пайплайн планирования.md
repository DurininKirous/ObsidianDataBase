#sr-due 
Pod появляется в etcd (без nodeName)
           ↓
kube-scheduler via watch API
           ↓
[PreFilter Plugins]
           ↓
[Filter Plugins]  → отбрасывают неподходящие ноды
           ↓
[Score Plugins]   → проставляют приоритеты
           ↓
[Select Best Node]
           ↓
[Bind Plugin]     → делает Patch: pod.spec.nodeName = "node-X"

Всё это управляется **через Framework Scheduling API**.
