#sr-due 
1. Guaranteed
	1. У каждого контейнера заданы `requests` и `limits` для CPU и памяти, причём requests=limits
	2. Идея: «не эластичный», должен держаться до последнего
2. Burstable
	1. Есть хоть один `request`, но не выполняется правило Guaranteed для всех контейнеров
	2. Идея: «эластичный», может разрастись выше requests до limits
3. BestEffort
	1. Ни у одного контейнера **нет** `requests` и `limits` ни по CPU, ни по памяти.
	2. Идея: «как повезёт», первые кандидаты на выселение.

> QoS вычисляется **на весь Pod** из набора контейнеров (init-контейнеры не влияют).
