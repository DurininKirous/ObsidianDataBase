#sr-due 
- **Где искать**: `/etc/kubernetes/manifests` (или путь из `--pod-manifest-path`).  
    Проверяй логи kubelet: `journalctl -u kubelet | grep -i static`.
- **Переименование файла** = удаление пода (kubelet увидит, что файла нет).
- **Имя mirror**: не удивляйся суффиксу `-<nodeName>` — так задумано.
- **Отладка**: `kubectl describe pod <mirror-name> -n <ns>`, `kubectl logs/exec` работают так же, как на обычных подах.
- **Не пытайся управлять через Deployment** — это другой механизм; static pod — «локальный сервис» ноды.
