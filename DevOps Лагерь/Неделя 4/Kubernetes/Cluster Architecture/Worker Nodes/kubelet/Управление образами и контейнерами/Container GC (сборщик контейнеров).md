#sr-due 
### Когда срабатывает
- kubelet чисти завершённые контейнеры
- Параметры:
	- `--minimum-container-ttl-duration` (по умолчанию 0s) → сколько контейнер должен храниться после завершения.
	- `--maximum-dead-containers` (по умолчанию unlimited).
	- `--maximum-dead-containers-per-container` (по умолчанию 1).
Алгоритм:
- kubelet хранит не больше заданного числа остановленных контейнеров
- Если лимиты превышены -> старые контейнеры удаляются

### Важное:
- kubelet всегда хранит **последний завершённый контейнер**, чтобы можно было посмотреть его логи (`kubectl logs --previous`).
- Если больше контейнеров уже не надо → они удаляются GC.
