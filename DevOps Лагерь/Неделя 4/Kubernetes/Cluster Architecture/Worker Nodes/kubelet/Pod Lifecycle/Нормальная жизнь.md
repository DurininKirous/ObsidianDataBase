#sr-due 
- kubelet следит за контейнерами, пробами, перезапускает по `restartPolicy`
- restartPolicy:
	- `Always` (Deployment): любой выход контейнера -> рестарт
	- `OnFailure` (Job): рестарт при ненулевом коде
	- `Never`: не рестартует
- CashLoopBackOff: контейнер быстро падает после старта -> рестарты с экспоненциальным бэкоффом, kubectl describe pod покажет причину
