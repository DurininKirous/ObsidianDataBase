Ноды контролируют информацию связанную с их объёмом ресурсов, например количество свободного озу, ядер и т.д. Эти данные отправляются на API сервер автоматически через kubelet, если включена авторегистрация. Если ноды добавляются вручную, то надо самому прописывать эти данные.
