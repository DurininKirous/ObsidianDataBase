Каждый кластер должен иметь свой DNS.
Кластерный DNS это такой DNS сервер, который предоставляет DNS записи для сервисов Kubernetes.
Контейнеры, которые запущены Kubernetes, автоматически имеют DNS кластера в своих настройках.
