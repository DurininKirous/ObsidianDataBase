#sr-due 
- Несовпадение `storageClassName` между PVC и PV (или PVC просит класс, а PV без класса)
- AccessModes не совпадают (PVC запрашивает RWX, а PV умеет только RWO)
- Недостаточная capacity
- VolumeMode mismatch (PVC: Block, PV: Filesystem)
- Node/Zonal Affinity (PV привязан к другой зоне, чем планируется Pod)
- Для облачных дисков RWO: **multi-attach запрещён** — один и тот же том нельзя одновременно писать с нескольких нод.
Быстрый debug
``` shell
kubectl get pvc -A
kubectl describe pvc data-pvc -n app   # события «почему не биндимся»
kubectl get pv
kubectl describe pv data-pv
```
