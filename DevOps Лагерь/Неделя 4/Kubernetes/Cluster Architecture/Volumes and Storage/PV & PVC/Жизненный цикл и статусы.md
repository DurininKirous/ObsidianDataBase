#sr-due 
- PV: `Available` -> (биндится) -> `Bound` -> (PVC удалён) -> Released -> (дальше по ReclaimPolicy: Retain/Delete)
- PVC: `Pending` (ищет PV/ждёт динамики) -> Bound (есть том)
- Важно: PV - кластерный ресурс, а PVC - namespace-ресурс. Один PV биндится к одному PVC
