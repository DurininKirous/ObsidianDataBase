#sr-due 
```bash
mychart/
├─ Chart.yaml              # метаданные пакета (name, version, appVersion, type)
├─ values.yaml             # дефолтные значения для всех шаблонов
├─ values.schema.json      # (рекоменд.) валидация values на этапе install/upgrade
├─ templates/              # только рендеримые манифесты
│   ├─ deployment.yaml
│   ├─ service.yaml
│   ├─ configmap.yaml
│   ├─ ingress.yaml
│   └─ _helpers.tpl        # функции/шаблоны для include/define
└─ charts/                 # зависимости (tar.gz subcharts) после helm dep update

```
Ключевые идеи:
- всё, что может меняться между окружениями -> в values.yaml
- логику выносим в helpers.tpl (меньше дублирования, стабильный diff)
- имена ресурсов - через helper'ы, а не вбитые строки (иначе получите дрейф имён)
