### 💡 The What
*Определение для 5-летнего. Что это?*
Yadi - это инструмент для поиска компонент с известными уязвимостями в зависимостях вашего проекта

### ⚙️ The Why & How
*Инженерная суть. Механика. Зачем это нужно?*
- Большая часть любого нашего сервиса состоит из 3rd party компонент. Из-за этого возникают риски безопасности
- Используйте Yadi, чтобы проверить сторонние компоненты вашего сервиса
- Yadi поддерживает Node.js (NPM и Yarn) и Python (PyPi) и умеет даватьь рекомендации по устранению проблем
- Может использоваться как для регулярного мониторинга, так и самостоятельной проверки зависимостей проекта
