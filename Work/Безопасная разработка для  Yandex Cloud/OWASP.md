### 💡 The What
*Определение для 5-летнего. Что это?*
Open Web Application Security Project (OWASP) - это открытый проект обеспечения безопасности веб-приложений. Участники проекта работают над созданием статей, учебных пособий, документации, инструментов и технологий, находящихся в свободном доступе

 OWASP Web Security Testing Guide (WSTG) -  является ведущим ресурсом по тестированию кибербезопасности для разработчиков веб-приложений и не только
