#sr-due 
Это один длинный ряд чисел, например:
```
1234 (bash) S 1 1234 1234 0 -1 4194560 804 0 0 0 3 1 0 0 20 0 1 0 12345 1048576 200 18446744073709551615 4194304 4198368 140737488346976 0 0 0 0 0 0 0 0 0 17 1 0 0 0 0 0 6295552 6296576 12582912 140737488349501 140737488349516 140737488349516 140737488351633 0
```
Поля (по man proc):

|№|Имя|Что значит|
|---|---|---|
|1|pid|идентификатор процесса|
|2|comm|имя исполняемого файла|
|3|state|состояние (R, S, D, Z, T, t)|
|4|ppid|родительский PID|
|14|utime|время в user mode (в тиках)|
|15|stime|время в kernel mode|
|23|rss|количество страниц памяти|
|24|rsslim|лимит по RSS|
