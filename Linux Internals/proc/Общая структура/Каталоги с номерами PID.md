| Файл              | Что содержит                                  | Как использовать                   |
| ----------------- | --------------------------------------------- | ---------------------------------- |
| /proc/pid/cmdline | Команда запуска процесса (аргументы через \0) | Прочитать и заменить \0 на пробелы |
| /proc/pid/comm    | Короткое имя процесса                         | Простое чтение                     |
| /proc/pid/stat    | 50+ числовых полей со всей статистикой        | нужен парсинг                      |
| /proc/pid/status  | Читаемый человекоориентированный статус       | Удобно вытаскивать ключ            |
| /proc/pid/io      | Байты чтения/записи в файловую систему        | Для I/O статистики                 |
| /proc/pid/cwd     | Ссылка на текущий каталог                     | Через os.readlink                  |
| /proc/pid/exe     | Симлинк на исполняемый файд                   | Через os.readlink                  |
| /proc/pid/fd      | Список открытых файловых дескрипторов         | Для анализа FD                     |
| /proc/pid/environ | Переменные окружения                          | Разделитель \0                     |
| /proc/pid/statm   | Обобщённая статистика по памяти               | Иногда проще, чем status           |
