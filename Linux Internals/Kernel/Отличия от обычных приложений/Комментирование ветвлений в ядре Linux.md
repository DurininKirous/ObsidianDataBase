### 💡 The What
*Что это?*
Компилятор gcc имеет встроенные директивы, которые позволяют оптимизировать различные ветви условных операторов, выполнение которых наиболее и наименее вероятно. В ядре эти директивы заключены в макросы likely() и unlikely()

### ⚙️ The Why & How
*Инженерная суть. Механика. Зачем это нужно?*
Пример, есть блок
```
if (error) {
/* .... */
}
``` 
Если это ветвление маловероятно, можно использовать следующее:
```
if (unlikely(error)) {
/* ... */
}
```
Если оно наиболее вероятно, можно использовать следующее:
```
if (likely(error)) {
/* ... */
}
```
Их стоит использовать только в том случае, когда направление ветвления  с большой вероятностью известно априори или когда необходима оптимизация какой-либо части кода за счет другой части.
При неправильном предсказывании вероятности ветвления можно снизить производительность, поэтому нужно использовать эти директивы с уверенностью в оценках.
