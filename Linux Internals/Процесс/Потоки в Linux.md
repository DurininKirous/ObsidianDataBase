### 💡 The What
*Что это?*
Потоки в Linux представляют собой процессы, которые делят виртуальное адресное пространство пользователя с родителем.

### ⚙️ The Why & How
*Инженерная суть. Механика. Зачем это нужно?*
- По сути это тот же процесс, только вызываемый с доп флагами для clone
- Есть также потоки ядра, которые не имеют адресное пространство пользователя вовсе, а имеют только системный стек ядра
- Второй тип потоков создается от имени процесса kthreadd, запущенного в ядре. 
- Данные потоки являются облегченными ввиду отсутствия пользовательского адресного пространства.
