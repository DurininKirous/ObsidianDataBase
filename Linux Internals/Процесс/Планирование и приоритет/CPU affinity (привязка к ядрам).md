#sr-due 
**Affinity** ограничивает, на каких логических CPU задача может исполняться. Поводы:
- уменьшить миграции/кэш‑промахи;
- закрепить горячие/NUMA‑чувствительные задачи;
- выделить «изоляцию» для latency‑чувствительных потоков.
Инструменты:
```bash
taskset -c 0,2-3 <cmd> # запустить на CPU0,2,3
taskset -cp 1-3 <PID> # поменять привязку процесса
# программно:
# sched_setaffinity(pid, sizeof(mask), &mask)
# NUMA-полезности:
numactl --cpunodebind=0 --membind=0 cmd # закрепить CPU и память на узле 0
```
