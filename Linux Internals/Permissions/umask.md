#sr-due 
**Маска запрещений**: права нового объекта = базовые права **И** побитовое отрицание `umask`.
- Файлы: базово `666` → **files = 666 & ~umask** (бит `x` по умолчанию **не ставится**).
- Каталоги: базово `777` → **dirs = 777 & ~umask**.  
    Примеры:
- `umask 022` → files **644**, dirs **755**.
- `umask 077` → files **600**, dirs **700**.
