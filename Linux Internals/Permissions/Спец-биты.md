#sr-due 
- **SUID (4xxx)** — исполняемый **файл** запускается с **effective UID владельца файла**.  
    Пример: `chmod 4755 /usr/bin/foo` → `-rwsr-xr-x`.  
    ⚠️ На **скриптах** обычно **игнорируется** (безопасность). Используйте аккуратно; альтернатива — Linux capabilities.
- **SGID (2xxx)**
    - на **файле**: запускается с **effective GID владельца** файла.
    - на **каталоге**: **наследование группы** — всё внутри получает GID каталога; новые подкаталоги тоже с SGID. Очень полезно для общих рабочих директорий команды.  
        Пример: `chmod 2775 /srv/teamshare` → `drwxrwsr-x`.
- **Sticky bit (1xxx)** — актуально для **каталогов**: в **мирово-доступном на запись** каталоге **удалять/переименовывать** файл может лишь **владелец файла/владелец каталога/root** (пример `/tmp`).  
    Пример: `chmod 1777 /tmp` → `drwxrwxrwt`. На файлах историческое поведение устарело.
