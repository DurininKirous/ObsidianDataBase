#sr-due 
Type=dbus - активируется через D-Bus

Семантика: сервис считается запущенным, когда он владеет указанным именем на D-Bus. systemd может его автоматически активировать при обращении к этому bus-name.

Когда использовать: демоны с D-Bus API, интегрированные в десктоп/системные шины (пример: org.freedesktop.\*)

Ключевые директивы: BusName=org.example.MyApp (обязательно), ExecStart=.

Подводные камни: нужен корректно настроенный сервис на системной/пользовательской шине; если имя не занято в таймаут - старт провалится

Мини-шаблон:
```ini
[Service]
Type=idle
ExecStart=/usr/local/bin/warm-cache.sh
```
