#sr-due 
Type=oneshot - запустился и завершился

Семантика: короткая задача завершается -> юнит считается успешным и может остаться "active" с RemainAfterExit=yes. Параллельно с другими oneshot по умолчанию не бегут

Когда использовать: миграция БД, подготовка директорий, стартовые скрипты, генерация конфигов.

Ключевые директивы: RemainAfterExit=yes (оставлять состояние active), возможно несколько ExecStart= (выполняются по очереди)

Подводные камни: не путать с долгоживущими демонами - он завершится, и перезапуск тут не имеет смысла. Для периодики лучше \*.timer.
Мини-шаблон:
```ini
[Service]
Type=oneshot
ExecStart=/usr/local/bin/init-db.sh
RemainAfterExit=yes
```
