#sr-due 
Type=idle - запуск, когда система освободится

Семантика: systemd откладывает старт до момента, когда остальные задачи получили свой квант (idle). Полезно, чтобы не мешать критическому пути загрузки. 

Когда использовать: низкоприоритетные вещи при буте: сбор метрик, прогрев кешей, не критично для readiness.

Ключевые директивы: Type=idle, дальше как simple

Подводные камни: не гарантия «после всех навсегда» — только отложенный старт; для строгого порядка всё равно используйте `After=`/`Requires=`.  
**Мини-шаблон:**
```ini
[Service]
Type=idle
ExecStart=/usr/local/bin/warm-cache.sh
```
