#sr-due 
Жёсткая зависимость ("must have")
- Смысл: зависимые обязательны: при старте нашего юнита systemd должен активировать их; если они падают/останавливаются - наш юнит тоже останавливают или считается failed.
- Важно: не задаёт порядок. Добавляй After= для детерминизма
- Когда: БД/Брокер без которых сервис не имеет смысла
Пример:
```ini
[Unit]
Requires=postgresql.service
After=postgresql.service
```
