#sr-due 
Init system:
- читает описание целей/зависимостей загрузки
- решает порядок старта с учётом зависимостей (и параллелизма, если поддерживаются)
- предоставляет механизмы активации (по сокету/пути/таймеру/событию - если поддерживается)
- следит за состоянием служб (живы ли процессы, коды выхода, перезапуски по политике)
- управляет завершением: последовательный стоп юнитов, размонтирование, синхронизация дисков, poweroff/reboot
