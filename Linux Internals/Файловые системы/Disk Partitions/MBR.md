#sr-due 
MBR (Master Boot Record)
- Разметка в первом секторе (LBAO, 512 байт): загрузчик + таблица разделов
- До 4 primary-разделов (или 3 primary + 1 extended)
- Ограничения по размеру: адресация 32-бит LBA -> ~2 ТиБ на диск/раздел
- Нет резервных копий таблицы; уязвич к порче первых секторов
- Используется с BIOS/Legacy boot

- В **MBR** (первый сектор диска, 512 Б) есть **таблица из 4 записей по 16 Б**.  
    4×16=64 Б под таблицу разделов — **жёсткий лимит формата MBR** → максимум **4 primary**.
- Это историческое ограничение. GPT его не имеет.
