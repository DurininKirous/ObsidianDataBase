#sr-due 
GPT (GUID Partition Table)
- Часть стандарта UEFI. Поддерживает и Legacy с защитным MBR
- Практически неограниченное число разделов (Linux обычно 128 по умолчанию)
- Большие диски: адресация 64-бит LBA
- Две копии таблицы (в начале и в конце), CRC32 для проверки целостности
- Разделы имеют GUID-типы (EFI System, Linux FS, Linux swap)
- Рекомендуется для всех новых установок
