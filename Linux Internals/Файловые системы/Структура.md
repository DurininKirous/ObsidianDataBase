#sr-due 
Superblock - метаданные ФС
- Паспорт ФС: размер, блоки, состояние/чистота, флаги, UUID, параметры журнала
- В ext4 есть резервные копии суперблока по группе блоков (можно восстановиться)
- Диагностика: `dumpe2fs -h /dev/sdX1` (ext*), `xfs_info` (xfs), `btrfs inspect-internal dump-super`
Inode table:
- Записи о файлах/каталогах: тип, владелец, права, временные метки, ссылки, указатели на данные/экстенты
- Для ext4 - размещаются по группам блоков; для xfs/btrfs -- B-деревья/экстенты и более сложные индексы
Data blocks:
- Собственно содержимое файлов/каталогов
- Размер блока влияет на фрагментацию/эффективность (типично 4К)
- В ext4 - extents (диапозоны блоков) для больших файлов; в xfs/btrfs - аналогично
Free space bitmap:
	- Карта свободного места
	- Битовые карты/бади-аллокаторы/деревья, отмечающие свободные/занятые блоки/иноды
	- В xfs/btrfs - B-деревья свободных экстентов (гибче, чем простой bitmap), что улучашет аллокацию для больших файлов и параллелизма
