#sr-due 
Сетевой UNIX-шаринг
**Ключевое:** общий доступ по сети, маппинг UID/GID, блокировки, кеши.

**Подводные камни:**
- Сеть — часть I/O пути: отвал → процессы в **D** (зависание); следи `dmesg`, `mountstats`, `nfsstat -m`.
- UID/GID-маппинг: нужен согласованный `idmapd`/LDAP/SSSD.
- Для прод-нагрузки — отдельная сеть, `rsize/wsize` тюнинг.
