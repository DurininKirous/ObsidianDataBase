#sr-due 
1. Номер inode
	- Уникальный ID внутри конкретного раздела/ФС. Не глобален между разными ФС.
	- Команда ls -li file (покажет номер), stat file
2. Тип (mode bits)
	1. Обычный файл (-), каталог (d), симлинк (l), сокет (s), FIFO (p), устройство блочное/символьное (b/c)
	2. Команды: stat -C %F file или %f/%A
3. Права (rwxrwxrwx + биты)
	1. Три триады: user/group/other
	2. Доп. биты: setuid (4k), setgid (2k), sticky (1k)
	3. Команды: chmpd, getfacl (если acl), stat -c %a file (октально)
4. Владалец (UID, GID)
	1. Кто владеет объектом и какая группа главная.
	2. Команды: chown user:group file, stat -c "%u %g %U %G"
5. Размер (size)
	1. Для обычного файла - байты данных
	2. Для каталога - размер "таблицы имён" (дирент)
	3. Для симлинка - длина пути-целевого (симлинк хранит строку)
	4. Команды: stat -c %s, du -h (занято на диске != size -> метаданные, блоки, sparse)
6. Временные метки
	1. atime (access): последний доступ/чтение. Часто оптимизируют монтированием relatime/noatime
	2. mtime (modify): изменилось содержимое файла
	3. ctime (change): изменились метаданные inode (права, владелец, ссылки) или содержимое (любой write тоже поднимает ctime)
	4. нет «creation time» в POSIX; некоторые ФС имеют **crtime/btime**, но не стандартно доступно.
	5. Команды: `stat -c 'A:%x M:%y C:%z' file`
7. Link count (hard links)
	1. Сколько каталожных записей (имён) указывают на этот же inode
		1. Обычный файл: 1 и выше
		2. Каталог: минимум 2 (. и ссылка у родителя ..), плюс по одному за каждый вложеннный каталог
		3. Удалёние файла: уменьшает link count; данные реально освобождаются только когда счётчик стал 0 и нет открытых дескрипторов
	2. Команды: stat -c %h file, find -samefile file
8. Указатели на данные (data blocks)
	1. Ссылки на блоки/экстенты с содержимым. Реализация зависит от ФС:
		1. ext2/3: прямые, косвенные/двойные/тройные косвенные блоки
		2. ext4/xfs/btrfs: extents (диапозоны блоков) - эффективнее для больших/фрагментированных файлов
		3. Также хранятся атрибуты о разрежённости (sparse), фрагментации, и пр. (зависит от ФС)
	2. В inode нет имени файла
