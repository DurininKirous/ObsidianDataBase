#sr-due 
1. Первичная диагностика:
```
uptime                     # показывает load average (1, 5, 15 мин)
mpstat -P ALL 1 5          # отображает загрузку каждого CPU по режимам (user, sys, iowait, steal)
top -H -o %CPU             # выводит процессы и потоки, сортированные по загрузке CPU
pidstat -u -r -d -w 1 5    # даёт статистику по процессам: CPU, память, I/O, контекст-свитчи
```
2. Интерпретация:
	1. load average < числа ядре - ок, = - на пределе, > -  насыщение (saturation)
	2. mpstat:
		1. us высокий - юзерский код нагружает CPU
		2. sy высокий - ядро занято системными вызовами
		3. st высокий - гипервизор "крадёт" cpu у vm
		4. iowait высокий - CPU простаивает, ждёт I/O
	3. pidstat -w: involuntary context switches growing -> вытеснение планировщиком
3. Снимок для пост-анализа:
```bash
top -b -n1 > /tmp/top.txt
ps -eo pid,ppid,cmd,%cpu,%mem,psr,pri,ni,stat --sort=-%cpu | head -50 > /tmp/ps_hot.txt
```
