#sr-due 
### Высокий `us%` (user space)
**Причины:** тяжёлые вычисления, неэффективный код, горячий цикл.  
**Действия:**
- Найди процесс/нить:
```bash
top -H -o %CPU
pidstat -t -u -p <PID> 1
```
- Профиль с `perf` или языковым профайлером.
- Оптимизация: кеширование, уменьшение сложности алгоритма, batch-обработка, параллелизм по ядрам.

### Высокий `sy%` (kernel space)
**Причины:** чрезмерные системные вызовы, сетевой драйвер, firewall, частые мелкие I/O.  
**Инструменты:**
```bash
mpstat -I SCPU 1      # детализирует прерывания по типам
cat /proc/softirqs    # показывает распределение softirq по типам
perf top -g            # выявляет горячие функции ядра
```
**Решения:**  
IRQ affinity, RPS/RFS, batching, offload на NIC, оптимизация правил iptables.

### Высокий `iowait%`
**Причина:** CPU ждёт I/O.  
**Инструменты:**
```bash
iostat -xz 1          # показывает утилизацию и задержки дисков
pidstat -d 1          # статистика I/O per PID
```
**Решения:** асинхронные операции, SSD, page cache, queue depth tuning.

### Высокий `st%` (steal)
**Причина:** гипервизор не выделяет CPU VM.  
**Инструменты:**  
`mpstat` — наблюдение steal time по ядрам.  
**Решения:** миграция VM, уменьшение overcommit, pinning vCPU.

### Большой run queue (`r`) и involuntary cswch
**Причина:** contention — задач больше, чем CPU.  
**Инструменты:**  
`vmstat 1` → поле `r`; `pidstat -w 1` → рост involuntary cswch.  
**Решения:** уменьшить число воркеров, tune cgroups, увеличить quota.

### SoftIRQ/IRQ пики
**Причина:** сетевой бурст, IRQ imbalance.  
**Инструменты:**
```bash
mpstat -I SCPU 1      # нагрузка от прерываний
cat /proc/softirqs
ethtool -S eth0       # сетевые счётчики (дропы, rx/tx)
```
**Решения:** irqbalance, RPS/RFS, tuning сетевых offload’ов.
