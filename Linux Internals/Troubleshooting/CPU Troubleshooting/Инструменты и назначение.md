#sr-due 
### Повседневные (низкая нагрузка)
- **top** — системный монитор в реальном времени: CPU, память, процессы.
- **htop** — интерактивный аналог `top` с визуализацией по ядрам и потокам.
- **pidstat** _(sysstat)_ — собирает статистику по каждому процессу или потоку (CPU, память, I/O).
- **mpstat** _(sysstat)_ — измеряет загрузку каждого CPU/ядра и режимы работы.
- **iostat** _(sysstat)_ — метрики по диску и I/O, полезно для корреляции с iowait.
- **vmstat** _(procps)_ — общая картина CPU, памяти, I/O, run queue, context switches.
- **sar** _(sysstat)_ — исторические данные системных метрик, удобно для ретроспективного анализа.
- **ps** — моментальный снимок процессов с возможностью сортировки и фильтрации.
### Профилирование (средняя нагрузка)
- **perf** _(Linux Performance Counters)_ — низкоуровневый профайлер ядра и user-space; измеряет, где “горит” CPU:
```bash
perf top -g --sort comm,dso,symbol   # профайлинг стэков в реальном времени
perf record -F 99 -g -p <PID> -- sleep 30  # запись профиля
perf report                          # анализ записанного профиля
```
- ➜ Используется для поиска горячих функций в коде и системных вызовах.
- **bpftrace / bcc tools** _(eBPF)_ — продвинутые динамические трейсеры;  
    примеры:
    - `profile` — частотный CPU-профайлер по стэкам;
    - `runqlat` — распределение задержек ожидания CPU;
    - `offcputime` — анализ времени вне CPU.  
        ➜ Позволяют увидеть узкие места без сильного overhead.
- **strace** — трассирует системные вызовы процесса;  
    помогает понять, что процесс делает в ядре (например, частые `futex`/`read`):
    ```
    strace -f -p <PID>
    ```
    Осторожно — влияет на производительность

### Языковые профайлеры
- **Go:** `go tool pprof` (CPU profile через `net/http/pprof`).
- **Python:** `py-spy` — внешний сэмплер; `cProfile` — встроенный профайлер.
- **JVM:** `async-profiler`, `jcmd`, `JFR` — захватывают стэки Java-приложений.  
    ➜ Позволяют изолировать проблему в бизнес-логике, а не в системе.
