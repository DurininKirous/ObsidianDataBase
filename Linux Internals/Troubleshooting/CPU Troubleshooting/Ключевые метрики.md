#sr-due 
1. Load Average и Run Queue
	1. uptime - сводка загрузки системы (число runnable задач)
	2. vmstat 1 - поле r показывает длину очереди на CPU
	3. sar -q 1 5 - исторические данные очередей
	4. Признак saturation: r > число vCPU стабильно
2. Расклад по режимам CPU
	1. mpstat -P ALL 1 - отображает время CPU в разных режимах (us, sy, wa, st)
	2. Анализ по ядрам даёт картину NUMA или IRQ-imbalance
3. Контекстные переключения
	1. pidstat -w 1 - показывает voluntary и involuntary context switches per PID
	2. vmstat 1 - поле cs (все контекст-свитчи/сек) -> involuntary растёт -> конкуренция за CPU; voluntary растёт -> частая блокировка потоков
4. Прерывания и softirq
	1. mpstat -I SUM 1 - сводка аппаратных прерываний
	2. cat /proc/softirqs - счётчики softirq (сетевые, таймеры и др.)
	3. -> NET_RX пики = сетевой шторм или IRQ imbalance
5. Steal (виртуализация)
	1. `mpstat`: колонка `st` — время, когда VM готова, но CPU не выделен.  
	    ➜ >5% = конкуренция с другими VM на хосте.
