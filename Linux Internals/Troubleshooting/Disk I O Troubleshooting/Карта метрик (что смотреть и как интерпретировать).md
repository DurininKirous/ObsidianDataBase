#sr-due 
- IOPS - число операций в секунду. Важно для мелких/рандомных запросов (БД, метаданные)
- Throughput (MB/s) - объём данных в секунду. Важно для больших/последовательных потоков
- Latency - время ответа на I/O. Ключевой показатель качества сервиса диска
- Queue depth - сколько запросов ждут обработки (очередь к устройству)
- %utilization - доля времени, когда устройство занято (но помни: на быстрых NVMe 100% util не всегда означает проблему - смотри ещё latency и queue)
### Быстрые ориентиры
- **Высокая latency** при умеренных IOPS/MB/s → медленный носитель, contention на уровне ФС/драйвера.
- **Высокий queue depth** → saturation (диск не успевает).
- **100% util** + рост latency → достигнут предел производительности.
- **Много процессов делают I/O** → конкуренция; ищем “шумного соседа”.
