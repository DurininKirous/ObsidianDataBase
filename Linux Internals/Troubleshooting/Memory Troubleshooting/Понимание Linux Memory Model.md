### 💡 The What
*Что это?*
Linux не считает "свободную" память добром - он кэширует всё, что может, чтобы ускорить операции.

### ⚙️ The Why & How
*Инженерная суть. Механика. Зачем это нужно?*

| Метрика   | Значение                                                |
| --------- | ------------------------------------------------------- |
| Used      | Активно используемая память (процессы, ядро, буферы)    |
| Free      | абсолютно неиспользуемая память (бесполезный простой)   |
| Buffers   | Кеш метаданных файловой системы (inodes, dir entries)   |
| Cached    | кеш содержимого файлов (страницы из page cache)         |
| Available | истинно свободная память - включает reclaimable кеш     |
| Swap      | область диска, используемая как RAM при нехватке памяти |
Главное правило:
	Низкий free != плохо
	Важно смотреть available, а не free
