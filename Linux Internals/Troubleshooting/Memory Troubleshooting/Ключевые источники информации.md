#sr-due 
### free -h - общий обзор памяти
Показывает использованную, свободную, кешированную и доступную память.
```bash
free -h
```
- Столбец available - реально доступная память
- used часто включает кеш, не паникуй при 90%

### /proc/meminfo
Текстовый файл с десятками метрик: total, free, cached, dirty, slab, swap и т.д.
```bash
cat /proc/meminfo
```
- MemTotal, MemAvailable - основные;
- Buffers, Cached, Slab - кеши;
- Dirty, Writeback - страницы ожидающие записи на диск

### vmstat - сводка виртуальной памяти, CPU и I/O
Показывает активность страниц, свопинг, кэш и run queue
```bash
vmstat 1
```
Колонки:
- si/so - swap in/out
- free, buff, cache;
- r/b - процессы в run queue и блокированные (При росте si/si -> система активно свопит (признак нехватки RAM))

### smem - детализированная статистика по процессам
Более точный, чем top, инструмент анализа потребления памяти (включая shared pages)
```bash
smem -r -k
```
-> Даёт USS (unique set size), PSS (proportional set size) - ключевые для реальной оценки использования памяти каждым процессом

### top / htop - мониторинг в реальном времени
Показывает per-process RSS (resident set size) и %MEM
```bash
top -o %MEM
```
- RSS - реально загруженные в RAM страницы
- VSZ - виртуальне адресное пространство (включает mmap, swap)
- -> Рост RSS при стабильной нагрузке = возможная утечка памяти

### **dmesg | grep -i oom** — события OOM Killer
Просматривает логи ядра на предмет убийства процессов из-за нехватки памяти
```bash
dmesg | grep -i oom
```
➜ Показывает, кого именно ядро убило и по какой причине (OOM score)
