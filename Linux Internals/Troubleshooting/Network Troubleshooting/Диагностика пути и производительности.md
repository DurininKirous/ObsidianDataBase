#sr-due 
Связность и маршрут:
```bash
traceroute 8.8.8.8        # traceroute — список хопов до цели
mtr -rw 8.8.8.8           # mtr — маршрут + потери/RTT в реальном времени
```
- Потери на конкретном хопе, но **без** дальнейших потерь → ICMP rate-limit (норма).
- Потери на хопе **и дальше** → реальная деградация сегмента.

### Пакетный анализ
```bash
tcpdump -n -i eth0 port 443          # tcpdump — захват пакетов по интерфейсу/фильтру BPF
tcpdump -vv -i eth0 host 1.2.3.4     # tcpdump — подробный дамп конкретного IP
```
Используй **краткие выборки** (несколько секунд) и узкие фильтры.
