#sr-due 
**Вопросы:** слушает ли сервис порт? можно ли подключиться? не режет ли межсетевой экран?
```bash
ss -tuln                  # ss — LISTEN-сокеты (tcp/udp, адрес:порт)
ss -tnp state established # ss — активные TCP-соединения с PID
nc -vz host 443           # nc — проверяет возможность TCP-подключения к порту
# telnet host 25          # telnet — альтернативная ручная TCP-проверка (старый, но наглядный)
```
- Порт не слушается локально → приложение не поднялось/не тот bind-address.
- Подключение локально ок, удалённо — нет → сетевые ACL/межсетевой экран/маршрут.

**Действия:** проверить bind (0.0.0.0 vs 127.0.0.1), открыть порт в FW/SG, убедиться в корректном SNAT/DNAT.
