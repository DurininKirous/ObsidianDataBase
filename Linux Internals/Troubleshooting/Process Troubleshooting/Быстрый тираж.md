#sr-due 
```bash
ps -eo pid,ppid,stat,wchan:20,cmd --sort=stat | head -40
# ps — снимок процессов; stat=состояние, wchan=в каком ядровом ожидании “спит”

top -H -o %CPU
# top — реальное время; -H показывает потоки, видно кто “жрёт” CPU/висит

pstree -ap
# pstree — дерево процессов (кто чей родитель, аргументы)

grep -E 'State|Name' /proc/*/status 2>/dev/null | head
# /proc/<pid>/status — состояние и детали из /proc
```
Если много `D` → смотри диск/СХД/сеть. Если много `Z` (зомби) → проблема с родителем, который не делает `wait()`.
